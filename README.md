## 🚀 Быстрый старт для новичка

**Ваша система:** [🪟 Windows](#windows--один-двойной-щелчок) · [🐧 Linux (Ubuntu и др.)](#linux-ubuntu--одна-команда)

### Windows — один двойной щелчок
1. Скачайте программу: зелёная кнопка **Code → Download ZIP**
   ([прямая ссылка](https://github.com/Teslyar75/My_Stamina/archive/refs/heads/master.zip)) и распакуйте,
   например, в `C:\StarTyping`. (Или `git clone https://github.com/Teslyar75/My_Stamina.git`.)
2. Дважды щёлкните **`install.bat`**. Он сделает всё сам:
   - нет Python — поставит Python 3.12 через `winget` (если winget нет, откроет python.org: при установке
     поставьте галочку **«Add python.exe to PATH»** и запустите `install.bat` ещё раз);
   - создаст папку `.venv`, поставит Pillow; спросит один раз (20 с, по умолчанию «нет») про проверку
     произношения (vosk + модель ~40 МБ);
   - создаст ярлык **«Star Typing»** на рабочем столе (это `create_shortcut.ps1`; вручную:
     `powershell -ExecutionPolicy Bypass -File create_shortcut.ps1`) и запустит программу.
3. Дальше — ярлык на рабочем столе или `Stamina.bat`. Если запустить `Stamina.bat` раньше `install.bat`,
   он сам предложит установку.

### Linux (Ubuntu) — одна команда
1. Скачайте и распакуйте ZIP (как выше) или `git clone https://github.com/Teslyar75/My_Stamina.git`.
2. В папке программы выполните:
   ```bash
   bash install.sh
   ```
   Скрипт спросит пароль sudo и поставит всё: `python3 python3-tk python3-venv python3-pip libportaudio2
   espeak-ng alsa-utils` (apt; есть варианты для dnf, pacman, zypper), папку `.venv` с Pillow, vosk и
   sounddevice, модель речи, ярлык в меню (`~/.local/share/applications/star-typing.desktop`) и на рабочем
   столе — и запустит программу. Потом запуск: ярлык или `./run.sh`. Без проверки произношения:
   `bash install.sh --no-voice`.

   Совсем без ZIP, одной строкой (скачает в `~/StarTyping`):
   ```bash
   curl -fsSL https://raw.githubusercontent.com/Teslyar75/My_Stamina/master/install.sh | bash
   ```

### Если что-то не так
| Проблема | Решение |
|---|---|
| `python` не найден / «Python не установлен» (Windows) | запустите `install.bat`; если winget нет — поставьте Python с python.org с галочкой **Add python.exe to PATH**, перезапустите `install.bat` |
| Открывается Microsoft Store вместо Python | Параметры → Приложения → Псевдонимы выполнения приложений → выключите `python.exe`/`python3.exe`, затем `install.bat` |
| Нет фона «Живой космос», в настройках «Не установлен Pillow» | кнопка «УСТАНОВИТЬ ВСЁ» в приветствии или `install.bat` / `bash install.sh` |
| Linux: `No module named tkinter` | `sudo apt install python3-tk` (или просто `bash install.sh`) |
| Linux: `externally-managed-environment` при pip | ставьте через `bash install.sh` — он делает отдельную `.venv` |
| Не слышно звуков / озвучки (Linux) | `sudo apt install alsa-utils espeak-ng`; проверьте: `espeak-ng "hello"` |
| Микрофон не работает | Windows: Параметры → Конфиденциальность → Микрофон → разрешить приложениям; Linux: `sudo apt install libportaudio2`, выберите микрофон в настройках звука. Без микрофона «говорение» переходит на самооценку |
| Данные | Windows: `%APPDATA%\Stamina`, Linux: `~/.local/share/StarTyping` |

*Бывший **Stamina**.*

Star Typing — настольная программа на Python (tkinter) в стиле **пульта
космического корабля**. Основные задачи:

1. **Слепая печать** — скорость, точность, ритм, миссии по рядам клавиатуры
   (английская QWERTY и русская ЙЦУКЕН), звания и бортжурнал.
2. **Изучение английского** — вы загружаете книгу или статью на английском и
   печатаете её, а панель **UPLINK** показывает перевод **текущего слова**
   (под прицелом, с красной подсветкой нужной буквы) и **всего предложения**.
   Печать и словарь идут одним потоком: пальцы учатся, мозг запоминает слова
   в контексте.
3. **Скорочтение** — гипердрайв (RSVP по слову с красной буквой-точкой фиксации и
   плавным разгоном), обычная читалка **«Книга»** с полки, проверка понимания и тренажёры
   обзора: Шульте, Горбов, пирамида, вспышка. Библиотека общая с печатью + свободные книги Gutenberg.

С версии 3.4 за одним компьютером может заниматься **целый экипаж**: у каждого пилота свой
профиль (позывной, эмблема, необязательный код доступа) и весь свой прогресс, а **ДОСКА ПОЧЁТА**
показывает, кто впереди.

## Новое (октябрь 2026)

- **ЭФИР (Ctrl+6) — канал связи экипажа.** Пилоты одного компьютера оставляют друг другу
  сообщения в общей ленте: непрочитанное подсвечивает раздел, ответ — строкой ввода внизу (Enter).
  Это прототип и фундамент будущего **онлайн-эфира флота**: слой данных повторяет будущее
  серверное API, поэтому при онлайне экран не переписывается. Подробно: [docs/COMM_ETHER.md](docs/COMM_ETHER.md).

- **Звуки скинов** и **Esc-перезапуск змейки** (PR #19).
- **ОРИОН (Ctrl+7, Home) — приём агента на борт.** Бортовой разум живёт как пассажир корабля: чат
  с живой линией и доской, микрофон (Vosk) и озвучка ответа голосом корабля, задания в документ борта.

### Мостик
- **Иллюминатор** — текст «проезжает» через неподвижный прицел в центре (идея исходного
  Stamina). Набранное уходит влево и тускнеет, текущая буква в янтарной рамке.
  Ошибка — красная вспышка и подсказка «нажато «ы» — нужно «s»»; если перепутана
  раскладка, программа подскажет переключить её.
- **Звёзды** летят быстрее, когда вы печатаете быстрее (можно выключить).
- **Двигатель** — спидометр: живая скорость в знаках в минуту, средняя скорость и WPM
  (слов в минуту), янтарная отметка — цель миссии.
- **Телеметрия** — точность, время, ошибки, серия без ошибок, сколько осталось.
- **Ритм печати** — насколько ровно вы печатаете (100 % — как метроном).
- **Навигация пальцев** — клавиатура с подписями EN и RU, цветные зоны пальцев,
  следующая клавиша подсвечена, внизу иллюминатора подсказка, каким пальцем жать.
  Кнопка «Тепловая карта» показывает процент ошибок на каждой клавише.
- **UPLINK // ПЕРЕВОДЧИК** (только для своего текста) — см. отдельный раздел ниже.

### В чём фишка: печать + английский (UPLINK)

Панель UPLINK под иллюминатором — это и есть «учебный канал»:

| Элемент | Что показывает |
| --- | --- |
| Строка сверху | исходное английское предложение |
| **Окошко по центру (под прицелом)** | набираемое **слово**: слева оригинал, справа перевод; **красная** буква — та, которую нужно нажать сейчас; уже набранные буквы слова приглушены |
| Строка под окошком | перевод **всего предложения** крупным шрифтом |

Так вы не отрываетесь от набора: слово запоминается в момент печати, а предложение
даёт контекст. Для русского «груза» направление перевода обратное (RU → EN).
Переводчик работает в фоне, кэширует ответы и не тормозит печать.

### Время считается честно
Таймер стартует с первой нажатой клавиши. Если вы отошли и не печатали больше 4 секунд,
это время не засчитывается. **Esc** — пауза (Esc или Пробел — продолжить). Если окно
теряет фокус или вы уходите в другой раздел, полёт ставится на паузу сам.

### Миссии и звания
Каждая миссия добавляет новые клавиши: домашний ряд → верхний ряд → нижний ряд →
все буквы → цифры. Миссия засчитана при точности от 92 %:
★ — засчитано, ★★ — точность ≥ 95 % и скорость не ниже цели,
★★★ — точность ≥ 98 % и скорость на 25 % выше цели. Пройденная миссия открывает следующую.
За каждый заход начисляется опыт (XP), звания: Кадет → Пилот-стажёр → Мичман →
Лейтенант → Капитан-лейтенант → Капитан → Коммодор → Адмирал флота.

**Ремонт систем** — программа запоминает ошибки по каждой клавише и собирает упражнение
из слов, в которых много ваших «слабых» букв.

### Свой текст: главная функция Star Typing
Раздел **«Свой текст»** (Ctrl+3), панель «Подготовка текста — загрузка груза»:
1. **Полка книг** / **Свободные книги** — каталог [Project Gutenberg](https://www.gutenberg.org/)
   (общественное достояние): поиск по названию и автору, **▤ ПО КАТЕГОРИЯМ** (CEFR **A1–C2**),
   лента бесплатных книг **с обложкой или без**, скачивание на борт и набор.
   Либо **Открыть файл…** (`.txt`, UTF-8 или Windows-1251) / **Вставить из буфера**.
2. Справа, в панели **«Обработка текста»**, три независимых переключателя (по умолчанию включены все):
   - **Убрать заглавные буквы.** Если выключить, регистр учитывается, и вы тренируете Shift;
   - **Убрать знаки препинания.** Если выключить, знаки остаются, а типографские
     « » — … заменяются на обычные " - ..., чтобы их можно было набрать;
   - **Один пробел между словами.** Лишние пробелы, табуляции и переводы строк схлопываются.
3. **✦ Применить к тексту в поле** — выбранная обработка применяется прямо к тексту в редакторе
   (как «Применить все правки» в прежней версии).
4. **Предпросмотр для тренажёра**: что именно попадёт в строку набора, сколько знаков, язык и
   сколько времени займёт текст при вашей скорости.
5. **Сохранить на борт** (текст готов, старт с первой клавиши на Мостике), **На борт и старт с
   начала** или **Продолжить с …%**.
6. Ещё есть **Очистить**, **Защита от правки** (поле только для чтения) и **Экспорт .txt**
   (сохранить подготовленный текст в файл).

Оригинал текста сохраняется: по нему переводчик понимает, где кончается предложение.
Прогресс сохраняется автоматически, программу можно закрыть в любой момент и
потом нажать «Продолжить». Незаконченный текст из версии 2 (например, «1984»)
продолжается с того же места. Если заново открыть тот же файл, можно продолжить с того же
места, и переводчик начнёт работать по предложениям.

### Звук
- верная клавиша — щелчок печатной машинки;
- ошибка — глухой «бззт»;
- миссия выполнена — колокольчик каретки.

Звуки синтезирует сама программа (`stamina/sounds.py`), файлы лежат в `stamina/sounds/`.
Включить или выключить звук: F9 или кнопка «ЗВУК» вверху. Громкость меняется в настройках.

### Переводчик UPLINK (технически)
- Переводит **слово** и **предложение** отдельно (оба запроса кэшируются).
- Перевод идёт в фоне, печать никогда не тормозит.
- Сначала бесплатный Google Translate (без ключа), запасной вариант — MyMemory.
- Кэш: `cache/translations.json` рядом с программой — повторные фразы работают офлайн.
- Нет сети — на панели «НЕТ СВЯЗИ», повтор раз в 20 секунд.
- Выключается в настройках.

## Экипаж и ДОСКА ПОЧЁТА (версия 3.4)

За одним ноутбуком занимаются несколько человек — у каждого **свой пилот**: позывной, эмблема,
акцентный цвет, звание и весь прогресс (печать и миссии, свой текст, английский, скорочтение,
библиотека). Данные пилота лежат в своей папке `%APPDATA%\Stamina\pilots\<id>\`, пилоты не видят
и не портят прогресс друг друга. Демо-экипаж на снимках вымышленный.

Вход и доска — [выше](#пульт-основные-экраны). На входе: ← →, Enter, Insert — новый пилот,
F2 — личное дело, Del — списать, «★ ДОСКА ПОЧЁТА». В шапке кабины — плашка пилота
(Ctrl+Shift+P — сменить). Доска: звание, XP, печать, английский, чтение, Шульте; период
«всё время» / «неделя»; сортировка по колонкам; код для просмотра не нужен.

| Новый пилот | Код доступа |
| --- | --- |
| ![Новый пилот](screenshots/pilots/02_create_pilot.png) | ![Код](screenshots/pilots/03_pin_dialog.png) |
| Позывной, эмблема, цвет, копирование настроек. | 4–8 цифр, блокировка после 5 ошибок; сброс с подтверждением. |

**Как устроено:**
- **Перенос без потерь.** При первом запуске 3.4 прежние данные копируются в пилота №1
  «George Orwell / 1984» с проверкой SHA-256; перед этим — резервная копия
  `backups\pre-pilots-<дата>\`, старые файлы в корне переименовываются в `*.migrated`.
- **Код доступа** — необязательный, 4–8 цифр; хранится только солёный хэш PBKDF2-SHA256
  (200 000 итераций). Это защита от случайного входа в чужой профиль, а не шифрование.
  Кодов по умолчанию нет нигде — ни в программе, ни в тестах, ни в документации.
- **Смена пилота** — всё сохраняется, программа перезапускается с экраном входа. Ярлык на конкретного
  пилота: `main.py --pilot "<позывной>"` (или переменная `STAMINA_PILOT`).
- **Экспорт / импорт** — файл `.stpilot` (zip + манифест с SHA-256); при импорте новый id и свободный позывной.

Устройство и план: [docs/pilots/](docs/pilots/) (SPEC_PILOTS, CURSOR_TASK_PILOTS, макеты).

## Живой космос (версия 3.5)

Во **всех разделах** за полупрозрачными «голографическими» панелями — живой космос: звёзды в трёх
слоях с параллаксом, кометы с хвостами, далёкие планеты (одна с кольцом), астероиды. В открытых
местах (иллюминатор мостика, просветы между панелями, поле карточек на входе в кабину) сцена резкая;
под панелями и кнопками — **матовое стекло**: размыто, затемнено и подкрашено в цвет панели, поэтому
текст, цифры и кнопки остаются чёткими. Когда вы печатаете, корабль «разгоняется», а резкое окно
обновляется реже, чтобы не мешать.

**Настройки → «Живой космос»:** `ВЫКЛ` · `ЛЁГКИЙ` (по умолчанию, до 12 к/с) · `ПОЛНЫЙ` (до 24 к/с,
больше объектов). Если «полный» на вашем компьютере не успевает (кадр > 30 мс 5 секунд подряд),
программа сама переходит на «лёгкий» до перезапуска. При выключенной анимации Windows
(«уменьшение движения») картинка неподвижна. Нужен **Pillow** (`pip install -r requirements.txt`);
без него фон просто выключен.

Анимация — GIF в начале README (там же ссылка на MP4). Фон один во всех вкладках;
отдельные снимки каждого отсека с космосом не дублируем.

| Мостик, ожидание | Мостик, набор |
|---|---|
| ![](screenshots/living_space/bridge_idle.png) | ![](screenshots/living_space/bridge_typing.png) |

Замер на ноутбуке (HP, Ryzen 3, 8 ГБ, окно 1260×800, % одного ядра — весь процесс Star Typing):

| Режим | Простой: к/с · CPU | Печать ~300 зн/мин: к/с · CPU |
|---|---|---|
| ВЫКЛ | — · 8 % | — · 17 % |
| ЛЁГКИЙ | 11 · 11 % | 6 · 22 % |
| ПОЛНЫЙ | 21 · 39 % | 11 · 38 % |

Как это укладывается в слабый ноутбук без numpy: статичный слой (туманности и планеты) кэшируется;
каждый кадр рисуются только звёзды, кометы и астероиды и только в резких окнах; стекло считается в
половинном разрешении и размывается раз в 6 секунд, а между пересчётами перерисовываются только те
панели, над которыми пролетает комета или астероид; изображения вставляются в уже созданные
PhotoImage (`paste`). Подробно — [docs/living_space/SPEC.md](docs/living_space/SPEC.md).

## Язык интерфейса, PDF и книги на разных языках (версия 3.6)

### Язык интерфейса: русский, українська, English, Deutsch
Выбор — на экране приветствия (меняется **сразу**) и в **НАСТРОЙКИ → Язык интерфейса** (применяется
**после перезапуска**; кнопка «⟳ ПЕРЕЗАПУСТИТЬ» перезапускает программу с тем же пилотом, прогресс сохраняется).
Переводятся только надписи программы: тексты для печати, словари английского и книги остаются как есть.
Инструкция F1 пока только на русском. Выбор общий для всех пилотов (файл `ui.json` в папке данных).

Интерфейс на английском / немецком выглядит так же, как русский HUD — меняются только подписи
(`screenshots/i18n_en_bridge.png`, `screenshots/i18n_de_settings.png` в репозитории).

### Открыть PDF
**СВОЙ ТЕКСТ → «ОТКРЫТЬ PDF…»** или **СКОРОЧТЕНИЕ → БИБЛИОТЕКА → «＋ ОТКРЫТЬ PDF»** (и просто `.pdf` в «Открыть файл»).
Текст достаётся библиотекой `pypdf` (ставится «УСТАНОВИТЬ ВСЁ» / `install.bat` / `install.sh`) и чистится: склеиваются
переносы «сло-/во», строки собираются в абзацы, убираются номера страниц и повторяющиеся колонтитулы, исправляются
лигатуры (ﬁ → fi). Можно выбрать диапазон страниц и посмотреть текст до импорта. Дальше это обычная книга
библиотеки: оригинал + версия для печати, скорочтение, UPLINK. Книга на 270 страниц читается за ~5 секунд.
Сканы без текстового слоя распознаются и честно показывают сообщение: сначала прогоните файл через OCR
(OCRmyPDF, Tesseract, ABBYY, «Сохранить как текст» в Adobe Reader). Встроенный OCR — в планах.

### Книги на русском, украинском, немецком, английском…
* Язык книги определяется сам, без интернета (ru, uk, be, en, de, fr, es, it, pt, pl, cs, nl, sv).
* Печать кириллицы с украинскими **і ї є ґ** и апострофом (м'ясо, сім'я — апостроф внутри слова остаётся),
  немецкие **ä ö ü ß**. Подсказка раскладки на экранной клавиатуре: **ЙЦУКЕН RU / ЙЦУКЕН UA / QWERTZ / QWERTY**.
  Если нажата буква не той раскладки — подсказка «переключите раскладку».
* Опции подготовки текста: **«Без умлаутов: ä ö ü ß → ae oe ue ss»** (если нет немецкой раскладки) и **«Ё → Е»**.
* Статистика и тепловая карта считают каждую букву; в БОРТЖУРНАЛЕ карта переключается **EN / DE / RU / UA**.
* **UPLINK переводит в любую сторону** между ru / uk / en / de (и с других языков): НАСТРОЙКИ → «UPLINK: перевод на»
  (АВТО = язык интерфейса). Книга на языке перевода переводится на английский (русская/украинская) или на русский.
  Направление видно в заголовке панели: «UPLINK // ПЕРЕВОДЧИК  DE → RU». Перевод онлайн (Google, запасной MyMemory);
  без сети — только фразы, уже лежащие в кэше (кэш отдельный для каждой пары языков).
* Скорочтение: ORP-буква для кириллицы и умлаутов, главы «Розділ / Kapitel / Teil», тест на понимание на языке
  текста, Шульте с буквами А–Я / А–Ї / A–Z / A–Ü, вспышки слов и пирамида на языке книги.

### Как добавить язык интерфейса
1. Скопируйте `stamina/i18n/en.json` в `stamina/i18n/xx.json` (`xx` — код языка) и переведите **значения**
   (ключи — русские фразы — не трогайте; `{0}`, `{1:.0f}` и т. п. сохраните как есть).
2. Добавьте язык в `LANGS` в `stamina/i18n/__init__.py`: `"xx": "Название"`.
3. Проверьте: `python tools/i18n_check.py` (или `python tools/i18n_check.py --missing xx` — список непереведённых фраз).
   Непереведённые фразы показываются по-русски, программа не ломается.
4. После правок кода, где появились новые надписи `t("…")`: `python tools/i18n_check.py --fix-ru`.
Как получены машинные переводы uk/en/de — `tools/i18n_mt/README.md`.

## Горячие клавиши
| Клавиша | Действие |
| --- | --- |
| F1 | справка (инструкция) |
| Esc / Del | пауза / продолжить |
| F5 | начать заново |
| F9 | звук вкл/выкл |
| Home / PgUp / PgDn | Орион / слайдшоу в простое / полный экран (выход — Esc/Del) |
| Ctrl+1…8 | разделы: Мостик, Английский, Скорочтение, Отдых, Радиорубка, Эфир, Орион, Настройки |
| Ctrl+Shift+P | сменить пилота (экран «ВХОД В КАБИНУ») |
| Скорочтение: Пробел / ↑ ↓ / ← → / 1–5 / S / Enter | пауза / скорость / по предложениям / слов в кадре / к месту печати / финиш и тест |
| В отчёте: Enter / → / R / Esc | повторить / следующая миссия / ремонт / закрыть |
| **Tab** | без мыши: прыжок в главное меню; ещё раз Tab — к кнопкам раздела |
| **← → ↑ ↓** (кнопка в фокусе) | соседняя вкладка / подвкладка / кнопка |
| **Enter / Пробел** (кнопка в фокусе) | нажать; **Esc** или **Shift+Tab** — убрать фокус |

Кнопка в фокусе отмечена янтарными уголками. Во время полёта на мостике Tab и стрелки идут в печать:
выйти к меню — **Esc**, затем **Tab**. Работает во всех разделах, на экранах приветствия и входа, в диалогах.

## Где хранятся данные
`%APPDATA%\Stamina\` (на Linux `~/.local/share/StarTyping`, старая `~/.stamina` — если уже есть). С версии 3.4 там лежат реестр экипажа `pilots.json`,
общий `app.json` (размер окна) и папки пилотов `pilots\<id>\`; в папке **каждого пилота** — файлы
из таблицы ниже (формат прежний), плюс `profile.json` и `avatar.png`.

| Файл | Что внутри |
| --- | --- |
| `session.json` | незаконченный свой текст и место, где вы остановились (формат как в версии 2) |
| `stats.json` | история заходов, ошибки по клавишам, звёзды миссий, опыт |
| `settings.json` | настройки и размер окна |
| `cargo.txt`, `cargo_original.txt` | свой текст: адаптированный и оригинал |
|   `english.json` | прогресс вкладки «АНГЛИЙСКИЙ»: карточки, свои переводы, отсеки, XP |
| `library\` | общая библиотека текстов: оригинал, версия для печати и позиции каждого текста |
| `speedread.json` | скорочтение: сессии чтения, рекорды тренажёров, настройки |
| `lounge.json` | рекорды комнаты отдыха |
| `radio.json`, `radio_cache.json` | избранные станции и кэш топа эфира |

Личные данные в репозиторий не попадают: они лежат вне папки программы, а `.gitignore`
дополнительно исключает `session.json`, `stats.json`, `settings.json`, `english.json`,
`speedread.json`, `library/`, `pilots.json`, `app.json`, `pilots/`, `*.stpilot`, логи,
`cache/` и `models/`.

Кэш переводов: `cache\translations.json` в папке программы.

## Установка и запуск
Для новичка — [Быстрый старт](#-быстрый-старт-для-новичка) (`install.bat` / `bash install.sh`). Вручную:
```bash
git clone https://github.com/Teslyar75/My_Stamina.git
cd My_Stamina
python -m venv .venv          # Linux: python3 -m venv .venv
.venv\Scripts\pip install -r requirements.txt    # Linux: .venv/bin/pip install -r requirements.txt
python main.py
```
Проверка произношения (необязательно; модель Vosk ~40 МБ в git не хранится):
`pip install vosk sounddevice` и `python scripts/download_vosk_model.py`.
- `install.bat` / `install.sh` — установка в один шаг; `Stamina.bat` / `run.sh` — запуск;
- `create_shortcut.ps1` — ярлык «Star Typing» на рабочем столе Windows (из `.venv`, если есть);
- данные: Windows `%APPDATA%\Stamina`, Linux `~/.local/share/StarTyping` (прежняя `~/.stamina` тоже читается).
