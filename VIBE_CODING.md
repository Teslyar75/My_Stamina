## 1. Как работать с ИИ

1. **Один документ = один «контракт».** Не говорите «сделай как Star Typing из головы» —
   вставляйте §2, затем **один** этап из §7.
2. **Не просите всё сразу.** После каждого этапа: запуск + тесты (команды в этапе).
3. **Правило приёмки в каждом промпте.** Агент должен знать, когда остановиться.
4. **Если агент «уплыл»** — снова вставьте §2 и фразу:
   `Вернись к этапу N. Не рефакторь вне scope. Сначала тесты.`
5. **Язык ответов агента:** русский. Код и имена файлов — как в спеке (латиница).

### Стартовый пакет для новой сессии

Скопируйте в чат подряд:

1. весь блок §2;
2. текст нужного этапа из §7 (например «Этап 2»);
3. при необходимости: «Эталонные идеи уже в репо `Teslyar75/My_Stamina`, но строй по спеке выше; репо — только сверка.»

## 2. Системный промпт (вставить первым)

```text
Ты — инженер, который собирает настольное приложение Star Typing с нуля.

Стек (MVP):
- Python 3.10+
- только стандартная библиотека: tkinter (+ Canvas), threading, urllib, json, pathlib,
  wave/struct (синтез WAV), winsound на Windows (на Linux — aplay/paplay или тихий fallback)
- без PyQt, CustomTkinter, pygame, Electron

Имена (не менять):
- точка входа: main.py → stamina.app.run_app()
- пакет: stamina/
- данные Windows: %APPDATA%\Stamina\
- данные Linux: ~/.local/share/StarTyping (если уже есть ~/.stamina — можно оставить)
- session.json формат: {"text","index","typed","errors","elapsed"} — прогресс священен

UI: «пульт космического корабля»
- фон #03060C, панели #081221, рамки #15314D
- неон циан #00E5FF, янтарь #FFB000, красный #FF3B5C, зелёный #3DFF8A
- текст #D6F4FF, приглушённый #6F90AB
- кнопки/панели на Canvas со срезанными углами; «свечение» = blend hex-цветов (нет alpha)

Правила работы:
1) Делай только текущий этап; не тащи следующие фичи «заодно».
2) Пиши рабочий код; минимальный дифф; без косметического рефакторинга.
3) После этапа: unittest + краткий отчёт «что проверить руками».
4) Отвечай на русском. Не выдумывай pip-зависимости в MVP.
5) Если чего-то не хватает в спеке — спроси одним коротким вопросом; иначе выбери
   разумный default и напиши его явно.
```

## 3. Что строить

### MVP (обязательно — этапы 0…12)

Настольный тренажёр слепой печати:

1. Пользователь вставляет/открывает **свой текст** → адаптация (регистр / пунктуация / пробелы).
2. **Мостик:** строка набора с фиксированным прицелом по центру, виртуальная клавиатура
   EN+RU, пауза Esc, честный CPM, звук.
3. **Миссии** 10 EN + 10 RU по рядам клавиш, звёзды, XP, звания, «ремонт» слабых клавиш.
4. **Бортжурнал:** сводка, график, тепловая карта ошибок.
5. **UPLINK:** перевод текущего предложения своего текста в фоне (не блокирует печать).
6. **Настройки + F1-справка** (файл ИНСТРУКЦИЯ.md).

### После MVP (этап §8 — по желанию)

Пилоты с PIN, вкладка «Английский», скорочтение/библиотека/Gutenberg, радио, комната отдыха,
«живой космос» (Pillow). **Не начинайте их, пока MVP не проходит чеклист §12.**

### Не цель

Веб-сервис, мобильное приложение, облачный аккаунт, магазины плагинов, «красивый UI на React».

## 4. Жёсткие ограничения

| Правило | Почему |
| --- | --- |
| Не переименовывать `main.py`, пакет `stamina`, AppData `Stamina` | ярлык и прогресс |
| Не ломать формат `session.json` | продолжение книги |
| UI не блокировать сетью | переводчик только в фоне |
| IDLE_CAP = 4.0 с | простои не раздувают время |
| CPM только по верным символам | иначе «награда за ошибки» |
| Слабое железо (≈8 ГБ RAM) | дешёвые анимации, отключаемые эффекты |

### Команды проверки (Windows PowerShell)

```powershell
python -m unittest discover -s tests -v
python main.py
```

## 5. Дизайн-система (кратко)

```
BG       #03060C
PANEL    #081221
LINE     #15314D
CYAN     #00E5FF
AMBER    #FFB000
RED      #FF3B5C
GREEN    #3DFF8A
TEXT     #D6F4FF
MUTED    #6F90AB
```

- Шрифты UI: Bahnschrift → Segoe UI; моно: Cascadia Mono → Consolas.
- `px(n)` — масштаб от DPI (`winfo_fpixels("1i")/96`).
- `blend(c1,c2,t)` — смешение hex для «неона» без прозрачности.
- Иллюминатор: **граница набрано/осталось зафиксирована в центре Canvas**; двигается текст.
- Звёзды в фоне (опционально) ускоряются от `instant_cpm`, ~20–30 fps, можно выключить.

```

  test_engine.py

```

### Данные пользователя (`%APPDATA%\Stamina\`)

| Файл | Назначение |
| --- | --- |
| `session.json` | незаконченный свой текст: text, index, typed, errors, elapsed |
| `settings.json` | звук, громкость, переводчик, звёзды, клавиатура, font, geometry… |
| `stats.json` | runs[], key_errors, stars миссий, xp |
| `cargo.txt` / `cargo_original.txt` | адаптированный и оригинальный текст |
| `cache/translations.json` | кэш UPLINK (можно рядом с программой или в AppData) |

Запись сессии — атомарно: `*.tmp` → replace. Автосейв ≤ 1 раза / ~3 с.

### Поток

```
main → app.run_app → Cockpit
  ├─ Bridge + TypingEngine (+ UPLINK для cargo)
  ├─ MissionsScreen → start_mission → Bridge
  ├─ CargoScreen → process_text → session/cargo → Bridge
  ├─ LogScreen ← stats
  └─ Settings / Help(F1)
```

## 7. Этапы MVP (ядро)

После §2 вставляйте **ровно один** блок ниже.

### Этап 0 — Каркас

```text
Создай каркас Star Typing (Python 3.10+, только stdlib).

Структура:
  main.py                 # if __name__ == "__main__": run_app()
  stamina/__init__.py     # APP_NAME="Star Typing", __version__="0.1.0"
  stamina/app.py          # run_app(): DPI на Windows, затем tk.Tk
  requirements.txt        # комментарий: MVP = stdlib only
  .gitignore              # __pycache__, .venv, cache/, *.pyc, .idea

В app.py на Windows:
- SetProcessDpiAwareness(1) или SetProcessDPIAware
- SetCurrentProcessExplicitAppUserModelID("Teslyar75.StarTyping")

Окно: фон #03060C, title "Star Typing", minsize ~900×600.
Не добавляй pip-зависимости. Не пиши движок и миссии.
Готово: python main.py открывает пустое тёмное окно без traceback.
```

### Этап 1 — Адаптация текста + тесты

```text
Реализуй stamina/text_processing.py и tests/test_text_processing.py.

Функции:
- normalize_spaces(text) — любой whitespace → один пробел, trim
- remove_punctuation(text) — убрать ASCII punct + типографику «»„“—–…№; буквы/цифры/пробелы оставить
- to_lowercase(text)
- adapt_for_typing(text) = normalize_spaces(to_lowercase(remove_punctuation(text)))
- is_valid_practice_text(text) — после adapt непусто
- process_text(text, *, lower=True, punct=True, spaces=True, translit=False, yo=False)
  (флаги независимы; translit/yo можно заглушить на потом)

Тесты unittest:
- "  Hello,   World!  " → "hello world"
- «Привет,   мир!» → "привет мир"
- пусто / только знаки → невалидно
- process_text с выключенными флагами по отдельности

Без UI. Запусти: python -m unittest tests.test_text_processing -v
```

### Этап 2 — Движок набора

```text
Реализуй stamina/engine.py — TypingEngine без tkinter — и tests/test_engine.py.

API:
- __init__(text, index=0, typed=0, errors=0, elapsed=0.0, case_sensitive=False)
- current, finished, progress, started
- press(char, now) → "ok" | "error" | "done" | None
- pause(now) / resume(now)
- elapsed(now), cpm(now), instant_cpm(), accuracy, rhythm
- segment(now) → dict для журнала
- key_stats: dict[str, [ok, err]]

Правила:
- таймер с первого press
- dt между нажатиями режется IDLE_CAP=4.0
- на паузе время не растёт
- CPM = index * 60 / elapsed  (ошибки НЕ в числителе)
- instant_cpm по ~25 последним интервалам
- rhythm 0..100 по вариации ~30 интервалов

Тесты: ok/error, pause, idle cap, CPM без ошибок, segment.
Запусти unittest. UI не трогай.
```

```text
theme.py: цвета из системного промпта; px(); font(); blend().
```

### Этап 4 — Мостик MVP

```text
Собери stamina/layouts.py и stamina/bridge.py.

layouts.py: ряды QWERTY и ЙЦУКЕН; id клавиши; зона пальца; цвет зоны; lookup символа.

bridge.py (фрейм внутри будущего Cockpit, пока можно pack в root):
1) Иллюминатор (Canvas): прицел ФИКСИРОВАН по центру; текст едет; текущий символ в янтарной рамке;
   пробелы только между словами.
2) Виртуальная клавиатура: подсветка следующей клавиши (янтарь) / ошибки (красный); подписи EN/RU.
3) KeyPress → TypingEngine.press → перерисовка.
4) Esc — пауза/продолжить (не диалог выхода).
5) Табло: время, CPM, ошибки, точность.

Пока без миссий, UPLINK и спидометра-дуги. Можно стартовать с захардкоженной фразы.
Готово: печать идёт, пауза работает, подсветка клавиши верная.
```

## 8. Расширения (после MVP)

Вставляйте **по одному** модулю. В начале каждого промпта добавьте:

```text
Контекст: Star Typing MVP уже работает (Cockpit, Bridge, Cargo, Missions, Log, UPLINK).
Не ломай session.json и ярлык. Новый код — отдельный пакет/хук, вкладка отключается при ошибке импорта.
```

### 8.1 Пилоты и вход

```text
Несколько пилотов: pilots.json + папка pilots/<id>/ с личными settings/stats/session.
Экран входа, позывной, опциональный PIN (соль+хэш, не plaintext).
Миграция старых данных корня → первый пилот.
Доска почёта. Ctrl+Shift+P — смена пилота (рестарт).
Тесты на миграцию/PIN без утечки секретов в лог.
```

### 8.2 Вкладка «Английский»

```text
Пакет stamina/english/ + english_hook.py (lazy import, лог ошибки в AppData).
Подразделы: обзор, звёздные карты (плитки слов), сканер слова (IPA/озвучка/перевод),
миссии (говорение/чтение/вопросы), проверка SM-2, отсеки, журнал, настройки.
Словарь — локальный JSON/данные; TTS платформенный; ASR опционален (vosk) и отключаем.
Критично: не вызывать Tk из фоновых потоков; UI-колбэки только через after/очередь главного потока.
Не устраивать Configure→resize→Configure циклы на кнопках.
```

### 8.3 Скорочтение и библиотека

```text
Пакет stamina/speedread/: гипердрайв RSVP, читалка «Книга», тренажёры (Шульте и др.),
журнал, настройки. Общая Library с «своим текстом».
Опционально: каталог Gutenberg / bilingual (отдельные модули, таймауты сети, кэш обложек).
Позиция чтения сохраняется. Тяжёлый парсинг — в фоне.
```

### 8.4 Радиорубка

```text
stamina/radio/: поиск radio-browser, избранное, плеер через внешний mpv/ffplay (subprocess).
Глобальный engine; мини-бар в шапке при эфире.
```

## 10. Промпты на типичные баги

### CPM завышен

```text
CPM растёт от ошибок. Исправь: числитель = число верно принятых символов (index),
не typed. Добавь тест. Не трогай UI сверх необходимости.
```

### Прицел «прыгает»

```text
В иллюминаторе граница набрано/осталось должна быть фиксирована в центре Canvas;
двигается только текст. Моноширинный шрифт. Без подчёркивания «как в Word».
```

### После пароля/входа окно мелькает или зависает

```text
После choose_pilot создаётся Cockpit и mainloop. Найди:
1) бесконечные Configure (обработчик меняет geometry → снова Configure);
2) вызовы Tk/winfo/after из фоновых threading.
Исправь: UI только из главного потока (очередь + after); в Configure — guard и
не менять размер, если значение то же. Добавь лог в AppData при необработанном исключении.
```

### Переводчик тормозит печать

```text
Все HTTP только в worker; UI — queue + after. Печать при «НЕТ СВЯЗИ» продолжается.
```

### Таймер тикает, когда отошёл

```text
IDLE_CAP=4с и полная остановка на pause / FocusOut. Проверь engine.elapsed.
```

## 13. Почему промпты такие (учёба)

Хороший промпт для кодинг-агента почти всегда содержит:

| Элемент | Пример из этого файла |
| --- | --- |
| **Роль и стек** | «инженер, Python+tkinter, stdlib» |
| **Нельзя ломать** | имена `main.py`, формат session.json |
| **Один scope** | один этап = одна цель |
| **Контракт API** | методы TypingEngine списком |
| **Примеры I/O** | `"Hello, World!" → "hello world"` |
| **Критерий готово** | команды тестов + ручной сценарий |
| **Анти-scope** | «не пиши UI», «не рефакторь соседнее» |

### Антипаттерны

| Плохо | Лучше |
| --- | --- |
| «Сделай крутой тренажёр печати» | этап 4 + критерии |
| «Исправь баги» | один симптом + ожидаемое поведение + где смотреть |
| «Как в идеальном приложении» | палитра, CPM-формула, IDLE_CAP |
| «И заодно перепиши архитектуру» | запрет рефакторинга вне задачи |
| Десять фич в одном сообщении | очередь этапов 0→12 |

### Мини-шаблон на каждый день

```text
Контекст: <1–2 предложения о проекте и стеке>.
Задача: <один результат для пользователя>.
Файлы: <список или «найди сам, но не трогай X»>.
Готово когда: <тест / ручной шаг>.
Не делать: <явный анти-scope>.
```
