# Читалка с озвучкой — план работ (Орион, 2026‑10‑19)

Цель: читалка, которая читает вслух **без ограничения на объём** и ведёт место чтения —
как системная озвучка в телефоне, только на борту и без оплаты за символы.

Не путать с Орионом: Орион — собеседник, читалкин голос ему не подчиняется. Читалка умеет
работать без агента и без интернета.

озвучки. Не хватает трёх вещей — движка, не привязанного к английскому; очереди «предложение
за предложением»; подсветки и автопереворота.

## 2. Архитектура

```
text  ──►  разбивка на предложения (смещения в символах)
              │
              ▼
        очередь озвучки (ReaderQueue)          ← пауза/продолжить/стоп/скорость
              │  SAY|id|rate|text
              ▼
        движок (Engine)                        ← SAPI сегодня, espeak / edge-tts / Piper потом
              │  события START/DONE/CANCEL/ERR
              ▼
        мост в интерфейс (ReaderPage)          ← подсветка предложения, автопереворот, позиция
```

Правила:
* движок не знает про интерфейс, интерфейс не знает про PowerShell;
* у каждого предложения — свой `id` и диапазон `(start, end)` в символах текста: по нему
  рисуется подсветка и переворачивается страница;
* запас вперёд: одно предложение уже отправлено, пока звучит текущее (нет пауз между фразами);
* ошибка движка не должна ломать чтение — переход на следующий движок или тихий режим.

---

## 3. Движки: что ставим, что оставляем на потом

| Движок | Интернет | Оплата | Лимит объёма | Качество | Вывод |
|---|---|---|---|---|---|
| **SAPI / OneCore** (`System.Speech`) | нет | нет | нет | «диктор», разборчиво | **берём первым** |
| **espeak‑ng** | нет | нет | нет | робот | уже есть для Linux |
| **edge-tts** (нейронные голоса Edge: Дмитрий, Светлана) | да | нет | нет (поток кусками) | почти человек | второй по очереди |
| **Piper / Silero** (локальная нейросеть) | нет | нет | нет (модель 50–100 МБ) | близко к нейронному | третий, если пилот захочет «как в телефоне» |
| Azure / Google Cloud | да | **за символы** | лимиты биллинга | эталон | не берём |

Переключение — в настройках читалки, без переделки кода: `Engine` — тонкий интерфейс
(`start(seg_id, text, rate)`, `stop()`, `voices()`, `alive()`).

## 4. Задачи

### R‑01. Слой движков и перенос английского протокола на общий
* Обобщить `stamina/english/tts.py` в `stamina/voice/engine.py`: `Engine` (интерфейс),
  `SapiEngine` (Windows, PowerShell‑воркер, выбор языка — параметр, а не жёсткий `en-*`),
  `EspeakEngine` (Linux).
* `stamina/voice/tts.py` оставить для реплик Ориона, но перевести его на `SapiEngine`.
* Тест: `tests/test_voice_engine.py` — выбор голоса по языку, разбор событий, стоп/отмена.

### R‑02. Очередь предложений
* `stamina/voice/reader_tts.py`: `ReaderQueue(text, engine)` → сегменты `(id, start, end, text)`,
  запас вперёд 1–2 предложения, `play/pause/resume/stop/set_rate/set_voice`,
  `jump_to(char)` (начать с места), `poll()` для интерфейса.
* Пропуск служебного: переводы строк, номера страниц, «Project Gutenberg»‑хвосты (по желанию).
* Тест: `tests/test_reader_tts.py` на моковом движке — порядок сегментов, пауза/продолжение,
  прыжок в середину, остановка на конце.

### R‑03. Подсветка и автопереворот в читалке
* `stamina/speedread/book_reader.py`: к текущему сегменту — фон/подчёркивание строки
  (у нас есть `_wrap_para_offs` — диапазоны строк уже в символах);
* когда `end` сегмента выходит за страницу — `_goto_char` на начало следующего предложения;
* кнопки на нижней панели: ▶ / ❚❚ / ■, скорость (−/+), голос, «читать с этого места»;
* горячие клавиши: `Space` — пауза, `Esc` — стоп.

### R‑04. Настройки читалки
* В `storage.py` / `app.json`: `reader_tts` = `{engine, voice, rate, auto_turn, highlight, sleep_min}`.
* Раздел «Настройки → Читалка» с предпрослушиванием голоса.

### R‑05. Озвучка из Ориона (закрывает долг пункта 5 в `_orion/tasks.md`)
* `stamina/orion_screen.py:943–948` — сейчас озвучивается только «Читаю: {название}».
  Подключить `ReaderQueue` и открыть читалку на позиции Ориона.
* Голос Ориона и голос книги — разные: Орион коротко комментирует, книга читается.

### R‑06. Закладки и заметки
* Хранение рядом с позицией: `session.json` → `marks: [{char, note, ts}]`;
* панель закладок в читалке, переход, удаление, экспорт в Markdown.

### R‑07. Поиск по книге
* Поиск по `original` (не по подготовленному тексту), список вхождений с контекстом,
  переход к месту, счётчик «найдено N».
* Для двуязычных книг — поиск по обеим сторонам.

### R‑08. Прогресс и время
* Полоса «прочитано», «осталось ≈ N минут» (есть константа `WPM_ESTIMATE = 230`),
  журнал сеансов чтения и вклад в общую статистику пилота (`stamina/pilot_stats.py`).

### R‑09. Движки «как в телефоне» (по желанию пилота)
* `EdgeEngine` — библиотека `edge-tts` (pip, интернет), стриминг в тот же протокол.
* `PiperEngine` — локальные модели, скачивание по кнопке, хранение в `<корень данных>/voices/`.
* Проверка: «Прочитать главу целиком без остановок» на каждом движке — отчёт о времени и сбоях.

## 5. Порядок

1. **R‑01 → R‑02 → R‑03 → R‑04** — читалка читает вслух, ведёт место, не спотыкается. Это и есть
   «классная читалка» в первом приближении.
2. **R‑05** — заодно закрывает известный долг Ориона.
3. **R‑06 → R‑07 → R‑08** — закладки, поиск, прогресс.

## 6. Проверка

```
python -m pytest tests -q
python tools/i18n_check.py
```

Плюс ручной прогон: книга на 300+ страниц, чтение вслух не меньше 30 минут подряд,
пауза на 10 минут с последующим продолжением с того же предложения, автопереворот,
смена движка и голоса на ходу.
