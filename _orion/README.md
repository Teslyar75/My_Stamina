# _orion — рабочая зона вне книги

Здесь живут темы нашего общения, которые **не относятся к рукописи**. Книжный рабочий блок — отдельно, в `MyBook/_orion/`.

## Правило номер один

**Это локальная зона.** Всё, что здесь лежит, на GitHub не уходит: папка исключена в корневом `.gitignore` строкой `_orion/`. Ни корабельный репозиторий, ни книжный её не видят.

## Что здесь

| Файл | О чём |
|---|---|
| `topics.md` | индекс тем: что обсуждалось, где лежит, чем кончилось |
| `ship.md` | Star Typing: техника, баги, незакрытые задачи, идеи по кораблю |
| `personal.md` | личное: путь, рефлексия, то, что не для чужих глаз |

## Чего здесь не должно быть

- рукописи и материалов книги — им место в `MyBook/`;
- секретов и токенов в открытом виде: это локальная папка, но не сейф;
- дублей: если тема выросла в документ книги, её место там, а здесь остаётся только ссылка.

## Как пополняется

Разговор → короткий конспект в подходящий файл → строка в `topics.md`. Не наоборот: индекс ведём всегда, иначе через месяц здесь будет свалка.

## Служебное

Проверка, что зона закрыта: `git status --ignored` в корне корабля должен показывать `_orion/` как ignored.
