# Документация (Ctrl+8) — руководство пилота

Документы хранятся в папке пилота `documents/` (формат `.stdoc`), сохраняются сами.
Справка «?» в отсеке показывает все кнопки и клавиши на текущем языке.

## Набор и оформление

| Что набрать | Кнопка / клавиши | Что получится |
| --- | --- | --- |
| `**текст**` | **B**, Ctrl+B | жирный |
| `*текст*` | *I*, Ctrl+I | курсив |
| `# Заголовок`, `## Подзаголовок` | H1 / H2 | заголовки |
| `- пункт`, `1. пункт` | Ctrl+Shift+8 / 7 | списки (Enter продолжает) |
| `- [ ] дело` | ☐, Ctrl+Shift+X | задача; щелчок по `[ ]` — `[x]` |
| `==текст==` | ==, Ctrl+Shift+H | выделение маркером |
| `\| a \| b \|` | ▦, Ctrl+Shift+T | таблица |
| — | ☰, Ctrl+Shift+O | оглавление: переход к заголовку |
| — | 👁, Ctrl+Shift+M | наглядный режим |

**Наглядный режим** прячет значки `**`, `#`, `==` и т. п. везде, кроме строки с курсором.
Ограничения: в таблицах и ссылках значки видны всегда; поиск находит и спрятанный текст —
строка с находкой раскрывается.

## Вставка, картинки, печать

- **Ctrl+V** — из браузера и Word текст приходит с оформлением (жирный, курсив, заголовки, списки, ссылки);
  **Ctrl+Shift+V** — только текст. Обе вставки отменяются одним Ctrl+Z.
- **Картинки** — Ctrl+V со снимком, скрин или файл. Ширину меняйте, потянув за правый нижний угол
  (курсор-уголок) или правым кликом; Ctrl+Z вернёт прежний размер.
- **Ctrl+P** — печать: документ собирается в PDF и открывается в просмотрщике (если PDF недоступен — HTML в браузере).
- **ЭКСПОРТ** — .md, .docx, .html (с оглавлением от трёх заголовков), .pdf, .txt. В .md ширина картинок
  сохраняется (`<img width>`) и читается обратно при открытии. Маркер в PDF печатается обычным текстом.

## Шаблоны, версии, корзина

- **▾** рядом с «+ НОВЫЙ» — новый документ из шаблона: заметки встречи, список дел, конспект книги,
  дневник, таблица.
- **🕘 Версии** — прежние состояния текущего документа (снимок не чаще раза в 10 минут, хранятся последние 20,
  в `documents/.versions/`). «ВЕРНУТЬ ЭТУ» сначала сохраняет нынешний текст тоже версией.
- **🗑 Корзина** — «УБРАТЬ» кладёт документ в `documents/.trash/` (одноимённые не затирают друг друга);
  оттуда — «ВЕРНУТЬ» или «УДАЛИТЬ НАСОВСЕМ» (с подтверждением).

## Малый экран

На 1024×600 и меньше лента компактная: редкие кнопки (цитата, код, таблица, оглавление, отмена/повтор, 👁) уходят
в меню «⋯», клавиши работают всегда. **Фокус O (Щ)** — редактор на всё окно, Esc — обратно.
