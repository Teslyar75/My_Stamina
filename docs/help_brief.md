# Бриф: тексты справки F1 / «?»

Каркас уже в коде. Нужно **только заменить заглушки** `TODO …` в JSON на готовые русские тексты. Идентификаторы (`id`), структуру файлов и набор полей не менять. После вставки текстов — тихая полная сюита, пуш ветки, русский PR, мерж по зелёному CI (это следующий заход, не сейчас).

## Формат JSON

Кодировка UTF-8, `ensure_ascii: false`, отступ 2 пробела. Схема одного файла:

```json
{
  "game": "docker_trainer",
  "overview": {
    "id": "overview",
    "title": "DOCKER ТРЕНАЖЁР · ДОК-СТАНЦИЯ",
    "goal": "что нужно сделать (цель)",
    "purpose": "зачем эта игра / этот режим",
    "interface": "панели, кнопки, индикаторы, клавиши",
    "steps": ["шаг 1", "шаг 2"]
  },
  "levels": [
    {
      "id": "mission_1",
      "title": "Миссия 1: Первые шаги",
      "goal": "…",
      "purpose": "…",
      "interface": "…",
      "steps": ["…"]
    }
  ]
}
```

Показ в оверлее (и в модалке Ориона):

1. **Что нужно сделать** — поле `goal`, затем нумерованный список из `steps`.
2. **Зачем эта игра** — поле `purpose`.
3. **Интерфейс** — поле `interface`.

`title` идёт в шапку карточки. Для обзора в подвале оверлея есть переключатель «Обзор» / «К уровню».

Заглушки сейчас уникальны: `TODO <game> <id> <поле>`, например `TODO docker_trainer mission_1 goal`. Можно искать по `TODO` и заменять значения, не трогая ключи.

## Как открывается справка

- Lounge: кнопка «?» в шапке `GameShell` и F1. Пока открыто, игра на паузе (снимается при закрытии, если паузу поставила справка). Esc / F1 / повторный «?» закрывают. Глобальный `bind_all`/`unbind_all` Escape не используется. F1 с лобби Lounge не дублируется (`screen.on_key` его не форвардит).
- Docker / VIM / Терраформер: оверлей текущего уровня; «Обзор» в подвале карточки.
- Змейка / Тетрис / Арканоид: только обзор игры.
- Орион (Мостик / Полёт): **та же** модалка `page_help.PageHelpDialog` (не второй оверлей). F1 / «?» в кабине. При `bridge.meta["mode"]=="mission"` в начало тела вставляются обзор + текущая миссия из `orion.json`. Shift+F1 (голос гида) не трогали.

## Docker · Док-станция

Песочница команд (не настоящий Docker): `run`, `ps`, `logs`, `stop`, `rm`, `images`, `pull`, `build`, `port`, `volume ls/create/rm`, `network ls/create`, `compose up/down/ps`, `system prune`. Образы: `ship/radio` (8080), `ship/orion` (9000), `ship/lab` (8888), `ship/scanner` (7777), `ship/base` (5432). После миссии 8 — `sandbox_mode`.

Экран: шапка (название, счёт/XP, рекорд), кнопки Пауза / Заново / В лобби / «?», подсказка справа, холст-терминал (вывод + строка ввода), снизу статус текущей миссии, точки прогресса 1–8. Клавиши: Enter выполнить, ↑/↓ история, Tab автодополнение, Backspace, Ctrl+L очистить, Ctrl+C сбросить ввод, F1 справка, Esc пауза (или закрыть справку).

## VIM · Учи команды

12 уроков (`lesson_idx`). Курсор на поле — `@`. Цель урока задана `target` + `hint`. Esc в VIM — выход в NORMAL; **когда справка открыта, Esc закрывает её** и в редактор не уходит.

Экран: шапка и кнопки как у всех Lounge, холст с текстом урока и курсором, строка статуса «Урок N/12», точки уроков, сообщение-подсказка, набор клавиш урока.

| id | title | Клавиши и задание |
|---|---|---|
| overview | VIM ТРЕНАЖЁР · УЧИ КОМАНДЫ | Зачем тренажёр, нормальный/вставка, как устроен экран, F1/«?». |
| motion_basic | Урок 1: Базовые движения | `h j k l`. Дойти `@` до правого края строки клавишей `l`. |
| motion_word | Урок 2: Словесные движения | `w b e`. Посетить начала (w) и концы (e) слов. |
| motion_line | Урок 3: Строчные движения | `0 ^ $` на каждой из трёх строк. |
| delete_char | Урок 4: Удаление символов | `x` под курсором, `X` перед ним. Удалить буквы первой строки. |
| delete_word | Урок 5: Удаление слов | `dw db de`. Удалить слова первой строки через `dw`. |
| delete_line | Урок 6: Удаление строк | `dd` целая строка, `D` до конца. Удалить 2-ю и 3-ю строки `dd`. |
| change_mode | Урок 7: Режим вставки | `i` до курсора, `a` после, `o` строка ниже, `O` выше. Три вставки: i, a, o; Esc → NORMAL. |
| change_operator | Урок 8: Оператор изменения | `cw cb ce cc C`. Заменить `this word` на `it` (`cw`), вторую строку целиком (`cc`). |
| visual_mode | Урок 9: Визуальный режим | `v` символы, `V` строки, затем `d/y/c`. Выделить `this text` и удалить; затем строку 2 (`V+d`). |
| search_replace | Урок 10: Поиск и замена | `/ n N * # :s`. Найти три вхождения `vim` (`/vim`, два раза `n`). |
| undo_redo | Урок 11: Отмена и возврат | `u` и `Ctrl+r` (отмена изменения, не движения). Изменить, `u`, затем `Ctrl+r`. |
| repeat_count | Урок 12: Повторители (каунтеры) | `5j 3dw 2dd 10x`. С нижней строки: `5k`, затем `3l`. |

## Терраформер

Этап справки = `stage_{get_language_level()}` (0–5), уровень языка — максимум прогресса английского и немецкого пилота, не номер «уровня карты». Существующая общая инструкция `_draw_help` / `help_sections()` сохранена в коде как запас, на F1 больше не показывается — её факты стоит перенести в `overview`.

Экран: левая панель ~230px (учебная смена, грунт, фундамент, находки, масштаб, список платформ, «Прогресс языка», шкала 6 сегментов, «Открыто…», «След. уровень…», подсказка галереи), поле, подсказка клавиш. Управление: WASD/стрелки, Пробел копать, E уложить блок, Q находки, B план постройки, G галерея (стрелки листают, Space/Enter — 2D/3D), F1/«?» справка, Esc закрывает оверлей или пауза. Улучшения (показывать локализованные имена, не raw id): пресс для грунта, автовыгрузка, очистка воды, усилитель добычи, дистанционное управление, логистическая сеть, автостроитель, ядро терраформирования.

|---|---|---|
| overview | ТРЕНАЖЁР ТЕРРАФОРМЕРА | Цель смены, зачем копать/строить, связь с прогрессом языка, весь интерфейс и клавиши. |

| stage_2 | Этап 2 · Робот A2, автовыгрузка и очистка воды | Варианты 0–2, роботы A1+A2, ещё `auto_unloader`, `water_purifier`. A2 копает глину и металл. |
| stage_3 | Этап 3 · Робот A3, усилитель добычи | + A3 (автономная добыча), `yield_booster` (+50%), `remote_control`. |
| stage_4 | Этап 4 · Робот A4, логистика и автостроитель | + A4 (строит платформы), `logistics_network`, `auto_builder`. |

## Орион (мостик)

20 тренировок набора: одни и те же названия у `ru-*` и `en-*`, разный набор клавиш и текст. Поле `goal` в коде миссии — число знаков (цель объёма), не путать с полем `goal` в JSON справки. Текущая миссия: `app.screens["bridge"].meta["mission"]` (словарь с `id`) при `mode=="mission"`.

Экран мостика (описать в `interface`): полоса миссии (название, подзаголовок), поле набора, тепло клавиатуры, скорость/точность/время, старт, пауза, разбор полёта, список миссий, F1/«?» в шапке кабинета, Alt+1–5 — отсеки. Не описывать Shift+F1 как закрытие справки (это голос гида).

## Простые игры (только обзор)

- `snake` — Змейка: направление, рост, не врезаться, счёт/рекорд, Пауза / Заново / В лобби / «?», Esc/P пауза, R заново.
- `tetris` — Тетрис: фигуры, поворот, линии, те же кнопки оболочки.
- `breakout` — Арканоид: платформа, мяч, блоки, те же кнопки оболочки.

Точные клавиши сверь по подсказке в шапке каждой игры, если будешь расписывать `interface`.

## Проверка после вставки текстов

Из `D:\Star_Typing_games`, интерпретатор `D:\Star_Typing\.venv\Scripts\python.exe` (дерево Star_Typing не менять):

```
$env:STAR_TYPING_SILENT="1"
# conftest и так ставит STAR_TYPING_SILENT=1
python -m pytest -q tests/test_lounge_help.py tests/test_docker_sim.py
```

Тесты каркаса требуют: все id на месте, поля непустые, тексты внутри пакета уникальны, хуки F1/«?» на месте, Орион подмешивается в ту же модалку. Когда заглушки сменятся живыми текстами, уникальность и непустота должны сохраниться.
