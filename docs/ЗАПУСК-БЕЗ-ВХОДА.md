# Быстрый запуск без экрана входа

Обычный ярлык (`main.py` без аргументов) идёт через окно входа: создаётся первое
окно Tk, затем оно уничтожается и строится кабина во втором окне. После такого
перехода кабина иногда уходит в бесконечный пересчёт раскладки (100 % CPU,
окно не отвечает).

Рабочий способ — не создавать окно входа вовсе.

## Команда

```
"C:\Users\mi\AppData\Local\Programs\Python\Python314\pythonw.exe" "D:\My_New_Stamina\_bypass.py"
```

Рабочая папка не важна: `_bypass.py` сам добавляет папку проекта в `sys.path`.

## Что делает `_bypass.py`

```python
pilot_screens.ask_pin = lambda *a, **k: True   # без запроса кода
app.run_app(["--pilot", "p-20261009-4fa9"])    # сразу кабина пилота
```

Экрана входа и диалога кода нет — кабина строится в чистом окне, как при моих
проверках, когда всё работает.

## Ярлык на рабочем столе

- Имя: `Star Typing (без входа).lnk`
- Объект: `C:\Users\mi\AppData\Local\Programs\Python\Python314\pythonw.exe`
- Аргументы: `"D:\My_New_Stamina\_bypass.py"`
- Рабочая папка: `D:\My_New_Stamina`
- Значок: `D:\My_New_Stamina\stamina\assets\star_typing.ico`

Создать такой же ярлык из PowerShell:

```powershell
$ws = New-Object -ComObject WScript.Shell
$path = "C:\Users\mi\OneDrive\Рабочий стол\Star Typing (без входа).lnk"
$sc = $ws.CreateShortcut($path)
$sc.TargetPath = "C:\Users\mi\AppData\Local\Programs\Python\Python314\pythonw.exe"
$sc.Arguments = '"D:\My_New_Stamina\_bypass.py"'
$sc.WorkingDirectory = "D:\My_New_Stamina"
$sc.IconLocation = "D:\My_New_Stamina\stamina\assets\star_typing.ico"
$sc.Description = "Star Typing — сразу в кабину, без экрана входа"
$sc.Save()
```

## Что ещё нужно починить

Настоящая причина — не сам вход, а то, что кабина иногда (через 15–20 с после
старта) уходит в бесконечную перерисовку текста. Журнал для разбора:

- `%APPDATA%\Stamina\start.log` — старт, окна, замирания главного потока;
- `%APPDATA%\Stamina\stall.log` — стек главного потока в момент замирания;
- `%APPDATA%\Stamina\pilots\` — настройки пилота (`living_space`, `stars` и т. д.).

Пока проверенный обход — запуск через `_bypass.py`.
