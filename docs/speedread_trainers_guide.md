# Руководство по тренажёрам Скорочтения (Speedread)

> Вкладка **СКОРОЧТЕНИЕ → ТРЕНАЖЁРЫ**. 9 тренажёров: 1 режим чтения (RSVP) + 8 упражнений для расширения поля зрения, устранения проговаривания и тренировки саккад.

---

## 🎯 Как начать

1. Открой вкладку **СКОРОЧТЕНИЕ** (в главном меню)
2. Перейди на вкладку **ТРЕНАЖЁРЫ** (4-я плитка)
3. Выбери любой тренажёр — карточка покажет лучший результат (есть ли он)
4. Нажми **«СТАРТ»** или просто кликни по карточке

Прогресс (лучшее время/точность/XP) сохраняется в `speedread.json` и виден на карточках.

|-----|----------|-----|---------------|------------|

## ⌨️ Общие клавиши

| Клавиша | Действие |
|---------|----------|
| `Esc` | Выход из тренажёра в каталог |
| `R` / `К` (рус.) | Перезапуск / новый раунд (в большинстве) |
| `Space` | Пауза (в E-PCR) |
| `↑/↓` | Изменить WPM (в E-PCR) |

## 📖 Подробное описание каждого тренажёра

---

### R-HYP — Гипердрайв (RSVP)

**Суть:** Слова показываются по одному в центре экрана с фиксированной скоростью. Одна буква в каждом слове подсвечивается красным — на неё нужно фокусироваться.

**Настройки:** WPM (слов в минуту), длина серии, пауза на пунктуации.

**Метрика:** WPM, процент понимания (квиз после серии).

**Научная база:** RSVP (Rapid Serial Visual Presentation) — классический метод скорочтения, убирает саккады и регрессии. Красная буква (Optimal Recognition Point) ускоряет распознавание.

---

### E-SHL — Таблица Шульте

**Суть:** Сетка 3×3 … 7×7 с числами (или буквами) в случайном порядке. Нужно кликать по ним по порядку: 1 → 2 → 3… максимально быстро.

**Варианты:** `3x3`, `4x4`, `5x5`, `6x6`, `7x7` — выбирается на старте.

**Метрика:** Время прохождения (сек). Чем меньше — лучше.

**Научная база:** Оригинальная таблица Шульте (1978) для тренировки периферического зрения и скорости поиска. Используется в спортивной психологии и пилотировке.

---

### E-GRB — Таблица Горбова (Горбова — Шульте)

**Суть:** Две перекрывающиеся таблицы: чёрные числа 1→N (возрастают) и красные N→1 (убывают). Нужно чередовать: чёрное 1, красное N, чёрное 2, красное N-1…

**Варианты:** те же размеры сетки.

**Метрика:** Время прохождения (сек).

**Научная база:** Модификация Шульте для тренировки переключения внимания и рабочей памяти. Требует удерживать две последовательности одновременно.

---

### E-PYR — Пирамида

**Суть:** Текст показывается «клином» — сначала узкий столбец по центру, потом расширяется. Нужно читать, не двигая глазами, захватывая всё поле зрения.

**Настройки:** Начальная ширина (знаков), шаг расширения, скорость.

**Метрика:** Максимальная ширина клина (знаков), которую удалось прочитать без ошибок.

**Научная база:** Метод расширения поля зрения (span) — тренирует способность воспринимать больше слов за одну фиксацию.

---

### E-TAC — Вспышка (Тахистоскоп)

**Суть:** Слово (или фраза) мелькает на экране 50–300 мс, затем маска (`#####`). Нужно ввести увиденное. Лестница: 3 верных подряд → время −20 мс, ошибка → +20 мс.

**Раундов:** 15.

**Метрика:** Лучшее время показа (мс) и длина слова/фразы.

**Научная база:** Тахистоскопическое представление — классический метод измерения порога распознавания и тренировки мгновенного чтения.

---

### E-FND — Поиск слов (НОВЫЙ)

**Суть:** На экране сплошной текст (~200 слов). 8 целевых слов подсвечены жёлтым. Нужно найти и кликнуть по каждому. Таймер стартует на первом клике.

**Раунд:** один текст — 8 целей.

**Метрика:** Время поиска всех 8 слов (сек).

**Научная база:** Сканирование текста (scanning) — навык быстрого поиска информации без полного чтения. Используется в speed reading для превью и поиска ответов.

**Совет:** Не читай всё — сканируй miradaми, ищи знакомые формы слов.

---

### E-GAP — Пропущенные буквы (НОВЫЙ)

**Суть:** Слово показывается с пропусками (`п р и в е т → п ▢ и ▢ е ▢`) на 600 мс, затем маска. Нужно ввести полное слово. 12 раундов.

**Метрика:** % верных + среднее время реакции (мс). Оценка: верных ×1000 − ср. мс.

**Научная база:** Топ-даун обработка / предвосхищение (prediction). Мозг восстанавливает слово по контексту и частичным признакам — основа плавного чтения.

**Совет:** Не гадай буквы — угадывай слово целиком по форме и контексту.

---

### E-EYE — Глазодвигатель / Саккады (НОВЫЙ)

**Суть:** В центре — красная точка фиксации. Через случайную задержку (500–1500 мс) появляется жёлтая мишень в случайном месте (радиус 25–40% экрана). Нужно кликнуть по ней максимально быстро. 20 раундов.

**Метрика:** % попаданий + средняя латентность саккады (мс). Оценка: попаданий ×1000 − ср. мс.

**Научная база:** Тренировка саккад — быстрых движений глаз между фиксациями. В чтении саккады занимают ~10% времени, но их точность определяет, попадёшь ли в следующее слово или перескочишь/пропустишь.

**Совет:** Держи фокус на красной точке до появления мишени — тренируй периферийное восприятие.

---

### E-PCR — Указка / Пейсер (НОВЫЙ)

**Суть:** Жёлтая пунктирная линия движется сверху вниз через текст заданной скоростью (WPM). Читай за линией — не возвращайся назад. Space — пауза, ↑/↓ — изменить WPM.

**Метрика:** Реальный WPM (прочитанных слов/мин), отклонение от цели, строк пройдено.

**Научная база:** Пейсер (pacer) — классическая техника скорочтения (палец, ручка, указатель). Внешний ритм подавляет регрессии (обратные саккады) и проговаривание.

**Совет:** Начни с комфортного WPM (+20–30% от обычной скорости). Не стопорись на непонятном — двигайся дальше.

---

## 📊 Система оценки (звёзды и XP)

Все тренажёры выдают **1–3 звёзды** и **XP** за раунд:

- ⭐⭐⭐ — отличный результат (рекорд или близко)
- ⭐⭐ — хороший
- ⭐ — есть прогресс
- ☆☆☆ — первый раз / пробный запуск

XP накапливается в профиле скорочтения. Рекорды отмечаются значком **«НОВЫЙ РЕКОРД!»**.

## 🎯 Рекомендуемая схема тренировки

| Этап | Тренажёры | Время | Цель |
|------|-----------|-------|------|
| **Разогрев (2–3 мин)** | E-SHL (3×3) → E-EYE | 2–3 мин | «Разогнать» глаза, саккады |
| **Поле зрения (3–5 мин)** | E-PYR → E-GRB (4×4) | 3–5 мин | Расширить span, переключение внимания |
| **Скорость распознавания (2–3 мин)** | E-TAC → E-GAP | 2–3 мин | Мгновенное чтение, топ-даун |
| **Сканирование (2 мин)** | E-FND | 2 мин | Поиск в тексте |
| **Темп чтения (5–10 мин)** | E-PCR → R-HYP | 5–10 мин | Перенос на реальное чтение |

**Итого:** 15–20 минут перед основной сессией чтения.

## ⚙️ Настройки (Speedread → ⚙️ Настройки)

- **Язык тренажёров** — отдельно для каждого (EN/DE/ES/FR/IT/русс.), берёт слова из активной книги или встроенных списков
- **WPM по умолчанию** — для R-HYP и E-PCR
- **Размер сетки** — для Шульте/Горбова
- **Время вспышки** — для E-TAC
- **Звуки / озвучка** — клики, конец раунда

## � Известные ограничения

- E-PCR: прокрутка текста привязана к строкам, нет плавного пиксельного скролла
- E-FND / E-GAP: пул слов берётся из активной книги или встроенного `FLASH_WORDS` (EN/DE/ES/FR/IT/RU)
- E-EYE: мишени только круговые, нет вариаций формы/цвета
- Нет мультиязычного квиза после R-HYP (только EN/русс. вопросы в `quiz.py`)
