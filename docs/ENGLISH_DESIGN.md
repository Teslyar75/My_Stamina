# Вкладка «АНГЛИЙСКИЙ»: визуальный стиль

> Документ писался для первой (веб-)версии модуля; сейчас модуль — вкладка внутри Star Typing на Tkinter, но правила стиля те же. Устройство вкладки: [ENGLISH_TAB.md](ENGLISH_TAB.md).

Стиль **один к одному** взят из Star Typing: та же палитра, те же шрифты, те же рамки, кнопки и приборы. **Новых цветов и шрифтов не вводить.** Если нужного элемента в Star Typing нет, он собирается из существующих токенов и компонентов.


## 1. Концепция

Пользователь — пилот, который учит язык на борту. Каждый экран — отдельный пульт: тёмный космос, тонкие неоновые рамки со срезанными углами, циановые показания приборов, янтарь для внимания и наград. Текст на английском — это «принятый сигнал», он всегда крупнее и ярче служебных надписей.

**Принципы:**
1. **Сначала содержание.** Слово, предложение или вопрос — самый крупный и контрастный элемент экрана. Декор не спорит с ним.
2. **Приборы вместо цифр в тексте.** XP, серия и точность показываются шкалами, кольцами и табло.
3. **Спокойно и легко.** Анимаций мало, они короткие и отключаются (§7). Ноутбук с 8 ГБ ОЗУ не должен шуметь вентилятором.
4. **Интерфейс по-русски, служебные заголовки КАПСОМ** с разрядкой (как в Star Typing: «НАВИГАЦИОННЫЙ КАНАЛ», «ТЕЛЕМЕТРИЯ»).

## 2. Цвета (токены)

Значения **скопированы из `stamina/theme.py` Star Typing без изменений**; имя CSS-переменной = имя константы в `theme.py` (`BG` → `--bg`, `CYAN_DIM` → `--cyan-dim`). Задаются в `src/styles/tokens.css`; в коде используются только переменные. Кроме этих токенов в Star Typing есть только `#FFFFFF` (текст нажатой кнопки). Промежуточные оттенки получаются смешиванием двух токенов, как функция `blend()` в `theme.py`: в CSS — `color-mix(in srgb, A p%, B)`.

| Токен | Значение | Назначение |
|---|---|---|
| `--bg` | `#03060C` | фон, глубокий космос |
| `--bg-2` | `#060C17` | второй слой фона, пустые сегменты шкал |
| `--panel` | `#081221` | заливка панелей |
| `--panel-hi` | `#0D1C33` | наведение, активная панель |
| `--line` | `#15314D` | тонкие рамки, разделители |
| `--line-hi` | `#1F4F7A` | рамка панели |
| `--cyan` | `#00E5FF` | основной акцент: активное, показания, ссылки, фокус |
| `--cyan-dim` | `#0B7285` | приглушённый акцент (только крупные элементы и декор) |
| `--cyan-deep` | `#06303B` | заливка выбранного |
| `--amber` | `#FFB000` | внимание, текущая цель, XP, звёзды, звание |
| `--amber-dim` | `#7A5300` | рамка «в процессе» |
| `--red` | `#FF3B5C` | ошибка, запись микрофона |
| `--red-dim` | `#5E1426` | фон ошибки |
| `--green` | `#3DFF8A` | правильно, «Знаю», миссия выполнена |
| `--green-dim` | `#155E36` | рамка пройденного |
| `--purple` | `#B76BFF` | редкое: достижения, «Трудное» |
| `--text` | `#D6F4FF` | основной текст |
| `--muted` | `#6F90AB` | подписи, второстепенный текст |
| `--faint` | `#2B4762` | только декор и недоступные элементы, не для текста |

**Смысловые цвета:** сложность слова: Лёгкое `--green`, Среднее `--cyan`, Трудное `--amber`. Статус сектора (набора): не начат — `--line-hi`, в процессе — `--amber`, пройден — `--green`. Тепловая карта бортжурнала — переход `--green-dim → --amber → --red`, как `heat_color()` в Star Typing.

**Светлой темы нет:** в Star Typing её нет, а дизайн повторяет его один к одному. Переключатель темы из спецификации §9 не делается.

## 3. Шрифты (без интернета)

Тот же выбор, что в `theme.init()` Star Typing: первый установленный из списка, только системные шрифты, ничего не загружается.

```css
--font-hud:  "Bahnschrift", "Segoe UI", "DejaVu Sans", "Helvetica", sans-serif;
--font-mono: "Cascadia Mono", "Consolas", "DejaVu Sans Mono", "Courier New", monospace;
```

Размеры задаются **в pt, как в Star Typing** (`theme.font(size)` — это pt в Tk), поэтому в CSS пишем те же числа с единицей `pt`. На 125% масштабе Windows браузер масштабирует их так же, как `theme.px()`.

| Роль | Как в Star Typing | CSS |
|---|---|---|
| Служебный заголовок панели КАПСОМ | заголовок `HudPanel`, `SegmentBar` | hud, bold, 9 pt |
| Мелкие подписи, кнопки-подсказки | `font(8)` / `font(8, True)` | hud, 8 pt |
| Основной текст интерфейса, кнопки | `HudButton` | hud, bold, 10 pt |
| Значения табло | `Readouts`, `SegmentBar` | mono, bold, 10–15 pt |
| Заголовок экрана / полосы миссии | `MissionStrip` | hud, bold, 14 pt |
| Крупные показания (кольцо, спидометр, итог) | `RingGauge`, `SpeedGauge`, отчёт о полёте | mono, bold, 17–22 pt |
| Заголовок отчёта «МИССИЯ ВЫПОЛНЕНА» | `show_debrief` | hud, bold, 20 pt |
| Слово на сканере, слово в задании | слово в `TranslatorPanel` | hud, bold, 22 pt; на сканере mono, bold, 40 pt |
| Перевод слова | `TranslatorPanel` (`_f_word_tr`) | hud, bold, 26 pt |
| Предложение для практики | строка `Viewport` (иллюминатор) | mono, 26 pt; изучаемое слово `--cyan` |
| Перевод предложения | `TranslatorPanel` (`_f_tr`) | hud, 18 pt |
| Транскрипция `[ LEE-der ]`, IPA | — | mono, 22 pt / 15 pt, `--cyan` |

## 4. Компоненты

Папка `src/components/hud/`. Каждый — небольшой React-компонент со своим CSS-модулем. Имена повторяют классы Star Typing (`hud.py`, `bridge.py`), чтобы было легко сравнивать.

### 4.1 Рамки и кнопки
- **`HudPanel`** — панель со срезанными углами (левый верхний и правый нижний, 12 px), рамка `--line-hi`, заливка `--panel`. На двух углах короткие акцентные засечки (40×2 px по горизонтали, 22×2 px по вертикали) цвета `accent` (по умолчанию `--cyan`). Необязательный заголовок КАПСОМ в левом верхнем углу и «статус» справа (например, «✓ ПРИНЯТО» зелёным).
  Реализация: `clip-path: polygon(12px 0, 100% 0, 100% calc(100% - 12px), calc(100% - 12px) 100%, 0 100%, 0 12px)` на двух слоях: внешний с фоном цвета рамки и внутренний с отступом 1 px и фоном панели. Засечки — `::before`/`::after`. Без SVG и без `filter`.
- **`HudButton`** — кнопка со срезанными углами (8 px). Состояния, как в `HudButton._draw()`: обычная (заливка `--panel`, рамка — акцент на 50%, текст — акцент с примесью белого), наведение (заливка — акцент на 12%, рамка — акцент, текст `--text`, засечка 14×3 px сверху слева), активная (заливка — акцент на 22%, рамка 2 px), нажатая (заливка — акцент на 45%, текст белый), недоступная (`--faint`). Варианты цвета: `cyan` (обычные), `amber` (главное действие экрана, например «ЗАПУСТИТЬ»), `green` («ДАЛЕЕ»), `red` (запись, сброс). Подсказка горячей клавиши справа мелким моноширинным текстом: `ПОВТОР  Enter`.
- **`HudTabs`** — навигация в шапке: ряд `HudButton`, активная вкладка подчёркнута светящейся линией `--cyan`.
- **`MissionStrip`** — полоса под шапкой: янтарная вертикальная метка, заголовок КАПСОМ («СЕКТОР TOP-1000 · ЗВЁЗДНАЯ КАРТА»), подзаголовок и справа «ПРОГРЕСС МАРШРУТА» (тонкая полоса и `219 / 1000 · 22%`).
- **`Toast`** — «СИСТЕМНОЕ СООБЩЕНИЕ»: маленькая `HudPanel` в правом нижнем углу на 4 с.
- **`DebriefModal`** — «ОТЧЁТ О ПОЛЁТЕ» (итог сессии): большой заголовок («МИССИЯ ВЫПОЛНЕНА» зелёным или «МИССИЯ ПРЕРВАНА» янтарным), звёзды, сетка показаний, «+50 XP» янтарным, ряд кнопок с горячими клавишами.

### 4.2 Приборы (HUD)
- **`RingGauge`** — кольцо: фон `--bg-2`, дуга значения, тонкая внешняя шкала с делениями, по центру число моноширинным шрифтом и подпись. Используется для **дневной цели XP** и **точности сессии**. Цвет дуги: < 50% `--red`, 50–80% `--amber`, ≥ 80% `--green` (для дневной цели всегда `--amber`).
- **`ArcGauge`** — «спидометр» (дуга 250°, стрелка, деления) как `SpeedGauge`. Используется для **уровня**: стрелка показывает долю пути до следующего уровня, по центру номер уровня.
- **`SegmentBar`** — шкала из 16 сегментов (пустые `--bg-2` с рамкой `--line`). Используется для **серии дней** (сегмент = день, последние 14 дней + сегодня мигает, если цель не набрана), «Ритма» в практике и прогресса набора на плитках.
- **`Readouts`** — колонка табло: цветная вертикальная метка, подпись КАПСОМ слева, значение моноширинным шрифтом справа (`ВРЕМЯ 03:33`, `ОШИБКИ 3`, `СЕРИЯ / ЛУЧШАЯ 4 / 12`).
- **`RankBadge`**: в шапке справа «★ ЛЕЙТЕНАНТ» янтарным и под ним `916 / 1500 XP` (XP до следующего звания), как в Star Typing. Звания и пороги XP взяты из `missions.RANKS` без изменений. Уровень из спецификации §7 показывается отдельно, в `ArcGauge`.

| Звание | С XP |
|---|---|
| Кадет | 0 |
| Пилот-стажёр | 100 |
| Мичман | 300 |
| Лейтенант | 700 |
| Капитан-лейтенант | 1500 |
| Капитан | 3000 |
| Коммодор | 6000 |
| Адмирал флота | 12 000 |

- **`StarRating`** — ★★☆ янтарными звёздами. В итоге сессии: ★ — точность ≥ 60%, ★★ — ≥ 80%, ★★★ — ≥ 95%.
- **`ClockReadout`** — часы `HH:MM` в правом верхнем углу шапки, `--cyan`, моноширинные.
- **`Starfield`** — фон из звёзд (§7).

### 4.3 Шапка (общая для всех экранов)
Слева логотип как у Star Typing (`_draw_logo()`: шестиугольник с янтарной звездой), рядом `APP_NAME` (пока «MY_ENGLISH») и подпись «ПУЛЬТ ПИЛОТА · ЯЗЫКОВОЙ ТРЕНАЖЁР». Затем `HudTabs`: **МОСТИК · ЗВЁЗДНЫЕ КАРТЫ · МИССИИ · ПРОВЕРКА СИСТЕМ (N) · БОРТЖУРНАЛ · ОТСЕКИ · НАСТРОЙКИ**. Справа: поиск (иконка, по клику раскрывается поле «СКАНИРОВАТЬ СЛОВО…»), `RankBadge`, серия «🔥 4», кнопка «♪ ЗВУК ВКЛ/ВЫКЛ», `ClockReadout`. Под шапкой тонкая светящаяся линия `--cyan`, как `_draw_line()` в Star Typing. На узком экране вкладки сворачиваются в кнопку «☰ НАВИГАЦИЯ».

## 6. Экраны

### 6.1 Мостик (главная)
- Сетка 12 колонок. Слева (8 колонок) — **«КУРС НА СЕГОДНЯ»**: `RingGauge` дневной цели, `Readouts` (к повторению, новых доступно, серия), две крупные кнопки: янтарная «▶ НАЧАТЬ ЗАНЯТИЕ» и циановая «БЫСТРАЯ МИССИЯ · 10».
- Под ним — **«СЕКТОРЫ»**: 4 плитки наборов в стиле карточек миссий Star Typing (код сектора `S-1000` в углу, название «Essential 1000», подпись «Фундамент», `SegmentBar` прогресса, «знаю 219 / 1000»). Вместо фотографий — мини-карта созвездия (CSS-точки, генерируется по seed из id набора). Рамка по статусу (§2). Плитка «Голосвязь» тусклая с меткой «⊘ СКОРО».
- Справа (4 колонки) — **«ТЕЛЕМЕТРИЯ ПИЛОТА»**: `ArcGauge` уровня, звание, `SegmentBar` серии, «слов выучено». Ниже — **«ПЕРЕХВАЧЕН СИГНАЛ»** (слово дня): слово моноширинным шрифтом, 🔊, определение, кнопка «СКАНИРОВАТЬ».
- Поиск — широкое поле «СКАНИРОВАТЬ СЛОВО…» над сеткой; результаты — выпадающая `HudPanel`.

### 6.2 Звёздная карта сектора (набор слов)
- `MissionStrip` с названием сектора и прогрессом маршрута.
- Фильтры — `HudPanel` «ПАРАМЕТРЫ СКАНИРОВАНИЯ»: переключатели — сегментированные `HudButton`, активный подсвечен. «✕ СБРОС» красным.
- Карточки слов — маленькие `HudPanel` («объекты»): `#586` моноширинным шрифтом в углу, слово, чипы POS и сложности (рамочные, цветом сложности), ⟳, «✓ ЗНАЮ» (при включении рамка карточки зелёная) и «⊞ В ОТСЕК». Переворот карточки — смена содержимого с плавным появлением (без 3D-поворота: дешевле и не мешает читать).
- Советы между карточками — панель с янтарной засечкой и заголовком «БОРТОВОЙ СОВЕТ».

### 6.3 Сканер объекта (карточка слова)
- Центр — «окно сканера»: широкая `HudPanel` со звёздным фоном. Слово крупно моноширинным шрифтом, по углам — тонкие рамки прицела (4 уголка `--cyan`). Над словом чип «ЧАСТОТНОСТЬ #586», под ним POS и теги.
- Справа от слова — кнопки 🔊 / 🐢 / HD как круглые «датчики» с подписью.
- Ниже две колонки: **«АНАЛИЗ ПРОИЗНОШЕНИЯ»** (`[ LEE-der ]` крупно, вкладки IPA / СЛОГИ / КАК ПРОИЗНОСИТЬ / ЗАМЕТКИ как `HudTabs`) и **«ДАННЫЕ ОБЪЕКТА»** (определение, пример с подсвеченным словом, «Мой перевод» — поле ввода в стиле табло, «Знаю», «В отсек», «В проверку систем»).
- Кнопки практики — ряд из 4 `HudButton` с иконками: «СЛУЧАЙНАЯ», «ГОВОРЕНИЕ», «ЧТЕНИЕ», «ВОПРОСЫ».
- Вкладка «Практика предложений» — **«КАНАЛ СВЯЗИ»**: предложение крупно, под ним кнопка микрофона — большой круг `--red` с подписью «ПЕРЕДАЧА» (во время записи пульсирует, сверху живой текст распознавания). Результат — `RingGauge` с баллом и раскрашенными словами.

### 6.4 Миссии (практика)
- Экран выбора — сетка карточек миссий как «ЗВЁЗДНАЯ КАРТА МИССИЙ» Star Typing: у каждого режима код (`M-RND`, `M-SPK`, `M-RDG`, `M-QST`), название, описание, лучший результат и ★ за последнюю сессию. Источник и длина — сегментированные переключатели над сеткой.
- Экран задания — как пульт Star Typing: сверху `MissionStrip` («МИССИЯ · ЧТЕНИЕ», `3 / 10`), в центре «НАВИГАЦИОННЫЙ КАНАЛ» с заданием, варианты ответа — крупные `HudButton` с номерами `1`–`4`. Справа узкая колонка «ТЕЛЕМЕТРИЯ»: `RingGauge` точности и `Readouts` (время, ошибки, серия). Внизу «⏸ ПАУЗА Esc», «ПРОПУСТИТЬ».
- Ответ: правильный — рамка и заливка `--green` на 0.4 с; ошибка — `--red` и короткое «дрожание» панели (2 колебания по 3 px; при reduced-motion — только цвет). Правильный вариант подсвечивается зелёным.
- Итог — `DebriefModal`.

### 6.5 Проверка систем (флеш-карточки)
- Заголовок «ПРОВЕРКА СИСТЕМ · ОСТАЛОСЬ 14». Карточка — большая `HudPanel` по центру, слово на ней — как на сканере. «Показать ответ» — янтарная кнопка «РАСШИФРОВАТЬ  Space».
- Кнопки оценки — 4 `HudButton`: «СНОВА 1» красная, «ТРУДНО 2» янтарная, «ХОРОШО 3» циановая, «ЛЕГКО 4» зелёная, под каждой интервал (`<10 мин`, `1 дн`, `6 дн`).
- Пустая очередь: «ВСЕ СИСТЕМЫ В НОРМЕ ✓» зелёным.

### 6.6 Бортжурнал (прогресс)
- Верх: `ArcGauge` уровня и звание, большие табло XP, серия, лучшая серия, «слов выучено».
- «ТЕПЛОВАЯ КАРТА ПОЛЁТОВ» — 12 недель квадратами, цвета из §2.
- Статистика по секторам — `SegmentBar` на каждый набор; точность по режимам — горизонтальные полосы.
- «ЗНАКИ ОТЛИЧИЯ» (достижения) — шестиугольные значки: полученные цветные (`--purple`/`--amber`) с датой, неполученные — контур `--faint` и условие.
- «ЖУРНАЛ ОШИБОК» — список слов с кнопкой «ПОВТОРИТЬ».

### 6.7 Отсеки (мои списки) и настройки
- Отсек — `HudPanel` с названием, числом объектов и кнопками «ПРОВЕРКА», «МИССИЯ», «ЭКСПОРТ». Внутри — та же сетка объектов, что на звёздной карте.
- Настройки — группы из спецификации §9 как отдельные `HudPanel` («ГОЛОСОВОЙ МОДУЛЬ», «ПРИЁМНИК РЕЧИ», «ПОЛЁТНЫЙ ПЛАН», «ВИД», «БОРТОВЫЕ ДАННЫЕ») + группа «ЗВУК И АНИМАЦИЯ» (§7–8). Переключатели — прямоугольные тумблеры с подписями ВКЛ/ВЫКЛ.

## 7. Анимации и нагрузка

- Длительности: наведение 120 мс, появление панелей 180 мс (`opacity` + сдвиг на 4 px), заполнение колец и шкал 400 мс `ease-out`. Анимируются только `opacity` и `transform`; `width`, `box-shadow` и `filter` не анимируются.
- **Размытого свечения нет** (в Star Typing его нет, в Tkinter нет прозрачности). «Свечение» сделано так же, как в `theme.py`: несколько тонких линий из смешанных цветов (`blend`). Пример — линия под шапкой: 1 px `--cyan` и под ней 2 px `color-mix(in srgb, var(--cyan) 40%, var(--bg))`. Без `box-shadow`-ореолов, `text-shadow`, `backdrop-filter` и `blur`.
- **`Starfield`**: по умолчанию статичный фон из 2–3 слоёв `radial-gradient` (0 нагрузки). Необязательный «Полёт» (настройка «Анимированные звёзды», по умолчанию ВЫКЛ) — один `<canvas>` на 70 звёзд (как `Viewport.STAR_COUNT` в Star Typing), 30 кадров/с, только на мостике и сканере, останавливается при скрытой вкладке (`document.hidden`).
- Мигание (сегмент «сегодня», запись микрофона) — `opacity` 1 → 0.5, период 1.2 с.
- **`prefers-reduced-motion: reduce`** или настройка «Без анимации»: все переходы 0 мс, нет дрожания, мигания и полёта звёзд; смысл передаётся цветом и значками.
- Бюджет: без изображений-фонов (кроме иконки), весь декор — CSS. Цель: первая отрисовка мостика < 1 с после загрузки данных, прокрутка карты 60 кадров/с.

## 8. Звуки (необязательно)

- Переключатель «♪ ЗВУК» в шапке и в настройках, **по умолчанию выключен**, громкость 1–4 (как `VOLUMES` в Star Typing: 25/50/75/100%).
- Те же 4 звука, что в Star Typing (они синтезированы её модулем `sounds.py`, своих лицензий нет): `click` — нажатие кнопки ответа, `error` — неверный ответ, `bell` — миссия выполнена / новое достижение, `start` — начало сессии. Скопировать из `D:\My_New_Stamina\stamina\sounds\` варианты `*_v2.wav` в `public/sounds/` (`click.wav`, `error.wav`, `bell.wav`, `start.wav`, ~60 КБ всего).
- Проигрывание — `src/services/sfx.ts`: заранее загруженные `HTMLAudioElement`, громкость из настроек. Звук эффектов никогда не играет во время озвучки (TTS) и записи микрофона.

## 9. Доступность и контраст

Контраст по WCAG (посчитан для токенов):

| Цвет текста | на `--bg` | на `--panel` | Использовать для |
|---|---|---|---|
| `--text` | 17.6 | 16.3 | любой текст |
| `--cyan` | 13.2 | 12.2 | любой текст, показания |
| `--green` | 15.3 | 14.2 | любой текст |
| `--amber` | 11.1 | 10.2 | любой текст |
| `--purple` | 6.3 | 5.9 | текст ≥ 10 pt |
| `--muted` | 6.0 | 5.6 | подписи |
| `--red` | 5.8 | 5.4 | текст ≥ 10 pt, ошибки |
| `--cyan-dim` | 3.6 | 3.4 | только крупный текст ≥ 18 pt и декор |
| `--faint`, `--line-hi` | 2.1 | 1.9 | только рамки и недоступные элементы |

- Тёмный текст `--bg` на заливке `--cyan`/`--amber`/`--green` (главные кнопки в нажатом состоянии) — контраст > 11.
- Цвет никогда не единственный признак: правильно ✓, ошибка ✗, статус сектора подписан словом.
- Фокус клавиатуры: `outline: 2px solid var(--cyan); outline-offset: 2px` на всех интерактивных элементах (срезанные углы не мешают — outline рисуется снаружи).
- Размеры текста — как в Star Typing (§3): основной 10 pt, КАПС-подписи 8–9 pt (только короткие). Учебный текст (слова, предложения) всегда крупный. Кликабельная зона ≥ 34 px по высоте (высота `HudButton`).
- Масштаб браузера до 200% не ломает вёрстку.
- Микрофон и звук имеют текстовые подписи, а не только иконки.

## 12. Итог проверки произношения: «СОВПАДЕНИЕ: N%»

Во вкладке Star Typing это виджет `MatchReadout` (`english_tab/ui.py`), показывается после каждой попытки в сканере («Канал связи») и в заданиях говорения.

- Панель со срезанным углом (`chamfer`), фон — цвет вердикта, смешанный с `PANEL` (12 %), рамка и левая полоса — цвет вердикта.
- Слева «СОВПАДЕНИЕ:» (`MUTED`, 10 pt жирный) и процент крупно (24 pt, моноширинный) цветом вердикта; справа вердикт (14 pt жирный).
- Цвет вердикта как у `RingGauge`: ≥ 85 % `GREEN` «ОТЛИЧНО», 60–84 % `AMBER` «ХОРОШО», < 60 % `RED` «ЕЩЁ РАЗ».
