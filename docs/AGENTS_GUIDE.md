# Как «заселить» своего ИИ-агента на корабль Star Typing

Свой ИИ-агент отвечает в чате Ориона текстом и голосом. Позвать его голосом можно с любого экрана:
кнопкой **«ОРИОН»** в шапке или клавишей **Home** (если курсор не в текстовом поле). Ниже — три способа
подключения. Если не знаете, с чего начать, берите **способ 1**: он бесплатный и без ключей.

## Где открыть окно подключения

- На экране выбора пилота нажмите **F4**.
- Или в рубке Ориона нажмите **«🔌 ПОДКЛЮЧИТЬ АГЕНТА»**.
- Чтобы изменить уже подключённого агента, нажмите **✎** в его строке на вкладке «АГЕНТЫ» (**✕** удаляет агента).

Клавиши в окне: **Tab** переходит между полями, **Ctrl+1/2/3** выбирают вид подключения,
**F5** проверяет связь, **Ctrl+Enter** сохраняет, **Esc** — отмена.

## Способ 1. OpenCode: бесплатные модели, без ключа (рекомендуется)

1. Установите [Node.js](https://nodejs.org/), затем в терминале выполните: `npm install -g opencode-ai`
2. Проверьте, что модели доступны: `opencode models`. Бесплатные модели оканчиваются на `-free`,
   например `opencode/deepseek-v4.1-flash-free`.
3. Проверьте, что модель отвечает: `opencode run -m opencode/deepseek-v4.1-flash-free "привет"`
4. В окне «Подключить агента» выберите **«OpenCode CLI»** (Ctrl+2).
5. Впишите имя агента. В поле «МОДЕЛЬ» впишите модель из шага 2. Если поле пустое,
   OpenCode берёт свою модель по умолчанию.
6. Нажмите **F5**, а когда связь подтвердится — **Ctrl+Enter**.

Самому Ориону тоже можно прописать модель: нажмите **✎** в строке Ориона.

## Способ 2. Любой OpenAI-совместимый API (нужен ключ)

Подходят OpenAI, DeepSeek, OpenRouter, Groq и локальная Ollama.

1. Получите ключ API на сайте сервиса. **Подписка ChatGPT Plus ключа API не даёт**: для OpenAI нужен
   отдельный ключ на platform.openai.com с оплатой по запросам. Для Ollama ключ не нужен.
2. Выберите **«API (OpenAI-совместимый)»** (Ctrl+1).
3. Нажмите кнопку готового адреса (openai, deepseek, openrouter, groq, ollama): программа сама подставит
   адрес и модель. Модель можно поменять.
4. Вставьте ключ в поле **«КЛЮЧ API»**, затем **F5** и **Ctrl+Enter**.

Ключ хранится **только в защищённом хранилище ОС**: в Windows это Диспетчер учётных данных
(запись `StarTyping/agent/<id>`), в Linux — gnome-keyring или KWallet. В файлах программы
ключа нет, только ссылка на запись. Если программа пишет «Нет ключа API», откройте агента
через **✎** и вставьте ключ заново.

## Способ 3. Мост GitHub (для разработчиков)

Сообщения (вместе с геолокацией из правого клика и скриншотами) уходят в обсуждение
GitHub Discussions вашего репозитория, а ответ корабль забирает оттуда опросом.

1. Создайте обсуждение в своём репозитории и узнайте его ID.
2. Создайте токен GitHub с доступом к Discussions.
3. Выберите **«Мост GitHub»** (Ctrl+3), впишите ID обсуждения и токен (токен ляжет в хранилище ОС).
4. На той стороне нужен отвечающий: бот или ассистент, который пишет ответы в это обсуждение.

## Голос агента

Поле **«ГОЛОС»** задаёт отдельный голос этого агента (имя голоса Windows, в Linux — голос espeak).
Если поле пустое, агент говорит голосом корабля. Пока ждёт ответа, агент сразу произносит
короткую фразу-заглушку, а потом озвучивает настоящий ответ.

## Если что-то не работает

- **«Нет ключа API»** — откройте агента через ✎ и вставьте ключ. Для бесплатных моделей переключите
  агента на OpenCode (способ 1): там ключ не нужен.
- **Ключ отклонён, лимит, нет сети** — причина показывается прямо в чате Ориона. Можно назначить
  **запасного агента**: если основной сбоит, ответит запасной, и в чате будет видно, кто ответил.
- **OpenCode не найден** — проверьте в терминале команду `opencode --version`. Установка — шаг 1 способа 1.
- **Home не срабатывает** — щёлкните вне текстового поля: в поле ввода Home двигает курсор.
- Голосовой вопрос и ответ сохраняются в чате Ориона, их можно перечитать в рубке.
- Linux: про хранилище ключей и голос см. [docs/LINUX.md](LINUX.md).
