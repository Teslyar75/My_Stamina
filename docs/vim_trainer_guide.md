# Руководство по VIM Тренажёру (Terraformer VIM)

> Интерактивный обучающий тренажёр VIM в лаундже Stamina. 12 уроков от основ движений до продвинутых техник.

---

## 🎮 Как начать

1. Открой **Лаундж** (кнопка в главном меню или `Ctrl+Shift+L`)
2. Нажми плитку **«VIM ТРЕНАЖЁР»** (🟣 фиолетовая иконка)
3. Откроется окно с первым уроком — *«Базовые движения»*

Прогресс сохраняется автоматически между сессиями.

---

## ⌨️ Управление в тренажёре

| Клавиша | Действие |
|---------|----------|
| `h` / `←` | Влево |
| `j` / `↓` | Вниз |
| `k` / `↑` | Вверх |
| `l` / `→` | Вправо |
| `Esc` | Выход в NORMAL режим (из INSERT/VISUAL/COMMAND) |
| `Ctrl+n` | Следующий урок (после завершения текущего) |
| `Ctrl+p` | Предыдущий урок |

> **Важно:** В тренажёре работают **только** клавиши, изучаемые в текущем уроке. Остальные игнорируются или дают подсказку.

## 📚 Список уроков (12 уровней)

### Урок 1: Базовые движения (`h j k l`)
**Цель:** Дойди курсором `@` до правого края строки.

```
........    ← поле 8×3
.@......    ← @ = твой курсор (старт: позиция 1, строка 1)
........    ← точки = пустые клетки
```

**Что учит:** В VIM курсор двигается **h/j/k/l**, не стрелками. Это мышечная память.
- `l` ×7 → конец строки
- `h` → назад
- `j`/`k` → вверх/вниз

---

### Урок 2: Словесные движения (`w b e`)
**Цель:** Посети все 7 целей (начала и концы слов) на трёх строках.

```
the quick brown fox
 jumps over the lazy
 dog...............
```

**Клавиши:**
- `w` — к **началу** следующего слова
- `b` — к **началу** предыдущего слова
- `e` — к **концу** текущего слова

**Задания:**
1. `w` → прыгай: quick → brown → fox
2. `b` → возвращайся к началу слова
3. `e` → концу слова
4. Окрой все 7 целей

---

### Урок 3: Строчные движения (`0 ^ $`)
**Цель:** Используй `0`, `^`, `$` на каждой из трёх строк.

```
   indented line
another line here
  third line
```

**Клавиши:**
- `0` — **абсолютное** начало строки (колонка 0)
- `^` — первый **не-пробел** (индент)
- `$` — **конец** строки

**Задания:**
1. Строка 1: `0` (0) → `^` (3: 'i') → `$` (15)
2. Строка 2: `0` (0) → `^` (0) → `$` (16)
3. Строка 3: `0` (0) → `^` (2: 't') → `$` (12)

---

### Урок 4: Удаление символов (`x X`)
**Цель:** Удали все буквы в первой строке.

```
delete_me
xXxXxXxXx
........     
```

**Клавиши:**
- `x` — удалить символ **ПОД** курсором
- `X` (Shift+x) — удалить символ **ПЕРЕД** курсором

**Задания:**
1. На 'd' → `x` → исчезнет
2. Ещё `x` → 'e', и так далее
3. `X` полезен, если проехал мимо цели
4. Очисти первую строку полностью

---

### Урок 5: Удаление слов (`dw db de`)
**Цель:** Удали все слова на первой строке командой `dw`.

```
remove these words please
..........................   
..........................   
```

**Клавиши:**
- `dw` — удалить слово **вперёд** (от курсора до пробела после слова)
- `db` — удалить слово **назад**
- `de` — удалить до **конца** слова

**Задания:**
1. В начале строки: `dw` → удалит `'remove '`
2. Ещё `dw` → `'these '`, `'words '`, `'please'`
3. `db` — назад (курсор в середине)
4. `de` — до конца слова
5. Очисти строку полностью

---

### Урок 6: Удаление строк (`dd D`)
**Цель:** Удали вторую и третью строки (`dd` на каждой).

```
line one
line two
line three
line four
```

**Клавиши:**
- `dd` — удалить **ЦЕЛУЮ** строку
- `D` — удалить от курсора **до конца** строки

**Задания:**
1. `j` → вторая строка
2. `dd` → 'line two' исчезает
3. `j` (теперь бывшая 3-я) → `dd`
4. `D` — только хвост строки
5. Остаются только 1-я и 4-я строки

---

### Урок 7: Режим вставки (`i a o O`)
**Цель:** Выполни 3 вставки: `i`, `a`, `o`. `Esc` — выход в NORMAL.

```
hello world
...........    
...........    
```

**Клавиши:**
- `i` — вставить **ПЕРЕД** курсором
- `a` — вставить **ПОСЛЕ** курсора
- `o` — новая строка **НИЖЕ** (входишь в INSERT)
- `O` — новая строка **ВЫШЕ**

**Задания:**
1. Курсор на пробел (поз. 5) → `i` → введи `' beautiful'` → `Esc` → `'hello beautiful world'`
2. Курсор на 'd' (поз. 11) → `a` → введи `'!'` → `Esc` → `'world!'`
3. На пустой строке 2 → `o` → введи `'new line below'` → `Esc`
4. `O` создаёт строку ВЫШЕ

---

### Урок 8: Оператор изменения (`cw cb ce cc C`)
**Цель:** Замени `'this word'` на `'it'` (`cw`), вторую строку целиком (`cc`).

```
replace this word
change whole line
.................   
```

**Клавиши:**
- `c` = **change** (удалить + войти в INSERT)
- `cw` — изменить слово
- `cc` — изменить **целую** строку
- `C` = `c$` — изменить до конца строки
- `cb`/`ce` — назад / до конца слова

**Задания:**
1. На 't' слова 'this' → `cw` → введи `'it'` → `Esc`
2. `j` → строка 2 → `cc` → введи `'new line'` → `Esc`
3. `C` — изменить хвост строки
4. `cb`/`ce` — редко нужны

---

### Урок 9: Визуальный режим (`v V`)
**Цель:** Выдели `'this text'` (`v` + `llll`), удали (`d`). Потом строку 2 (`V` + `d`).

```
select this text
and delete it
..............    
```

**Клавиши:**
- `v` — **посимвольное** выделение (VISUAL)
- `V` — **построчное** выделение (VISUAL LINE)
- В выделении: `d` — удалить, `y` — копировать, `c` — изменить

**Задания:**
1. На 't' слова 'this' → `v` (вход в VISUAL)
2. `l` ×8 → выделится `'this text'`
3. `d` → выделенное удалится
4. `j` → строка 2 → `V` (VISUAL LINE)
5. `d` → вся строка удалится
6. `y` — копировать (yank), `c` — изменить

---

### Урок 10: Поиск и замена (`/ n N * # :s`)
**Цель:** Найди все 3 вхождения `'vim'`.

```
find the word vim here
vim is powerful vim
......................    
```

**Клавиши:**
- `/pattern` — поиск **вперёд** (Enter для запуска)
- `?pattern` — поиск **назад**
- `n` — **следующее** совпадение
- `N` — **предыдущее** совпадение
- `*` — мгновенный поиск слова **ПОД** курсором
- `#` — то же назад
- `:s/old/new/g` — замена в строке (упрощено в тренажёре)

**Задания:**
1. `/` → введи `'vim'` → Enter → прыгает на 1-е `'vim'`
2. `n` → 2-е `'vim'` (строка 2)
3. `n` → 3-е `'vim'` (конец строки 2)
4. `N` — назад
5. `*` — поиск слова под курсором
6. `:s/old/new/g` — замена (демо)

---

### Урок 11: Отмена и возврат (`u Ctrl+r`)
**Цель:** Сделай изменение (`x` или `dw`), `u` — вернётся. `Ctrl+r` — снова уйдёт.

```
make a mistake
then fix it
..............    
```

**Клавиши:**
- `u` — **отменить** последнее ИЗМЕНЕНИЕ (не движение!)
- `Ctrl+r` — **вернуть** отменённое (redo)

**Задания:**
1. `x` → удалит 'm' в 'make'
2. `u` → 'm' вернётся (undo)
3. `Ctrl+r` → 'm' снова исчезнет (redo)
4. `u` работает с **ЛЮБЫМ** изменением: `x`, `dw`, `dd`, `cw`, `p`...
5. Дерево отмен в VIM — мощнейшая фишка

---

### Урок 12: Повторители/каунтеры (`5j 3dw 2dd 10x`)
**Цель:** С нижней строки — `5k` (вверх 5), потом `3l` (вправо 3).

```
........    ← строка 0
........    ← строка 1
........    ← строка 2
........    ← строка 3
........    ← строка 4
@.......    ← строка 5 (ты здесь)
```

**Принцип:** Число **ПЕРЕД** командой = количество повторов.

**Клавиши:**
- `5j` = `jjjjj` (вниз 5 строк)
- `5k` = `kkkkk` (вверх 5 строк)
- `3dw` = 3 раза `dw` (удалить 3 слова)
- `2dd` = 2 строки подряд
- `10x` = удалить 10 символов

**Задания:**
1. Ты на строке 5 → `5k` → окажешься на строке 0
2. `3l` → курсор сдвинется на 3 вправо
3. `2dd` — удалит 2 строки
4. `10x` — удалит 10 символов
5. Работает с **ПОЧТИ ВСЕМИ** командами движения и изменения

## 💡 Советы по прохождению

1. **Не спеши** — читай подсказки (жёлтый текст справа) и задания (белые пункты)
2. **Пробуй варианты** — тренажёр не штрафует за ошибки, `u` всё вернёт
3. **Используй каунтеры** — `5j` быстрее, чем `jjjjj`, это про VIM-мышление
4. **Esc — твой друг** — застрял в INSERT/VISUAL? `Esc` → NORMAL
5. **Прогресс сохраняется** — можешь закрыть окно и продолжить завтра
6. **Повторяй уроки** — `Ctrl+p` возвращает к пройденному для закрепления

## 🎯 Что даёт прохождение

- **Мышечная память** базовых движений (h/j/k/l → w/b/e → 0/^/$)
- **Понимание операторов** (d/c/y) и текстовых объектов (w/s/line)
- **Уверенность** в режимах: NORMAL, INSERT, VISUAL, COMMAND
- **Навык поиска** (`/`, `n`, `*`) и правки (`cw`, `cc`, `C`)
- **Рефлекс отмены** (`u` / `Ctrl+r`) — спасёт часы работы
- **Привычку каунтеров** — скорость ×5–10

## 🐛 Известные ограничения тренажёра

- Упрощённая реализация операторов (`d`/`c`/`y` работают как мгновенные действия, не ждут motion)
- Поиск назад (`?`, `N`) — заглушка
- Замена `:s///` — только демонстрация
- Блок навигации не работает (только h/j/k/l)
- Нет макросов (`q`/`@`), регистров (`"a`), окон (`Ctrl+w`), табов (`gt`)

> Для полноценной практики — открой настоящий VIM/Neovim и пройди `vimtutor`.
