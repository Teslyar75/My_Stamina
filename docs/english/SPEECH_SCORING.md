# Единый стандарт оценки произношения

Один стандарт для всех режимов: сканер, миссии, склад, CEFR, глаголы, книга, уроки.
Основа — логика склада (`stamina/english/warehouse.py`) и слоты качества (`stamina/english/quality.py`).
Документ общий для desktop и будущей web-версии: числа ниже — контракт.

## 1. Оценка одной попытки

Точность попытки — 0–100 % совпадения распознанного текста с эталоном (текущий алгоритм распознавания не меняется).

| Порог | Значение | Смысл |
|---|---|---|
| ★ | ≥ 60 % | понятно, но с ошибками; засчитывается только как история (сканер, `SENT_PASS`) |
| **зачёт элемента** | **≥ 80 %** | слово или предложение засчитано (`FLIP_OK`, ★★) |
| ★★★ | ≥ 95 % | чисто |

## 2. Оценка прогона карточки

Прогон = слово + его примеры. Прогон засчитан, если каждый элемент ≥ 80 % **и** средняя ≥ **85 %** (`PASS_QUALITY`).
Карточка «отработана» после N засчитанных прогонов (по умолчанию 2; выбор 1/2/3/5).

## 3. Слоты качества (до 20 на карточку)

Пороги растут с номером прохода внутри группы — первое касание прощает, повтор требует большего:

| Группа | Что делает ученик | Пороги по проходам |
|---|---|---|
| A · СЛОВО | сказать слово | 80, 80, 85, 90 |
| B · ЧТЕНИЕ | прочитать пример вслух | 80, 85 |
| C · ПЕРЕВОД | сказать EN по русскому | 85, 88, 90 |
| D · АУДИО | услышать и повторить | 80, 85 |
| E · СВОЁ | своё предложение | самооценка |

## Почему так

* **80 % на элемент** — ниже распознаватель часто путает близкие слова, выше — штрафует акцент, а не ошибку; на складе это проверено практикой.
* **85 % в среднем** — один «натянутый» элемент на 80 % не обнуляет прогон, но систематически слабый прогон не проходит.
* **Рост порогов** — повторение должно звучать увереннее первой попытки.
* **Одни числа везде** — ученик не должен угадывать, почему в миссии «зачёт», а на складе «нет».

## Поведение интерфейса (общий контракт)

* После зачтённой попытки фокус сам переходит к следующему элементу (авто-переход), без мыши.
* Микрофон: **Пробел** или **M**; кнопка микрофона стоит на одном месте во всех режимах.
* Незачтённая попытка оставляет фокус на элементе и показывает точность и порог.

Реализация: `stamina/english/speech_std.py` (ITEM_OK, RUN_OK, ADVANCE_MS = 900 мс, `typing_in`, `advance_later`).

| Режим | Space / M | Авто-переход после зачёта (≥ 80 %) |
|---|---|---|
| Сканер (и CEFR — клик по слову открывает сканер) | микрофон; S — озвучить | к следующему предложению |
| Миссии (S-задания) | микрофон | к следующему заданию |
| Склад | микрофон | к следующему элементу карточки (как было) |
| Книга | Space: сначала расшифровать, затем микрофон; M — микрофон | к следующей карточке (как было) |

Авто-переход отменяется, если ученик за паузу сам переключил элемент. В поле ввода
(Entry, редактируемый Text) пробел и буквы остаются тексту.
