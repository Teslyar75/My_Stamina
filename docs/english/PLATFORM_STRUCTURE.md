# Английский: структура платформы (десктоп, «Звездолёт»)

> Рабочий документ. Эталон — стандартная версия (классика) и скин «Звездолёт».
> Альтернативные скины не затрагиваем.

## 1. Навигация

Верхний ряд остаётся компактным (10 подвкладок), новые сущности живут внутри двух хабов.

| Вкладка | Что внутри |
|---|---|
| ОБЗОР | Курс на сегодня, **4 сектора-группы**, плашка книги, телеметрия |
| **НАБОРЫ** | `СТАНДАРТ` · `CEFR` · `ГЛАГОЛЫ` · `ИЗ КНИГИ` |
| СКАНЕР | Карточка слова (без изменений) |
| МИССИИ | Тренировки; кнопка «УРОКИ И ПРАВИЛА» |
| ПРОВЕРКА СИСТЕМ | SM-2 повторение |
| СКЛАД КАРТОЧЕК | Карточка + **20 слотов качества** |
| ОТСЕКИ | Пользовательские списки |
| **УРОКИ** (без отдельной кнопки) | `КАРТА УРОКОВ` · `СПРАВОЧНИК`; вход — ОБЗОР и МИССИИ |
| ЖУРНАЛ | Прогресс, ошибки |
| НАСТРОЙКИ | В т.ч. цель качественных повторений |

Переходы: ОБЗОР → «УРОКИ · ПРОДОЛЖИТЬ» → урок → правило (справа) → миссия по
словам урока → склад → 20 слотов → «Отработано».

УРОКИ намеренно **не занимают одиннадцатую кнопку**: верхний ряд остаётся
десятью подвкладками, а уроки открываются с ОБЗОРА и из МИССИЙ. Так курс
находится там, где начинается работа, и не ломает раскладку скинов.

`ИЗ КНИГИ` остаётся отдельной страницей (`pages_book.py`), но её вкладка в
НАБОРАХ ведёт туда же — один экран, два входа.

## 2. Модель карточки

Единая карточка для всех наборов. Провайдеры отдают один и тот же словарь.

```python
CARD = {
  "kind": "word",            # word | verb | sentence | lesson
  "set": "cefr-a1",          # набор-источник
  "level": "A1",             # CEFR / урок
  "slug": "apple",           # совпадает со slug словаря, если слово уже есть
  "word": "apple", "ru": "яблоко", "ipa": "ˈæp.əl",
  "senses": [{"pos": "noun", "definition": "…", "ru": "яблоко"}],
  "sentences": [{"en": "...", "ru": "...", "source": "...", "license": "..."}],
  "forms": {"base": "go", "past": "went", "pp": "gone", "ing": "going"},
  "source": {"name": "original", "url": "", "license": "CC BY-SA 4.0"},
}
```

**Ключевое решение:** CEFR-слова не кладутся отдельным файлом-дублем. Они
сливаются с частотным словарём по `slug`: у существующего слова появляется
`sets`-метка и добираются примеры до пяти. Одно слово — одна карточка, один
прогресс. Новые для словаря слова получают синтетический `rank` и живут так же.

Файлы данных:

```
stamina/english/data/sets/cefr_a1.json      # слова + 5 предложений
stamina/english/data/sets/cefr_a2.json      # слова + 5 предложений
stamina/english/data/grammar/a1.json        # правила, на которые ссылаются уроки
stamina/english/data/irregular_verbs.json   # этап 3
```

Уроки описаны кодом (`stamina/english/lessons.py`): id, номер, правила (id из
`grammar.py`), слова (slug из CEFR), шаги. Отдельные json-файлы уроков не нужны,
пока весь A1-план помещается в один список; данные и логика не расходятся.

## 3a. Порции CEFR: по 50 слов

Уровень делится на порции по `cefr.BLOCK_SIZE = 50` слов (допустимо 40–60;
последняя порция может быть короче). Порядок слов в файле — порядок изучения,
поэтому новые слова только дописываются в конец.

Слово считается пройденным, если закрыта цель качества (`quality.is_complete`)
или стоит отметка «знаю» / карточка на складе (`progress.is_known`,
`progress.is_learned`). Всё остальное выводится из прогресса, отдельного
хранилища блоков нет:

- первый блок уровня открыт сразу;
- блок N+1 программа открывает сама, как только закрыты все слова блока N;
- когда закрыт последний блок, уровень считается пройденным, и программа
  сразу открывает следующий доступный уровень;
- «УЧИТЬ КАРТОЧКАМИ» и «МИССИЯ» берут только слова текущего блока;
- вернуться к пройденному блоку можно кнопкой блока, прогресс не теряется;
- на низком окне число рядов уменьшается (4 → 3 → 2), чтобы нижняя панель
  с листалкой оставалась на экране, а плитки не сжимались в полоску.

Новые порции пишутся по инструкции `docs/english/AGENT_SETS_TASK.md`.

## 3. Качественные повторения: 20 — максимум

20 — верхняя граница. Ученик или учитель ставит цель меньше: `5 / 10 / 15 / 20`.
Цель хранится в настройках и может переопределяться для карточки.

Профиль на 20 слотов (слово):

| Блок | Слотов | Что делаем | Порог |
|---|---|---|---|
| A. Слово | 4 | сказать слово по-английски (RU → EN) | 80 / 80 / 85 / 90 |
| B. Чтение | 10 | 5 предложений × 2 прохода, английский виден | 80 / 85 |
| C. Перевод | 3 | предложение с русского, английский скрыт | 85 / 88 / 90 |
| D. Аудирование | 2 | услышать и повторить | 80 / 85 |
| E. Своё | 1 | составить своё предложение (чекбокс) | — |

Итого 20. Для глагола: A = 6 (по 2 на форму), B = 6, C = 4, D = 3, E = 1.
Для книжного предложения: A = 2, B = 6, C = 8, D = 3, E = 1.

Правила:

- слот загорается **сам** по результату распознавания (Vosk) или самооценки;
- ручной чекбокс — только слот E и режим без микрофона; такая галочка помечается
  как самооценка и не идёт в достижение «Голос»;
- провал обнуляет текущий слот, не карточку;
- не больше 4 слотов на карточку в день (20 повторений = 5–6 заходов);
- «Отработано» = цель набрана; дальше карточка живёт на SM-2 поддержке.

Хранение:

```json
"quality": {
  "apple": {"kind": "word", "n_sents": 5, "goal": 20,
            "slots": {"a0": [86, "2026-10-25"], "b21": [91, "2026-10-25"]},
            "self": 1}
}
```

`goal` копируется в карточку при первом открытии, чтобы смена глобальной
настройки не обнуляла уже начатые карточки.

## 4. Спряжение

`data/irregular_verbs.json` + генератор `conjugation.py`. Храним основу и три
формы, остальное считаем: 12 времён × 7 лиц × 3 polarity. Исключения — `be`,
`have`, `do`, модальные, stative (не ставятся в Continuous).

UI — внутри УРОКИ → СПРАВОЧНИК: сетка с замороженным первым столбцом,
переключатель `+ / − / ?`, клик по клетке — озвучка и «→ в карточку».

## 5. Уроки и справочник правил

Курс последовательный: урок открывается только после предыдущего. План A1 —
10 уроков (`lessons.PLANS`), у каждого:

```python
{"id": "a1-03", "n": 3, "title": "Мой день",
 "goal": "Говорить о привычках в Present Simple.",
 "rules": ["a1-present-simple"],          # id из data/grammar/a1.json
 "words": ["day", "morning", "evening", "time", "work", "school"],
 "steps": ["правило", "карточки", "перевод", "чтение вслух", "своё"]}
```

**Правила — часть урока.** В карточке урока есть кнопки «ПРАВИЛА УРОКА»: правило
открывается справа, не уводя с урока; внизу — примеры с озвучкой и переводом.
Тот же текст доступен в СПРАВОЧНИКЕ (вкладка рядом), сгруппированный по уровням.
Идентификаторы правил (`a1-to-be`, `a1-past-simple`, …) — единые для урока и
справочника, поэтому «правило урока» и «статья справочника» не расходятся.

Порядок шагов: ОБЗОР → УРОКИ → урок → «▶ НАЧАТЬ УРОК» (движок
`PracticePage.start`, слова урока) → «УРОК ПРОЙДЕН» → открывается следующий.
Грамматика объясняется до практики, а не после.

Раннер переиспользует существующий движок миссий; нового движка нет.
