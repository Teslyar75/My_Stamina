# Инструкция бортовому ИИ-агенту: наборы CEFR и загрузка блоками

> Документ для агента, который делает очередной набор слов и включает его в
> платформу. Короткий устав корабля — `AGENTS.md`; устройство платформы —
> `docs/english/PLATFORM_STRUCTURE.md`. Здесь только задание, правила контента
> и условия загрузки блоков.

## 0. Готовый промпт (можно копировать агенту)

```text
Ты — бортовой ИИ-агент Star Typing. Задача: сделать очередной блок набора CEFR
(40–60 слов) с пятью примерами на слово и включить последовательную загрузку
блоков.

Уровень: <A1 | A2 | B1.1 | ...>. Номер блока: <N>. Файл:
stamina/english/data/sets/cefr_<level>.json (создать, если уровня ещё нет).

Требования:
- 40–60 новых слов, которых нет ни в одном другом наборе CEFR;
- на каждое слово: word, ru, ipa, pos, senses[{pos, definition}], 5 предложений
  en+ru; слова идут в порядке изучения (простые → сложнее);
- предложения оригинальные, 4–10 слов, грамматика не выше уровня, целевое слово
  встречается один раз, без повторов внутри блока;
- лицензия CC BY-SA 4.0, источник указан в JSON и в docs;
- блоки по 50 слов определяются порядком слов в файле;
- следующий блок открывается только когда все слова текущего блока пройдены
  (quality.is_complete ИЛИ progress.is_known/is_learned); программа проверяет
  это сама и сразу грузит следующую порцию;
- следующий уровень открывается только когда все слова текущего уровня пройдены.

Проверки: python -m pytest tests/test_english_cefr.py tests/test_english_hub_ui.py -q,
плюс скрипт валидации из раздела 4. Ветка agent/<имя>/cefr-<level>-block-<N>,
коммит feat: <level> — блок <N> (<K> слов). Отчёт: что добавлено, какие проверки
прошли, сколько слов и примеров стало.
```

## 1. Что считается блоком

- Блок — это **отрезок файла уровня по 50 слов** (допустимо 40–60, но по
  умолчанию 50). Последний блок может быть короче.
- Порядок блоков = порядок слов в `words[]`. Отдельного поля «блок» нет:
  перестановка слов меняет блоки и ломает прогресс, поэтому **только дописывать
  в конец**.
- Новый блок — это новые слова, дописанные в конец файла уровня. Уже готовые
  слова не переписываются и не сортируются.
- Один блок = одна порция изучения: карточки, миссия и склад работают с текущим
  блоком, а не со всем уровнем.

## 2. Задание на блок

1. Взять уровень и номер блока. Посчитать, сколько слов уже есть:
   `len(cefr.prepared(level))`.
2. Подобрать 40–60 слов уровня, которых нет в других наборах. Проверить
   пересечения скриптом (раздел 4).
3. Написать на каждое слово пять примеров и переводы.
4. Дописать блок в файл уровня.
5. Включить/проверить последовательную загрузку блоков и уровней (раздел 5).
6. Прогнать валидацию и тесты, обновить счётчики в
   `docs/english/PLATFORM_STRUCTURE.md`.
7. Закоммитить в своей ветке и отчитаться пилоту.

## 3. Формат данных

Файл: `stamina/english/data/sets/cefr_<level>.json`, где `<level>` — `a1`,
`a2`, `b1_1`, `b1_2`, `b2_1`, `b2_2`, `c1`, `c2`.

```json
{
  "id": "cefr-a1",
  "level": "A1",
  "name": "A1 · Выживание",
  "source": {
    "name": "original",
    "url": "docs/english/PLATFORM_STRUCTURE.md",
    "license": "CC BY-SA 4.0"
  },
  "words": [
    {
      "word": "apple",
      "ru": "яблоко",
      "ipa": "ˈæp.əl",
      "pos": "noun",
      "senses": [
        {"pos": "noun", "definition": "a round fruit with red or green skin"}
      ],
      "sentences": [
        {"en": "I eat an apple every day.", "ru": "Я ем яблоко каждый день."},
        {"en": "This apple is red and sweet.", "ru": "Это яблоко красное и сладкое."},
        {"en": "She puts an apple in her bag.", "ru": "Она кладёт яблоко в сумку."},
        {"en": "We buy apples at the market.", "ru": "Мы покупаем яблоки на рынке."},
        {"en": "Do you want an apple?", "ru": "Хочешь яблоко?"}
      ]
    }
  ]
}
```

Обязательные поля слова: `word`, `ru`, `ipa`, `pos`, `senses` (минимум один
элемент с `pos` и `definition`), `sentences` (ровно 5, у каждого `en` и `ru`).

`pos` — одно из: `noun`, `verb`, `adjective`, `adverb`, `pronoun`,
`preposition`, `conjunction`, `determiner`, `interjection`, `other`.

### Правила контента

- **Уровень.** Слова и грамматика не выше заявленного уровня. Для A1 —
  Present Simple, `be`, `can`, `there is/are`, повелительное наклонение;
  без Perfect, пассива и сложных придаточных.
- **Предложения.** 4–10 слов, живые и разные по конструкции: утверждение,
  вопрос, отрицание, просьба. Целевое слово — один раз (формы допустимы:
  `apple` → `apples`).
- **Перевод.** Естественный русский, без кальки и машинного «это есть».
  Имена и реалии — по-русски.
- **IPA.** Британская транскрипция без слэшей, например `ˈæp.əl`.
- **Определение.** Простое, на английском, не длиннее одной строки, без
  целевого слова в определении (по возможности).
- **Повторы.** Ни одного повторяющегося предложения внутри слова и внутри
  блока. Слова не повторяются между уровнями.
- **Порядок.** Внутри блока — от простого к сложному; тематические гнёзда
  (еда, дом, тело) идут подряд.
- **Лицензия.** Текст оригинальный, CC BY-SA 4.0. Не копировать примеры из
  словарей и учебников. IPA/определения из Wiktionary допустимы с указанием
  источника (`source`, `license`).

## 4. Валидация

Скрипт (запускать из корня репозитория, перед коммитом):

```python
import json, collections
from stamina.english import cefr

level = "A1"
words = cefr.entries(level)

assert 40 <= len(words) <= 60 or len(words) < 40, "размер блока"
seen = set()
for w in words:
    assert w["word"] and w["ru"] and w["ipa"] and w["pos"], w["word"]
    assert len(w["sentences"]) == 5, (w["word"], len(w["sentences"]))
    assert w["senses"] and w["senses"][0]["definition"], w["word"]
    local = set()
    for s in w["sentences"]:
        assert s["en"].strip() and s["ru"].strip(), w["word"]
        key = s["en"].strip().lower()
        assert key not in local, (w["word"], s["en"])
        local.add(key)
    seen.add(w["word"].lower())

# пересечения между уровнями
for other in cefr.available():
    if other == level:
        continue
    dup = {w["word"].lower() for w in cefr.entries(other)} & seen
    assert not dup, f"дубли с {other}: {sorted(dup)}"

print("ok:", len(words), "слов")
```

Тесты:

```sh
python -m pytest tests/test_english_cefr.py tests/test_english_hub_ui.py ^
  tests/test_english_quality.py tests/test_english_lessons.py -q
```

Тест `test_english_cefr.py` проверяет все доступные уровни: пять примеров,
уникальность слов между уровнями, слияние без дублей.

## 5. Условия загрузки наборов

### 5.1. Блоки внутри уровня

Константа `cefr.BLOCK_SIZE = 50`. Блоки считаются по порядку:

```python
words = cefr.prepared(level)          # порядок файла
blocks = [words[i:i + BLOCK_SIZE] for i in range(0, len(words), BLOCK_SIZE)]
```

Слово считается пройденным, если выполнено хотя бы одно:

```python
def done(slug: str) -> bool:
    p = ctx.progress
    return (p.is_known(slug) or p.is_learned(slug)
            or quality.is_complete(p, slug))
```

`quality.is_complete` — цель качества достигнута (5/10/15/20 слотов).
`is_known` / `is_learned` — ручная отметка «знаю» или карточка на складе;
они нужны, чтобы блок не застревал, если пилот учил слова без микрофона.

Правила:

- Первый блок уровня открыт всегда.
- Блок `k` открыт, если **все слова блоков `0..k-1` пройдены**.
- Текущий блок можно листать внутри по 24 карточки — это не меняет блок.
- «УЧИТЬ КАРТОЧКАМИ» и «МИССИЯ ПО НАБОРУ» берут только слова текущего блока.
- Когда все слова блока пройдены, программа **сама проверяет** это и сразу
  грузит следующую порцию: блок N+1 становится текущим, его карточки показываются
  на экране. Нажимать ничего не нужно.
- Пройденный блок помечается `✓`; вернуться и повторить его можно.
- Если все блоки уровня пройдены — уровень считается пройденным, и программа
  сразу открывает следующий доступный уровень (его первый блок).

### 5.2. Уровни

- Первый доступный уровень (обычно A1) открыт всегда.
- Следующий уровень открыт, если **все слова предыдущего уровня пройдены**.
- Уровень, для которого ещё нет файла, показывается как «готовится» (`lv ·`),
  а не как замок. Это разные состояния: «нет контента» и «закрыто до прохождения».
- Закрытый уровень: кнопка с пометкой «закр», по клику — сообщение
  «Сначала пройди A1», состояние не меняется.

### 5.3. Экран (что должен увидеть пилот)

```
A1 · Выживание · блок 2 / 3 · слов 50 · пройдено 12 / 50
[1 ✓] [2] [3 закр]
карточки текущего блока (по 24 на страницу)
СТР. 1 / 3 · 1–24 из 50
```

- Строка блоков: номер, `✓` у пройденных, «закр» у закрытых, активный подсвечен.
- Информация: уровень, номер блока, сколько слов в блоке и сколько пройдено.
- Прогресс-полоса уровня — по текущему блоку, а не по всему уровню.
- При завершении блока — сообщение «БЛОК 2 ПРОЙДЕН · ОТКРЫТ БЛОК 3»,
  и блок 3 уже показан на экране (без ручного нажатия). Даже если последнее
  слово отмечено «знаю» прямо на плитке, порция меняется сразу.
- При завершении уровня — «УРОВЕНЬ A1 ПРОЙДЕН · ОТКРЫТ A2»; программа
  сразу переключает на A2.
- На низком окне панель блоков и карточки должны влезать без прокрутки:
  блоки — одна строка кнопок, карточки — по высоте окна.

### 5.4. Где это менять

- `stamina/english/cefr.py` — `BLOCK_SIZE`, `blocks(level)`, готовые слова
  (`prepared`).
- `stamina/english/pages_setshub.py` — `CefrPage`: кнопки блоков, выбор блока,
  проверка `done`, гейт уровней, текст информации, `learn`/`mission`.
- `stamina/english/screen.py` — `changed()`: после отметки «знаю» на плитке
  сразу обновляет CEFR, чтобы порция загрузилась без переключения вкладок.
- `stamina/english/quality.py` — `is_complete` (не менять без нужды).
- `stamina/english/progress.py` — `is_known`, `is_learned` (только чтение).

Хранить состояние блоков отдельно **не нужно**: всё выводится из прогресса.
Не добавляй поля в progress без необходимости — иначе миграции и рассинхрон.

### 5.5. Крайние случаи

- Уровень из одного блока — блок 1 сразу открыт, после прохождения уровень
  считается пройденным.
- Последний блок короче 50 слов — это нормально, счётчик и прогресс считаются
  по фактическому числу слов.
- Нельзя удалять/переставлять слова в уже пройденном блоке: это сдвинет блоки
  и обнулит ощущение прогресса. Только дописывать в конец.
- Если слово встречается в другом уровне, блок не принимать: сначала
  согласовать перенос или замену.
- Если прогресс пуст, открыт только первый блок первого уровня — это норма.

## 6. Git и отчёт

- Ветка: `agent/<имя>/cefr-<level>-block-<N>`.
- Перед рискованной правкой: `powershell -ExecutionPolicy Bypass -File tools\snapshot.ps1`.
- Коммит: `feat: A1 — блок 3 (50 слов)`; один коммит — один блок (плюс тесты,
  если менял механику загрузки).
- Не коммитить чужие файлы, `%APPDATA%\Stamina`, кэши и личные данные.
- Отчёт пилоту: уровень, номер блока, сколько слов и примеров добавлено,
  сколько всего слов в уровне, какие проверки прошли, что осталось.

## 7. Чек-лист готовности

- [ ] 40–60 слов, все новые для CEFR-наборов.
- [ ] У каждого слова 5 примеров с переводом, IPA, pos, definition.
- [ ] Нет повторов предложений и слов между уровнями.
- [ ] Грамматика и лексика не выше уровня.
- [ ] Блок дописан в конец файла, старые слова не тронуты.
- [ ] Блоки считаются по 50, следующий программа открывает сама после прохождения текущего.
- [ ] Следующий уровень открывается после прохождения текущего.
- [ ] Кнопка закрытого блока/уровня показывает «закр» и не переключает экран.
- [ ] «УЧИТЬ КАРТОЧКАМИ» и «МИССИЯ» берут только текущий блок.
