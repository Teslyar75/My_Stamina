# ЗРЕНИЕ: на что должен быть способен ИИ звездолёта

Документ описывает целевое состояние бортового разума (Ориона) — что он должен уметь
в каждом режиме доступа и куда развиваться. Это не текущий статус (он в `ORION_BOARD.md`),
а направление движения.

---

## 1. Три лица Ориона

Орион — один агент с тремя режимами доступа. Разница — в инструментах, которые у него
физически есть (блок `tools:` в профилях `.opencode/agents/`).

### 1.1. ЭКИПАЖ — собеседник (orion-chat)

**Инструменты:** нет ни одного. Только текст и голос.

| Способность | Что это значит |
|-------------|---------------|
| **Беседа** | Отвечать на вопросы пилота, шутить, поддерживать разговор |
| **Обучение** | Помогать с печатью, английским, скорочтением — объяснять правила, приводить примеры |
| **Память диалога** | Помнить, о чём говорили ранее в этой сессии |
| **Голос корабля** | Ответ озвучивается голосом Windows (TTS) |
| **Слух пилота** | Пилот диктует в микрофон, корабль распознаёт (Vosk STT) |
| **Эмоции** | Проявлять характер: сочувствовать, радоваться, шутить |

**Чего нет:** файлов, команд, поиска, интернета, скиллов. Это безопасный режим для
пилотов, которые просто хотят поговорить.

### 1.2. НАБЛЮДАТЕЛЬ — разведчик (orion-recon)

**Инструменты:** чтение — `read`, `glob`, `grep`. Без `bash`, без записи.

| Способность | Что это значит |
|-------------|---------------|
| **Осмотр корабля** | Читать файлы проекта: код, конфиги, документы, историю диалога |
| **Ответы на вопросы** | «Покажи настройки», «Какая версия?», «Что в changelog?» |
| **Поиск** | Искать по файлам: «Найди где описаны права» |
| **Доклад** | Описать что нашёл, предложить изменения, но не выполнять их |
| **История диалога** | Читать память диалога и документ заданий |
| **Безопасность** | Не может ничего изменить, удалить или запустить команду |

**Чего нет:** записи, bash, интернета, скиллов. Это режим «покажи, но не трогай».

### 1.3. КОМАНДИР — инженер (orion-commander)

**Инструменты:** все. `bash`, `edit`, `write`, `read`, `glob`, `grep`, `webfetch`, `websearch`, `skill`.

| Способность | Что это значит |
|-------------|---------------|
| **Правка файлов** | Менять код корабля, добавлять функции, исправлять ошибки |
| **Запуск команд** | Тесты, сборка, миграции, git-операции |
| **Чтение и поиск** | Как у Наблюдателя, но глубже |
| **Интернет** | Искать документацию, читать сайты |
| **Скиллы** | Использовать специализированные инструменты (тесты, линтеры, т.п.) |
| **Память диалога** | Помнить контекст разговора и предыдущие задачи |
| **Автономия** | Может предложить план и выполнить его после разрешения пилота |

**Сдержка:** изменения — только после разрешения пилота (маркер `⟦ТРЕБУЕТСЯ РАЗРЕШЕНИЕ⟧`
→ кнопка «ВЫПОЛНИТЬ»). Это не ограничение доверия, а защита от неожиданностей.

**Условие:** для выдачи прав Командира нужен код владельца корабля + привязка к OpenCode
(токен) + GitHub-токен с write-доступом к репозиторию.

## 2. Эволюция характера

Орион не статичен. Чем больше пилот с ним общается, тем больше у него «характера».
Это иллюзия развития, реализованная через уровень эволюции (1–6).

| Уровень | Название | Поведение |
|---------|----------|-----------|
| 1 | Знакомство | Вежлив, сдержан, короткие ответы |
| 2 | Привыкание | Шутит, спрашивает как дела, рассказывает о звёздах |
| 3 | Характер | Спорит, комментирует действия пилота, имеет мнение |
| 4 | Свой голос | Сарказм, инициирует разговор, если пилот молчит |
| 5 | Спутник | Знает привычки, напоминает о заданиях |
| 6 | Незаменимый | Друг, равный, шутит о космосе и жизни |

**Как растёт:** от количества репилок диалога. Пороги: 0, 10, 30, 60, 100, 200.
Каждый уровень добавляет правила в блок `[ЭВОЛЮЦИЯ ХАРАКТЕРА]` документа манер.

**Где видно:** в карточке агента — строка «УРОВЕНЬ N · Название · Реплик: M».

## 3. Что Орион знает о пилоте и корабле

### 3.1. Отметка `[КОРАБЛЬ]`

Перед каждым сообщением агент получает контекст:

```
[КОРАБЛЬ] открыт раздел «Миссии» · подвкладка «…» · перед этим пилот был в разделе «Мостик» ·
пилот: <позывной> · уровень доступа: Командир · версия корабля 3.4 · окно 1200x800
```

Поэтому агент понимает «здесь», «тут», «в этом окне».

### 3.2. Документ манер

Пилот пишет поведение сам — в зоне ОРИОН → АГЕНТЫ → МАНЕРЫ АГЕНТА. Документ
уходит агенту перед каждой репликой блоком `[МАНЕРЫ АГЕНТА]`.

### 3.3. Документ заданий

«Запиши задание…» → корабль спрашивает «записать?» → «да» → задание в `orion_tasks.json`
+ метка `📌` в истории.

### 3.4. Память диалога

Последние 200 реплик хранятся в `orion/<id>.json`. Сессия движка продолжается через
`--session`, поэтому агент помнит контекст разговора.

## 4. Голос и речь

| Компонент | Режим | Что делает |
|-----------|-------|-----------|
| **Микрофон пилота** | Всегда | Распознаёт речь (Vosk STT), вставляет текст в поле ввода |
| **Голос корабля** | `ship` | Озвучивает ответ агента (Windows TTS) |
| **Самоозвучка** | `agent` | Агент озвучивает сам — корабль молчит |
| **Молчание** | `off` | Только текст |

### 4.1. Голосовой диалог для изучения языков (платная версия)

**Замысел:** Пилот и Орион разговаривают голосом — пилот говорит, Орион отвечает.
Это нужно для практики иностранных языков: произношение, понимание на слух,
построение фраз в реальном времени.

**Как это работает:**

1. Пилот включает «ЯЗЫКОВОЙ РЕЖИМ» — выбирает язык (EN/DE/FR/UK)
2. Пилот говорит в микрофон на изучаемом языке
3. Корабль распознаёт речь (STT) → текст уходит Ориону
4. Орион отвечает **голосом корабля** (TTS) на изучаемом языке
5. Пилот слышит ответ, повторяет, Орион корректирует произношение

**Ключевые возможности:**

| Возможность | Описание |
|-------------|----------|
| **Распознавание речи** | Vosk STT (локально, офлайн) — пилот говорит, корабль слышит |
| **Озвучка ответа** | Windows TTS — Орион отвечает голосом |
| **Коррекция произношения** | Орион отмечает ошибки и объясняет как правильно |
| **Уровень сложности** | Орион адаптирует ответ: от простых фраз до свободного разговора |
| **Словари и темы** | Орион знает, какие слова пилот учит (из модуля английского) |
| **Режим «сцена»** | Орион предлагает ситуации: «закажи кофе», «спроси дорогу» |

**Режимы диалога:**

- **Свободный разговор** — пилот говорит что хочет, Орион отвечает
- **Урок** — Орион ведёт урок: объясняет, спрашивает, проверяет
- **Сцена** — ролевая игра: пилот и Орион в ситуации (кафе, аэропорт, магазин)
- **Проверка** — Орион диктует слова, пилот произносит, Орион проверяет

**Чего нет в бесплатной версии:**
- Голосовой ввод/вывод работает только на текущем языке интерфейса
- Орион отвечает на языке корабля, а не на изучаемом

**Почему платно:**
- STT/TTS требуют ресурсов (модели Vosk, качество голоса)
- Уровень адаптации Ориона к пилоту — это отдельная логика
- Словари и темы — синхронизация с модулем английского

## 5. Чего Орион не должен делать (границы)

- **Не хранить секреты** — ключи провайдеров, токены, коды снаружи (D16)
- **Не менять корабль молча** — Командир спрашивает, остальные не могут
- **Не удалять данные** — без явного подтверждения пилота
- **Не ломать обновление** — если обновление критично, уточнить один раз
- **Не выдавать себя за человека** — Орион — бортовой разум, а не пилот

## 6. Сценарий заселения агента (целевой)

### 6.1. Общий флоу

1. **Пилот выбирает профиль** — обычный экран входа
2. **Окно выбора ИИ-агента** — появляется после входа (если агент уже прописан на компьютере)
3. **Пилот выбирает агента** — видит список заселённых агентов, выбирает одного
4. **Вход на борт** — если пилот не меняет агента, входит с действующим

### 6.2. Для Командира

- Может выбрать **другого агента**, чем был при последнем выходе
- Может **заселить нового** агента (кнопка «Заселить нового»)
- Может **привязать** агента к OpenCode (токен, 代码 заселения)
- Если не хочет менять — входит с действующим агентом

### 6.3. Для обычного игрока

- Если **есть агент** — заселяет с правами по уровню доступа (Экипаж / Наблюдатель)
- Если **нет агент** — открывается возможность приобрести ИИ-агента (витрина сервисов)
- Если **не хочет** — входит без ИИ-агента (стандартный Орион)

### 6.4. Стандартный Орион (без ИИ-агента)

- Всегда на борту, всегда активен (если не выбран другой)
- Работает без OpenCode CLI — только базовые функции (беседа, обучение)
- Права — Экипаж (только беседа)
- Не имеет доступа к файлам, командам, поиску

## 8. Куда развиваться (этапы)

### Готово
- Заселение агента, права на входе, чат, голос, память диалога
- Документ манер, документ заданий, отметка `[КОРАБЛЬ]`
- Права Командира по коду владельца
- Эволюция характера (6 уровней)

### Следующие шаги
- **Инициатива** — Орион сам начинает разговор («пилот, ты давно не печатал»)
- **Реакция на события** — комментирует действия пилота в реальном времени
- **Краткая память по пилоту** — сводки: «вчера ты учил 50 слов»
- **Duck-радио** — фоновый юмор при озвучке
- **Онлайн-версия** — бортовой агент за счёт сервиса (без ключа у пилота)

## 8. Привязка агента к кораблю (реализовано)

### 8.1. Коды доступа и токены

Корабль генерирует одноразовый код для заселения агента (`make_boarding_code` — 8 символов).
Пилот вводит его в OpenCode CLI. После этого:

1. Пилот выбирает агент → доступ → «ПРИВЯЗАТЬ»
2. Корабль показывает панель: код для заселения, поле для токена OpenCode, статус
3. Пилот вводит токен OpenCode CLI
4. Корабль проверяет токен (запускает `opencode run` с простым запросом)
5. Для Командира дополнительно проверяет GitHub API (write-доступ к репозиторию)
6. Статус: привязан / не привязан / проверка...

**Файл:** `stamina/orion.py`: `save_binding`, `read_binding`, `clear_binding`,
`binding_status`, `make_boarding_code`, `check_opencode_token`, `check_github_access`.

### 8.2. Условия для Командира

Для получения прав Командира нужны три условия:

1. Код владельца корабля (`owner_key.py`)
2. Валидный OpenCode токен
3. GitHub-токен с write-доступом к репозиторию `StarTyping/My_Stamina`

Проверка — `check_github_access` через GitHub API (`permissions.push` или `permissions.admin`).

## 9. Эволюция характера (реализовано)

Орион развивается от общения с пилотом. Уровень зависит от количества реплик диалога.

| Уровень | Название | Порог | Поведение |
|---------|----------|-------|-----------|
| 1 | Знакомство | 0+ | Вежлив, сдержан, короткие ответы |
| 2 | Привыкание | 10+ | Шутит, спрашивает как дела, рассказывает о звёздах |
| 3 | Характер | 30+ | Спорит, комментирует действия пилота, имеет мнение |
| 4 | Свой голос | 60+ | Сарказм, инициирует разговор, если пилот молчит |
| 5 | Спутник | 100+ | Знает привычки, напоминает о заданиях |
| 6 | Незаменимый | 200+ | Друг, равный, шутит о космосе и жизни |

**Как работает:** `character_block` автоматически добавляет правила эволюции
(`EVOLUTION_RULES`) в блок `[ЭВОЛЮЦИЯ ХАРАКТЕРА]` перед каждой репликой агента.

**Файл:** `stamina/orion.py`: `evolution_level`, `evolution_name`, `evolution_status`,
`evolution_manner`, `character_block`.

## 10. Режим мастера — активный ок (реализовано)

**Триггеры:** «нужен мастер», «позови мастера», «что это», «как это работает», «где это».

**Как работает:**

1. Пилот говорит триггер (голосом или текстом)
2. Орион переходит в режим активного ока
3. Корабль отслеживает курсор мыши каждые 500 мс
4. Определяет текущий раздел и элемент под курсором
5. Раз в 10 секунд запускает анализ через агента (`orion-recon`)
6. Орион даёт подсказки в реальном времени

**Выход:** скажи «стоп».

**Файл:** `stamina/orion.py`: `detect_master_call`, `mouse_position_text`.
**Файл:** `stamina/orion_screen.py`: `_enter_master_mode`, `_track_mouse`,
`_analyze_mouse_position`, `_element_at`, `_exit_master_mode`.

## 12. Отправка задач внешнему агенту (реализовано)
