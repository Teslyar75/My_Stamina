# ОРИОН — бортовой разум: идея, статус десктопа, будущее

Документ для настольной сборки Star Typing ([My_Stamina](https://github.com/Teslyar75/My_Stamina)).  
Родственный веб-сервис (гид **уже работает**, включая голосовой вызов): [Wed_Star_Typing_Version](https://github.com/Teslyar75/Wed_Star_Typing_Version) → полный текст: [`docs/ORION_VISION.md`](https://github.com/Teslyar75/Wed_Star_Typing_Version/blob/web_star_typing_version/docs/ORION_VISION.md).

Цель — чтобы на звездолёт **хотелось возвращаться** не только ради слепой печати и музыки, а ради живого компаньона на мостике.

---

## Цель

Орион — вежливый дворецкий с сухой иронией: иногда скучает и сам вмешивается; по вызову слушает пилота и выполняет поручения; позже — ИИ-агент с памятью по пилоту и подпиской.

## Примеры взаимодействия (как на вебе; цель паритета на десктопе)

Полные сценарии — в веб-доке. Кратко:

1. **Знакомство** — Орион представляется, Enter/Esc.
2. **Скука** — сам предлагает анекдот; Enter — да, Esc — не сейчас.
3. **Радио** — приглушает эфир, предлагает шутку.
4. **Вызов** — кнопка ОРИОН → *«Да, я тут, сэр. Что-то нужно?»* → микрофон.
5. **«Дай шутку»** — рассказывает анекдот.
6. **«Смени волну»** — следующая станция из избранного.
7. **Рекорд / звание / ошибки / long break** — короткие реплики на события.

## Десктоп — в планах (порт с веба)

1. Пакет `stamina/guide/`: логика, JSON реплик, tkinter-окно, состояние на пилота.
2. Welcome + Настройки «Гид» + события мостика.
3. Шутки ~10 мин, duck радио при TTS.
4. Кнопка вызова Ориона в хроме (рядом с полноэкраном / слайдами): приветствие → микрофон (Vosk) → те же команды.
5. Тесты pytest; этот документ → «сделано».

До порта пользуйтесь [веб-версией](https://github.com/Teslyar75/Wed_Star_Typing_Version).
