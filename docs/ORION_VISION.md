# ОРИОН — бортовой разум: идея, статус десктопа, будущее

Документ для настольной сборки Star Typing ([My_Stamina](https://github.com/Teslyar75/My_Stamina)).  
Родственный веб-сервис (гид **уже работает**): [Wed_Star_Typing_Version](https://github.com/Teslyar75/Wed_Star_Typing_Version) → [`docs/ORION_VISION.md`](https://github.com/Teslyar75/Wed_Star_Typing_Version/blob/web_star_typing_version/docs/ORION_VISION.md).

Цель — чтобы на звездолёт **хотелось возвращаться** не только ради слепой печати и музыки, а ради живого компаньона на мостике.

---

## Цель

Орион — не «подсказка по таймеру», а персонаж:

- вежливый дворецкий с сухой иронией;
- иногда **скучает** и сам вмешивается в тишину или в радио, чтобы поговорить с *этим* пилотом;
- запоминает контекст именно этого пилота (позже — через ИИ);
- помогает с английским и другими занятиями на борту.

В перспективе: **подписка на ИИ-агента** (ChatGPT или аналог), который живёт в звездолёте, общается с разными пилотами, помнит темы разговоров с каждым и развивается вместе с ними.

## Десктоп — в планах (порт с веба)

Когда возьмёмся за реализацию:

1. Пакет `stamina/guide/`: логика показа (`can_show`, кулдауны, шутки), JSON персоны/реплик (из веб-`packages/guides/`), состояние на пилота, окно tkinter (**Enter** / **Esc** / **Shift+Esc** / **V**).
2. Врезка: welcome (выбор гида), Настройки → «Гид», события мостика (звание, рекорд, ошибки, long_break).
3. Таймер предложения анекдота ~раз в 10 мин; при речи гида — приглушение радио (как duck на вебе).
4. Тесты pytest на чистую логику; обновить этот документ и README: «сделано» вместо «в планах».

До порта пилоты десктопа пользуются Орионом в [веб-версии](https://github.com/Teslyar75/Wed_Star_Typing_Version).

## Будущее (общее для веба и десктопа)

1. Свободный диалог на мостике (не только односторонние окна).
2. Память тем разговоров по позывному.
3. Подписка на ИИ-сервис за биллингом; без подписки — скриптовый Орион.
4. Английский и другие зоны через разговор с компаньоном.
5. Адаптация тона и частоты вмешательств под пилота.
