# Вкладка «АНГЛИЙСКИЙ» в Star Typing

> Обучение английскому встроено вкладкой в тренажёр печати Star Typing (Python + Tkinter). Внешний вид — [ENGLISH_DESIGN.md](ENGLISH_DESIGN.md), формат и источники словаря — [ENGLISH_DATA.md](ENGLISH_DATA.md).

## 1. Как это устроено

| Что | Где |
|---|---|
| Код вкладки (пакет Python) | `stamina/english/` |
| Словарь | `stamina/english/data/vocab.json` (если нет — встроенный пробный `stamina/english/sample_vocab.json`) |
| Модель распознавания речи Vosk | `models/vosk-model-small-en-us-0.15` (в git не хранится, скачивается `python scripts/download_vosk_model.py`) |
| Прогресс | `%APPDATA%\Stamina\english.json` (рядом с данными Star Typing) |
| Подключение в Star Typing | `stamina/english_hook.py` + несколько строк в `stamina/cockpit.py` |
| Журнал ошибок подключения | `%APPDATA%\Stamina\english_error.log` |

- Star Typing при запуске импортирует пакет `stamina.english`. Если модуль падает при загрузке, вкладка просто не появляется, а Star Typing работает как раньше; причина пишется в `english_error.log`.
- Вкладка стоит между БОРТЖУРНАЛ и НАСТРОЙКИ, горячая клавиша Ctrl+5 (НАСТРОЙКИ становятся Ctrl+6). При шести вкладках надписи на кнопках верхнего меню на 1 пт меньше, чтобы всё поместилось.
- Компоненты и цвета берутся прямо из Star Typing (`stamina.theme`, `stamina.hud`: HudButton, HudPanel, RingGauge, SegmentBar, Readouts). Новых цветов и шрифтов нет.
- Опыт (XP) из «Английского» добавляется к общему опыту Star Typing и двигает те же звания (Кадет → … → Адмирал флота). В журнал заездов печати ничего не пишется. Отключается в настройках вкладки («XP идёт в звание Star Typing»).
- Озвучка: голос Windows Microsoft Zira (en-US) через PowerShell System.Speech, без интернета.
- Распознавание речи: Vosk + sounddevice, без интернета (`pip install vosk sounddevice` и `python scripts/download_vosk_model.py`). Если библиотек, модели или микрофона нет, вместо микрофона показываются кнопки самооценки.

## 2. Подразделы вкладки

| Подраздел | Что там |
|---|---|
| ОБЗОР | Курс на сегодня (кольцо дневной цели, к повторению, новых доступно, серия), «Начать занятие», «Быстрая миссия · 10», 4 сектора-набора с прогрессом, телеметрия пилота (уровень, звание Star Typing, серия 14 дней), слово дня |
| ЗВЁЗДНЫЕ КАРТЫ | Наборы S-1000/3000/10K/20K, поиск, фильтры (знаю/не знаю/на повторении, длина, сложность, часть речи), сортировка, перемешать, плитки слов (⟳ перевернуть, ✓ знаю, ⊞ в отсек), «учить карточками», «миссия по набору» |
| СКАНЕР | Карточка слова: озвучка (обычно/медленно), анализ произношения (IPA, слоги, как произносить, заметки), определение, пример, «мой перевод», ЗНАЮ, В ОТСЕК, В ПРОВЕРКУ СИСТЕМ, кнопки миссий по слову, **канал связи: практика предложений с микрофоном** |
| МИССИИ | 4 режима: случайная, говорение (S1–S3), чтение (R1–R3), вопросы (Q1–Q4); источник слов (набор, отсек, на повторении, ошибки 7 дней), длина 5/10/20; телеметрия (точность, время, ошибки, серия, XP); отчёт о полёте со звёздами, «повторить ошибки» |
| ПРОВЕРКА СИСТЕМ | Флеш-карточки SM-2: СНОВА/ТРУДНО/ХОРОШО/ЛЕГКО (1–4), показ интервала, обратные карточки, «добавить 10 новых» |
| СКЛАД КАРТОЧЕК | Выученные слова: русский на экране → английский вслух; галочки сложности; подсказка (удержание = EN); 🔊 EN; звёзды; отсеки НА СКЛАДЕ / В РАБОТЕ / ОТРАБОТАНО. Описание: [WAREHOUSE_CARDS.md](WAREHOUSE_CARDS.md) |
| ОТСЕКИ | Мои списки: «Избранное» + свои; создать, переименовать, удалить, убрать слово, карточки и миссия по отсеку, экспорт CSV, импорт слов из .txt |
| ЖУРНАЛ | Уровень, XP, звание, серия, освоение наборов, точность по режимам, активность за 12 недель, 12 знаков отличия, ошибки за 7 дней |
| НАСТРОЙКИ | Скорость озвучки, тест голоса, автоозвучка, распознавание вкл/выкл + состояние + тест микрофона, самооценка, текущий набор, дневная цель, новых в день, длина миссии, обратные карточки, перевод примеров, XP в звание, экспорт/импорт/сброс прогресса, открыть папку |

Не делается (решение пользователя): задания на слух, диктант, письменная проверка.

## 3. Проверка произношения предложения и процент совпадения

1. Пользователь нажимает «🎤 ПЕРЕДАЧА» (или M) и читает предложение вслух. Запись останавливается сама после паузы (не дольше 9 с).
2. Vosk выдаёт до 5 вариантов распознавания. Каждый сравнивается с образцом по словам (выравнивание, как в diff): слово засчитано при сходстве ≥ 0,8; изучаемое слово и короткие слова (до 3 букв) — только при точном совпадении. Берётся лучший вариант.
3. **Совпадение, %** = засчитанные слова / слова образца × 100. Если изучаемое слово не распознано, совпадение не выше 59 %.
4. Результат показывается крупной HUD-плашкой `MatchReadout` (`stamina/english/ui.py`):
   - «СОВПАДЕНИЕ: 86%» крупными цифрами и вердикт: ≥ 85 % ОТЛИЧНО (зелёный), 60–84 % ХОРОШО (янтарный), < 60 % ЕЩЁ РАЗ (красный);
   - шкала из 20 сегментов с отметками 60 % и 85 %;
   - строка «слов засчитано 5 / 7 · пропущено: no, rush · услышано: «…»», плюс пометка, если не распознано ключевое слово;
   - в самом предложении засчитанные слова подсвечиваются зелёным, пропущенные — красным с подчёркиванием.
5. При самооценке (нет распознавания) та же плашка показывает «САМООЦЕНКА: 90%».
6. Где работает: СКАНЕР → «Канал связи» и задания говорения в МИССИЯХ (S1 — слово, S2 — прочитать предложение, S3 — перевести вслух). XP: в сканере +5 (≥ 85 %) или +3 (≥ 60 %) один раз в день за предложение; в миссии +10/+5 за задание.

## 3а. Озвучка, индикаторы и перевод

- **Почему голос молчал.** `tts.py` писал команды в PowerShell через текстовый канал, Windows превращала `\r\n` в `\r\r\n`, и PowerShell получал лишнюю пустую строку сразу после фразы. На каждую строку скрипт вызывал `SpeakAsyncCancelAll()`, поэтому фраза отменялась через миллисекунды, без звука и без ошибки. Теперь канал двоичный, пустые строки пропускаются, а PowerShell сообщает `START / DONE / CANCEL / ERR` по каждой фразе.
- **Кнопки озвучки** (ГОЛОС, МЕДЛЕННО, ОБРАЗЕЦ, ТЕСТ) создаются через `ctx.audio_button(...)`: при нажатии кнопка светится янтарным и пишет «▶ ЧИТАЕТ…», пока голос не договорит. При ошибке на 2 с появляется «ОШИБКА ЗВУКА», причина пишется в строку состояния внизу окна. Если голос не начал говорить за 10 с, это тоже ошибка.
- **Микрофон (ПЕРЕДАЧА):** «● СЛУШАЮ…» (красный) и живая 20-сегментная шкала громкости по RMS сигнала, затем «◌ РАСПОЗНАЮ…» (янтарный), затем результат и СОВПАДЕНИЕ %. Если за запись уровень ни разу не поднялся выше порога, выводится «Микрофон не слышит звук — проверьте устройство ввода…». Тест микрофона в настройках тоже показывает уровень.
- **Перевод слов:** поле `ru` в `vocab.json`. «МОЙ ПЕРЕВОД» заполнен им заранее; собственный вариант пользователя главнее и хранится в `english.json` (`Progress.tr()` = свой или словарный, `Progress.my_tr()` = только свой).
- **F1 на вкладке** открывает справку Star Typing сразу на главе «12. АНГЛИЙСКИЙ».

## 5. Как убрать вкладку

Удалить (или переименовать) папку `stamina/english`: `english_hook.load_class()` вернёт `None`, и Star Typing покажет пять прежних вкладок. Прогресс в `%APPDATA%\Stamina\english.json` при этом не трогается.
