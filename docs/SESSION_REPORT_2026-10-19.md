# Отчёт о проделанной работе — 19 октября 2026

## Реализованные функции бортового ИИ «Орион»

### 1. Привязка агента к OpenCode
- Корабль генерирует одноразовый код заселения (8 символов)
- Панель в карточке агента: код, токен OpenCode, статус связи
- Проверка токена через `opencode run` с простым запросом
- Для Командира: проверка GitHub API (write-доступ к репозиторию)
- Условия для Командира: код владельца + токен OpenCode + GitHub-токен

### 2. Эволюция характера Ориона
- 6 уровней развития (от количества репилок диалога: 0, 10, 30, 60, 100, 200)
- Уровень 1: Знакомство → Уровень 6: Незаменимый
- Правила эволюции автоматически добавляются в блок `[ЭВОЛЮЦИЯ ХАРАКТЕРА]`
- Отображение в карточке агента: «УРОВЕНЬ N · Название · Реплик: M»

### 3. Режим мастера (активный ок)
- Триггеры: «нужен мастер», «позови мастера», «что это», «как это работает»
- Отслеживание курсора мыши каждые 500 мс
- Анализ элемента под курсором и текущего раздела
- Подсказки через агента каждые 10 секунд
- Выход: скажи «стоп»

### 4. Доступ к радиорубке и библиотеке
- **Радиорубка**: переключение волны, громкость, включение/выключение через команды в ответе агента
- **Библиотека**: чтение книг вслух из библиотеки корабля
- Доступ для любого пилота с агентом, но не для стандартного Ориона

### 5. Кнопка «ВЫПОЛНИТЬ» — реальные права
- При втором проходе в промпт добавляется «РАЗРЕШЕНИЕ: Командир разрешил изменения»
- Агент реально вызывает edit/write/bash после разрешения

### 6. Ложные запросы разрешения исправлены
- Только структурные признаки: `type="permission"`, `state="denied"`, `tool_use.status="error"`

### 7. Запрет MCP-инструментов
- `orion-recon.md` и `orion-chat.md`: `pencil: false`, `mcp: false`
- Режим доклада не имеет доступа к инструментам записи

### 8. Орион — гид по умолчанию
- При входе в любой отсек автоматически приветствует пилота
- Рассказывает что происходит в текущем окне (через page_help)
- Невидимый, но активный — говорит через TTS

### 9. Копирование и вставка в чате
- Копирование текста из чата: правый клик или Ctrl+C
- Вставка текста в строку сообщения: Ctrl+V или правый клик
- Контекстное меню: «Вставить» / «Копировать»

### 10. Диалог выбора агента после входа
- Кнопка «Заселить агента» на экране входа
- После выбора пилота появляется диалог выбора агента
- Выбор сохраняется, изменить можно позже
