# Задача для Cursor: переделать читалку (Star Typing, `D:\My_New_Stamina`)

Образцы лежат рядом с этим файлом: `ref_readest_dark.png`, `ref_readest_annotations.png`, `ref_readest_tts.png` (читалка Readest, https://github.com/readest/readest, документация по режимам https://readest.com/docs/reading).
Как выглядит сейчас у нас: `our_current.png`.

## Что сейчас плохо (см. our_current.png)
1. Текст режется на обрывки. Переносы строк из исходного файла (книги из Гутенберга с жёсткими переносами примерно через 70 символов) выводятся как отдельные абзацы. Получаются «лесенки»: строка, перенос, кусок, большой пробел.
2. Большие пустые поля, на странице мало текста, нижняя треть пустая.
3. Абзацы не отличаются от строк: нет отступа первой строки и нормальных интервалов.
4. Кнопки панели («1», «РАЗВ.», «D», «P», «S») ничего не говорят без подписей и подсказок.

## Что сделать
### Текст
- Перед вёрсткой склеивать жёсткие переносы. Одиночный `\n` превращать в пробел, абзацем считать только пустую строку (`\n\n`). Слово с дефисом на конце строки (`exam-\nple`) склеивать в одно. Брать оригинальный текст из библиотеки, а не подготовленный для набора.
- Делать выключку по ширине (justify) или выравнивание по левому краю, без рваных обрывков. Ставить отступ первой строки абзаца и небольшой интервал между абзацами.
- Межстрочный интервал около 1.4–1.5, нормальный шрифт с засечками (Georgia, Cambria, Literata, если он есть).

### Режимы
- **1 страница** — одна колонка по центру, ширина около 60–75 символов в строке.
- **Разворот (2 страницы)** — две колонки, как в Readest и Apple Books в горизонтальном режиме. Колонки заполняются ПОЛНОСТЬЮ: текст перетекает с левой страницы на правую, затем на следующий разворот. Между колонками узкий корешок.
- **Прокрутка** — непрерывный текст (по желанию).
- Пагинация считается по реальной высоте текста в окне (измерять через `font.metrics` / `bbox` в Tkinter) и пересчитывается при изменении размера окна или шрифта. Текущая позиция в книге при этом сохраняется.

### Интерфейс (в стиле нашей панели звездолёта)
- Верхняя панель: назад к библиотеке, название и автор, кнопки шрифта A−/A+, переключатель «1 стр / Разворот / Прокрутка» понятными словами (не «D», «P», «S»), темы (Бумага / Ночь / Сепия), оглавление.
- Нижняя строка: прогресс в процентах, страница из числа страниц, время до конца главы (по средней скорости).
- Панели скрываются при чтении и появляются по наведению или по клавише.
- Клавиши: стрелки или PageUp/PageDown листают, Home/End, `+`/`-` меняют шрифт, `Shift+J` переключает режим, Esc выходит. Для каждой кнопки подсказка при наведении.
- Сохранять позицию чтения для каждого пилота и книги, общую с прогрессом скорочтения и набора.
- Все подписи через i18n (ru/uk/en/de).

## Шаг 0
Найди в проекте модуль читалки (это окно на our_current.png). Проверь, откуда он берёт текст (оригинал или подготовленный) и как строит страницы. Только после этого начинай.
