# Лаборатория · созвездия знаний — план и прототип

Отсек «Лаборатория» — граф знаний пилота в духе Obsidian. **Звёзды** — реально выученное, **рёбра** — только реальные связи. Звёзды тускнеют без практики, но никогда не исчезают. В центре — **сущность** (живой сгусток): при регулярной практике пульсирует и переливается, после перерыва затихает в тумане — без наказания и без потери знаний.

Сущность потом летит в роботе-терраформере с ИИ-агентом; её данные (полный слепок) определяют облик планеты.

## 1. Источники данных (только чтение, папка пилота)

| Файл | Что берём |
|---|---|
| `english.json` | `words[slug].known/known_at`, `cards[slug]` (SM-2: `interval`, `reps`, `last`), `quality[slug].slots` (в том числе `verb:<slug>`), `verb_scores`, `xp.by_day`, `book_sentences` |
| `stats.json` | `runs[]` (дни практики, cpm/acc), `missions{id: stars, best_cpm, best_acc}` |
| `speedread.json` | `sessions[]` (`title`, `eff_wpm`, `day`), `exercises[ex][variant].runs[]`, `days` |
| `library/library.json` | `texts[{id, title, author}]` — названия книг |
| справочники приложения | `english/data/sets/cefr_*.json` (уровень и тема слова), `english/data/verbs/irregular.json` (V2/V3) |

**Пробелы в данных:**
- у слова нет ссылки на книгу, кроме отработанных предложений из книги;
- позиция чтения в книге не используется;
- для глаголов не из списка неправильных формы не строятся;
- у части элементов нет даты практики — для них яркость фиксирована на 0.55.

## 2. Модель (`stamina/lab_data.py`)

У узла есть поля `id`, `kind`, `skill` (en/read/type), `group` (созвездие), `label`, `detail`, `last` (дата), `strength`, `fresh`.

**Виды узлов:** word, verb, form, book, milestone, exercise, mission, cluster.

**Рёбра:** глагол→форма; книга→слова из предложений; цепочки рубежей/миссий.

**Свежесть:** `fresh = FLOOR + (1 − FLOOR)·exp(−Δдней / S)`, `S = 3·(1 + strength)^1.3`, `FLOOR = 0.28`.

**Сущность:** `vitality` за 14 дней; после 2 тихих дней гаснет (минимум 0.08); `growth = log1p(число звёзд)`.

**Выбор звезды (рабочий уровень):** `star_neighborhood(graph, id, limit=20, offset=…)` — выбранный узел (`detail_level=full`) + порция **1-hop** соседей (`compact`). «Показать ещё» увеличивает offset. Кэш на экране; смена выбора инвалидирует token.

## 3. Три уровня детализации

### 3.1. Визуальный (по умолчанию)

- Только кластеры/агрегаты (`collapse_to_clusters`), без отдельных слов.
- Живая сущность; idle-автоповорот (yaw); свой фон-туманность на Canvas.
- Клик по кластеру → рабочий уровень.

### 3.2. Рабочий (частичный)

- `fragment_of(full, group)` — узлы созвездия + соседи по рёбрам.
- **Выбор звезды (клик без драга):** лениво подгружаются детали **этого** объекта и **прямых** связей (1-hop), порциями по 20; остальное не грузится.
- Подсветка выбранного + рёбер; соседи — компактно; остальное тускнеет.
- Кнопка **«Показать ещё»** / API с offset; кэш фрагментов; отмена устаревшей загрузки при смене выбора.
- **Назад** → визуальный уровень.

### 3.3. Полный слепок (отдельный запрос)

- Кнопка **«Полный слепок»** / `iter_snapshot` / `export_snapshot`.
- Чанки (`SNAPSHOT_CHUNK = 200`), прогресс, отмена → JSON для Ориона.
- Данные пилота только читаются.

## 4. Камера и взаимодействие

| Жест | Действие |
|---|---|
| **Ctrl + колёсико** | Зум к точке курсора (clamp `ZOOM_MIN…ZOOM_MAX`). Win: `<MouseWheel>`+state; Linux: Button-4/5. Без Ctrl — прежнее поведение. |
| **ЛКМ drag** | Орбита: горизонталь = yaw, вертикаль = pitch (clamp ±`PITCH_MAX`). Лёгкая инерция. |
| **Короткий клик** (< `DRAG_CLICK_PX`) | Выбор (не орбита): на visual — фрагмент; на work — звезда + 1-hop. |
| **1∶1** / **Ctrl+Home** | Сброс вида (зум/pan/yaw/pitch). **Не Ctrl+0** — он занят зоной «Лаборатория». |

Проекция: лёгкая 3D (`rotate_xyz` → depth-scale на Canvas). Размер/яркость звёзд зависят от глубины. Зум/орбита **не** перезагружают данные — только `coords` с throttle ~33 мс.

## 5. Визуал и раскладка

- Цвета: EN=`CYAN`, read=`AMBER`, type=`GREEN`, сущность=`PURPLE`.
- Раскладка 3D: английский — полумесяц; книги — центры, слова веером; печать — рукав; Z — объём.
- Новые звёзды влетают из центра (≤60); `lab.json` — seen; демо ничего не пишет.

## 6. Рендеринг

Tk Canvas; кадр 33 мс; LOD анимации по бюджету 22 мс; ≤1600 звёзд / ≤900 рёбер; таймер стоит, когда отсек скрыт.

## 7. Навигация и i18n

- Зона `lab`, **Ctrl+0** (навигация). Сброс вида — **Ctrl+Home** + кнопка **1∶1**.
- Демо: `lab_demo.bat` / `lab_demo.sh` / `STAMINA_LAB_DEMO=1`.

1. Прототип — сделано.
2. Три уровня + сущность — сделано.
3. Зум Ctrl+wheel, 3D-орбита, выбор + 1-hop — сделано в этой ветке.

## 9. Риски

- Старый Canvas / 150 % DPI — visual + throttle + LOD.
- Большие профили — полный collect кэшируется на экране при первом рабочем/выборе.
- Неполные даты — яркость 0.55.
