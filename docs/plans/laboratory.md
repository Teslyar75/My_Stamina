# Лаборатория · созвездия знаний — план и прототип

Отсек «Лаборатория» — граф знаний пилота в духе Obsidian. **Звёзды** — реально выученное, **рёбра** — только реальные связи. Звёзды тускнеют без практики, но никогда не исчезают. В центре — **сущность** (живой сгусток): при регулярной практике пульсирует и переливается, после перерыва затихает в тумане — без наказания и без потери знаний.

Сущность потом летит в роботе-терраформере с ИИ-агентом; её данные (полный слепок) определяют облик планеты.

## 1. Источники данных (только чтение, папка пилота)

| Файл | Что берём |
|---|---|
| `english.json` | `words[slug].known/known_at`, `cards[slug]` (SM-2: `interval`, `reps`, `last`), `quality[slug].slots` (в том числе `verb:<slug>`), `verb_scores`, `xp.by_day`, `book_sentences` |
| `stats.json` | `runs[]` (дни практики, cpm/acc), `missions{id: stars, best_cpm, best_acc}` |
| `speedread.json` | `sessions[]` (`title`, `eff_wpm`, `day`), `exercises[ex][variant].runs[]`, `days` |
| `library/library.json` | `texts[{id, title, author}]` — названия книг |
| справочники приложения | `english/data/sets/cefr_*.json` (уровень и тема слова), `english/data/verbs/irregular.json` (V2/V3) |

**Пробелы в данных:**
- у слова нет ссылки на книгу, кроме отработанных предложений из книги;
- позиция чтения в книге не используется;
- для глаголов не из списка неправильных формы не строятся;
- у части элементов нет даты практики — для них яркость фиксирована на 0.55.

## 2. Модель (`stamina/lab_data.py`)

У узла есть поля `id`, `kind`, `skill` (en/read/type), `group` (созвездие), `label`, `detail`, `last` (дата), `strength`, `fresh`.

**Виды узлов:**
- `word` — слово выучено, если выполнено одно из условий: отмечено «знаю», SM-2 interval ≥ 21 или качество полное;
- `verb` и `form` — неправильный глагол и его формы V2/V3;
- `book` — книга;
- `milestone` — рубежи скорости чтения (150/200/250… сл/мин) и печати (CPM/точность);
- `exercise` — упражнение;
- `mission` — миссия;
- `cluster` — агрегат созвездия (визуальный уровень).

**Рёбра:**
- глагол → его форма;
- книга → слова, отработанные в предложениях этой книги (не больше 40 на книгу);
- книга → рубеж чтения;
- миссия → рубеж печати;
- рубежи связаны цепочкой.

Внутри созвездия контурные рёбра строит раскладка; это рисунок, а не данные.

**Свежесть:** `fresh = FLOOR + (1 − FLOOR)·exp(−Δдней / S)`, где `S = 3·(1 + strength)^1.3` дней и `FLOOR = 0.28`. Яркость звезды никогда не опускается ниже FLOOR.

**Сущность:**
- `vitality` = активные дни за последние 14 / 14;
- после 2 тихих дней множитель `0.5^((тихие − 2)/4)`, минимум 0.08;
- `growth = log1p(число звёзд)`.

## 3. Три уровня детализации

Систему не нагружаем: по умолчанию на холсте только агрегаты; детали — по клику; полный слепок — редкий явный запрос.

### 3.1. Визуальный (по умолчанию)

- API: `collect` → `collapse_to_clusters` (экран: `LabScreen.mode = visual`).
- На карте — кластеры по созвездиям (CEFR/тема, глаголы, книги, рубежи), **без отдельных слов**.
- Живая сущность в центре плавно переливается и движется; звёзды слегка пульсируют от свежести.
- Свой фон отсека — процедурная туманность на Canvas (не чужие панорамы).
- Плавно на слабых машинах: мало объектов + LOD анимации по бюджету кадра.

### 3.2. Рабочий (частичный)

- Клик по кластеру / книге / рубежу → `fragment_of(full, group)`.
- Лениво подгружаются **только** узлы этого фрагмента (слова, книги, свежесть, связи) + соседи по рёбрам.
- Зум и лёгкий pan к навыку; кнопка **«Назад»** возвращает на визуальный уровень.
- Остальные созвездия в память экрана не разворачиваются.

### 3.3. Полный слепок (отдельный запрос)

- Кнопка **«Полный слепок»** / API `iter_snapshot` / `export_snapshot`.
- Сборка **чанками** (`SNAPSHOT_CHUNK = 200`) с прогрессом и отменой.
- JSON (`kind: lab_entity_snapshot`, version 1): `entity`, `counts`, `nodes` (+ `fresh`), `edges`, `gaps`.
- Назначение — контекст сущности и ИИ-агента (Орион) при создании мира. Пилоту нужен редко.
- Данные пилота только читаются; пишется выбранный пилотом файл экспорта (и при визитах — собственный `lab.json` со списком увиденных id).

## 4. Визуал и раскладка

- **Цвета** берутся из темы: английский — `CYAN`, чтение — `AMBER`, печать — `GREEN`, сущность — `PURPLE` с переливом.
- **Раскладка:**
  - английский — **полумесяц** слева (открыт к сущности);
  - чтение — книги как центры, слова **веером** от книги;
  - печать — рукав справа-снизу.
- **Звёзды:** размер = вид × свежесть × пульс; цвет смешивается с фоном по свежести; карта медленно дышит поворотом.
- **Сущность:** сгусток из нескольких оболочек + орбитали навыков; после перерыва — тише и в тумане (без исчезновения).
- **Новые звёзды** (с прошлого визита) влетают из центра, не больше 60 за раз. Список увиденных — `<pilot>/lab.json`. В демо ничего не записывается.
- **Подсказка при наведении:** что это, созвездие, свежесть; на визуальном — «клик — открыть фрагмент».
- **Пустое состояние:** «Лаборатория ждёт первых знаний».

## 5. Рендеринг

Решение — **Tk Canvas**: раскладка считается один раз, каждый кадр обновляются только `coords`.

- Кадр — 33 мс (~30 fps).
- **LOD анимации:** если среднее время шага больше 22 мс, позиции пересчитываются через кадр, затем через 2, 3, 4 кадра; если время падает, LOD снижается обратно.
- **Ограничения:** больше 1600 звёзд — мелкие созвездия → туманности; рёбер ≤ 900; летящих ≤ 60.
- Таймер останавливается, когда отсек не текущий или скрыт.

**Замер на Linux/Xvfb** (демо: 1000 звёзд полного графа → визуальные кластеры, LOD 1): цель — стабильные ~30 fps при бюджете шага ≪ 22 мс.

## 6. Навигация и i18n

- Зона `lab` стоит в `nav.ZONE_ORDER` между Орионом и Настройками.
- Горячая клавиша: `nav.FIXED_HOTKEYS = {"lab": "0"}` → **Ctrl+0**. Настройки остаются на Ctrl+9.
- Глиф ✧ в профилях alt-UI.
- Строки переведены на ru/uk/en/de.
- Демо: `lab_demo.bat` или `STAMINA_LAB_DEMO=1`.

## 7. Фазы

1. **Прототип (сделано):** адаптер, демо-режим, экран, подсказка, влёт новых звёзд, тесты.
2. **Три уровня + сущность (сделано в этой ветке):** visual / work / full snapshot; живой сгусток; полумесяц и веера; свой фон; план и тесты.
3. **Полировка:** relax-проход раскладки; клик по звезде открывает слово/книгу/миссию в родном отсеке.
4. **Связи:** слова ↔ книги по тексту книги (индекс); пак «1000 глаголов» отдельным созвездием.
5. **Живость:** вспышка звезды сразу после тренировки (сигнал от отсеков, без опроса файлов).

## 8. Риски

- Медленный Canvas на старых Windows с масштабом 150 %+. Защита: визуальный уровень + LOD; запасной путь — PIL.
- Большие профили: полный `collect` при первом заходе в рабочий фрагмент кэшируется на экране; визуальный рисует только кластеры.
- Неполные даты практики: такие звёзды «серые» (0.55).
- Нагрузка в фоне: таймер останавливается, но это нужно проверить на Windows.
