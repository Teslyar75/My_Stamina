# Лаборатория · созвездия знаний — план и прототип

Отсек «Лаборатория» — граф знаний пилота в духе Obsidian. **Звёзды** — реально выученное, **рёбра** — только реальные связи. Звёзды тускнеют без практики, но никогда не исчезают. В центре — **сущность**: при регулярной практике она пульсирует, после перерыва затихает.

## 1. Источники данных (только чтение, папка пилота)

| Файл | Что берём |
|---|---|
| `english.json` | `words[slug].known/known_at`, `cards[slug]` (SM-2: `interval`, `reps`, `last`), `quality[slug].slots` (в том числе `verb:<slug>`), `verb_scores`, `xp.by_day`, `book_sentences` |
| `stats.json` | `runs[]` (дни практики, cpm/acc), `missions{id: stars, best_cpm, best_acc}` |
| `speedread.json` | `sessions[]` (`title`, `eff_wpm`, `day`), `exercises[ex][variant].runs[]`, `days` |
| `library/library.json` | `texts[{id, title, author}]` — названия книг |
| справочники приложения | `english/data/sets/cefr_*.json` (уровень и тема слова), `english/data/verbs/irregular.json` (V2/V3) |

**Пробелы в данных:**
- у слова нет ссылки на книгу, кроме отработанных предложений из книги;
- позиция чтения в книге не используется;
- для глаголов не из списка неправильных формы не строятся;
- у части элементов нет даты практики — для них яркость фиксирована на 0.55.

## 2. Модель (`stamina/lab_data.py`)

У узла есть поля `id`, `kind`, `skill` (en/read/type), `group` (созвездие), `label`, `detail`, `last` (дата), `strength`, `fresh`.

**Виды узлов:**
- `word` — слово выучено, если выполнено одно из условий: отмечено «знаю», SM-2 interval ≥ 21 или качество полное;
- `verb` и `form` — неправильный глагол и его формы V2/V3;
- `book` — книга;
- `milestone` — рубежи скорости чтения (150/200/250… сл/мин) и печати (CPM/точность);
- `exercise` — упражнение;
- `mission` — миссия.

**Рёбра:**
- глагол → его форма;
- книга → слова, отработанные в предложениях этой книги (не больше 40 на книгу);
- книга → рубеж чтения;
- миссия → рубеж печати;
- рубежи связаны цепочкой.

Внутри созвездия контурные рёбра строит раскладка; это рисунок, а не данные.

**Свежесть:** `fresh = FLOOR + (1 − FLOOR)·exp(−Δдней / S)`, где `S = 3·(1 + strength)^1.3` дней и `FLOOR = 0.28`. Яркость звезды никогда не опускается ниже FLOOR.

**Сущность:**
- `vitality` = активные дни за последние 14 / 14;
- после 2 тихих дней множитель `0.5^((тихие − 2)/4)`, минимум 0.08;
- `growth = log1p(число звёзд)`.

## 3. Визуал

- **Цвета** берутся из темы: английский — `CYAN`, чтение — `AMBER`, печать — `GREEN`, сущность — `PURPLE`.
- **Раскладка:** три спиральных рукава, по одному на навык. Созвездие — кольцо филлотаксиса, его центр смещается вдоль рукава.
- **Звёзды:**
  - размер = вид × свежесть;
  - цвет смешивается с фоном по свежести;
  - галактика медленно вращается.
- **Новые звёзды** (с прошлого визита) влетают из центра, не больше 60 за раз. Список увиденных хранится в собственном файле `<pilot>/lab.json`; это единственная запись отсека. При первом визите влёта нет. В демо-режиме ничего не записывается.
- **Подсказка при наведении:** что это, созвездие, «практика: N дн. назад», яркость в %.
- **Пустое состояние:** «Лаборатория ждёт первых знаний» и что сделать, чтобы появились звёзды.

## 4. Рендеринг

Решение — **Tk Canvas**: раскладка считается один раз, каждый кадр обновляются только `coords`.

- Кадр — 33 мс (~30 fps).
- **LOD:** если среднее время шага больше 22 мс, позиции пересчитываются через кадр, затем через 2, 3, 4 кадра; если время падает, LOD снижается обратно.
- **Ограничения:**
  - больше 1600 звёзд — мелкие созвездия сворачиваются в «туманности»;
  - рёбер не больше 900;
  - летящих звёзд не больше 60.
- Таймер останавливается, когда отсек не текущий или скрыт.
- **Запасной путь** (если на слабых машинах Canvas не справится): PIL рисует кадр в изображение, Canvas показывает одно изображение. Сейчас этот путь не нужен.

**Замер на Linux/Xvfb** (демо: 1000 звёзд, 900 рёбер, LOD 1):

| Окно | Шаг кадра, в среднем | Максимум | Кадров/с | CPU |
|---|---|---|---|---|
| 1280×720 | ~3.0–3.4 мс | 5–14 мс | ~27 (цель 30) | ~12 % |
| 1024×600 | ~2.9–3.2 мс | 5–21 мс | ~27 | ~10 % |

## 5. Навигация и i18n

- Зона `lab` стоит в `nav.ZONE_ORDER` между Орионом и Настройками.
- Горячая клавиша фиксирована: `nav.FIXED_HOTKEYS = {"lab": "0"}`, то есть **Ctrl+0**. Остальные зоны нумеруются по-прежнему, Настройки остаются на Ctrl+9.
- Глиф ✧ добавлен в профили alt-UI.
- Строки переведены на ru/uk/en/de; `tools/i18n_check.py` проходит без пропусков.
- Подписи тем в подсказке берутся на языке интерфейса: `topic` или `topic_en`.

## 6. Фазы

1. **Прототип (сделано):** адаптер, демо-режим (`STAMINA_LAB_DEMO=1`), экран, подсказка, влёт новых звёзд, тесты.
2. **Полировка:**
   - раскладка без наложений (relax-проход), отдельные «тела» созвездий;
   - зум и перетаскивание;
   - клик по звезде открывает слово, книгу или миссию.
3. **Связи:**
   - слова ↔ книги по тексту книги (нужен индекс текста);
   - пак «1000 глаголов» отдельным созвездием.
4. **Живость:** вспышка звезды сразу после тренировки (сигнал от отсеков, без опроса файлов).

## 7. Риски

- Медленный Canvas на старых Windows с масштабом 150 %+. Защита: LOD и ограничения; запасной путь — PIL.
- Большие профили (тысячи слов): агрегация в туманности теряет детали.
- Неполные даты практики: такие звёзды «серые» (0.55), и это может вводить в заблуждение.
- Нагрузка в фоне: таймер останавливается, но это нужно проверить на Windows.
