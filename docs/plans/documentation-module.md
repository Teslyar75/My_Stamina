# Модуль «Документация» — план (без кода)

Статус: черновик плана, база master `1143490`. Продукт не называем «Stamina», в UI пишем «Star Typing».
Примечание: `graphify-out/GRAPH_REPORT.md` в репозитории нет (есть только graph.json/manifest), поэтому навигация шла по коду.

## 2. MVP vs позже
**MVP:** список документов (несколько), редактор (Tk Text) с форматированием, диктовка ru/uk/en, вставка текста и картинок из буфера, изменение размера картинок, автосохранение, экспорт DOCX/HTML/TXT, «Отправить почтой» через почтовый клиент.
**Позже:** PDF, ODT, таблицы, поиск-замена с regex, шаблоны (письмо, протокол, отчёт), обрезка/стрелки на скринах, SMTP-отправка, проверка орфографии, голосовые команды («новая строка», «точка», «жирный»), импорт DOCX.

## 3. Формат документа
Рекомендация: **внутренний формат `.stdoc` = папка/zip с `doc.json` (абзацы, run-ы со стилями, ссылки на картинки + ширина) и `images/*.png`**; экспорт в DOCX (python-docx), HTML (стандартная библиотека, картинки base64), TXT, позже PDF.
| Вариант | + | − |
|---|---|---|
| Свой JSON+картинки (основной) | точное восстановление Tk-разметки, простые тесты, без зависимостей | не открывается в Word без экспорта |
| DOCX как основной | открывается везде | обратный разбор сложен и с потерями |
| HTML как основной | открывается в браузере | парсинг в Tk — велосипед |
| RTF | Word понимает | картинки в RTF неудобны |
| PDF | для отправки | только экспорт (reportlab или через HTML) |

## 4. Речь → текст
- Переиспользуем `MicControl` + `stt.Listener`; режим «диктовка»: фраза по паузе (`PhraseSplitter`) вставляется в позицию курсора, partial отображается серым inline-тегом и заменяется финалом.
- Языки: выбор ru/uk/en в панели (`find_model(prefer=lang)`); нужны модели `vosk-model-small-uk`, `-en-us` — докачка через `scripts/download_vosk_model.py` + строки в `deps.py`. Автопунктуации у Vosk нет → MVP: первая буква заглавная + точка по длинной паузе; голосовые команды пунктуации — фаза 3.
- Ключей API нет, всё офлайн.

## 5. Картинки: вставка и размер
- Ctrl+V: если в буфере картинка (`shots.grab_clipboard`) → сохраняем в `images/`, вставляем `Text.image_create` в курсор; иначе текст. Кнопка «Скрин окна» (как в Орионе), «Файл…», drag-and-drop путей (`shots.image_paths_in`).
- Размер: клик по картинке → выделение + контекстная плашка: 25/50/75/100 %, «по ширине страницы», ±10 % (Ctrl+колесо), поле «px»; ресайз Pillow `LANCZOS` для отображения, оригинал хранится, ширина пишется в документ. Перетаскивание угла мышью — позже (Tk embedded image не даёт ручек нативно).
- Двойной клик — `image_viewer.show`.

## 6. Редактирование
Жирный/курсив/подчёркнутый, H1/H2/обычный, маркированный/нумерованный список, выравнивание, отмена/повтор (`Text(undo=True)`, картинки — в своём стеке операций), найти/заменить (Ctrl+F/Ctrl+H), счётчик слов/символов, «прочитать вслух», вставка даты. Стили — Tk-теги, общая таблица стилей для экспорта.

## 7. Сохранение/экспорт
Автосохранение каждые N с в `%APPDATA%\…\docs\<id>.stdoc` (через общие paths), «Сохранить как…» (.stdoc/.docx/.html/.txt; позже .pdf/.odt), «Открыть папку». Добавить `docs/` в `backups.py`.

## 8. Почта
mailto не умеет вложения. Варианты:
1. **(Рекомендую для MVP)** «Отправить»: экспорт в DOCX/PDF во временную папку → Windows: открыть почтовый клиент с вложением через MAPI (`MAPISendMail` через ctypes, работает с Outlook/Thunderbird) с fallback: mailto (тема + текст в теле) + открыть папку с файлом выделенным в Проводнике. Linux: `xdg-email --attach`.
2. SMTP (позже): пользователь вводит сервер/логин/пароль приложения; пароль хранить через Windows Credential Manager (`keyring`), не в коде и не в json. Gmail требует app password.
3. Только «сохранить и открыть папку» — самый простой.

## 9. Хоткеи
Внутри редактора печать главнее: стандартные Ctrl-сочетания (Ctrl+B/I/U/Z/Y/F/H/S/V, Ctrl+Shift+V — вставить без форматирования, Ctrl+1/2/0 — заголовки), диктовка — F9 или Ctrl+M (одиночная M запрещена в поле ввода, проверка `typing_in`). Одиночные буквы M/T/O не используются. F1 — справка, Esc — выход из выделения картинки.

## 10. Новые зависимости
- `python-docx` (MIT, офлайн) — экспорт DOCX, опционально, проверка в `deps.py`.
- Позже: `reportlab` (PDF) или PDF через печать HTML; `keyring` для SMTP; `odfpy` для ODT.
- Pillow, vosk, sounddevice уже есть.

## Фаза 5 — Перевод документа (ru/uk → en/de)

Что: перевести весь документ или выделенный фрагмент; результат — новый документ
«<название> (EN)» или вставка под выделением. Картинки переносятся как есть.

Рекомендация: **Argos Translate (офлайн, бесплатно, без ключей)**.
- Пакеты моделей качаются по требованию (как модели Vosk): ru→en, uk→en, en→de;
  для ru/uk→de — цепочка через en (Argos умеет pivot). ~100 МБ на пару.
- Работает без интернета и не отправляет текст пилота наружу.
- Запасной путь уже есть: `stamina/translator.py` — бесплатный онлайн Google/MyMemory
  без ключей. Использовать как фолбэк, если модели не скачаны, и честно писать
  в статусе «перевод онлайн».
- Разбиение по абзацам, перевод в фоне (поток), прогресс в статусе, отмена.
- Тесты: заглушка движка; проверка, что сегменты-картинки не трогаются.

## Фаза 6 — ИИ-проверка: грамматика, стиль, качество перевода

Что: кнопка «ПРОВЕРИТЬ» — список правок с «принять/отклонить» по одной и «принять все».

Рекомендация: **переиспользовать подключение модели Ориона**, без нового кода связи.
- `stamina/orion.py` уже содержит `check_prompt`, `parse_fixes`, `apply_fixes` —
  тот же контур, что проверяет текст в чате. Документ проверяем по абзацам.
- Режимы: «грамматика», «стиль», «перевод» (оригинал + перевод → замечания по
  точности и терминам).
- Ключи и выбор модели — только из настроек Ориона (никаких ключей в коде);
  без подключённой модели кнопка неактивна с подсказкой, где подключить.
- Правки показываются подсветкой в тексте; отмена — штатным Ctrl+Z.
