# Английский: связи окон + раскладка

Эталон: `screenshots/living_space/tab_english*.png`, `screenshots/english/tab_*.png`  
Десктоп-хаб: `stamina/english/screen.py` (`show` / `open_word` / `start_session` / `start_review` / `open_book_cards`)  
Веб-хаб: `web_star_typing/frontend/src/english/EnglishPanel.tsx`

## 0. Хаб API (общее)

| Метод десктопа | Куда | Параметры |
| --- | --- | --- |
| `show(name)` | любая из 10 подвкладок | `overview…settings` |
| `open_word(slug)` | **сканер** | `back` = текущая вкладка (кроме самого сканера) |
| `start_session(mode, source, single?, ids?)` | **миссии** (полёт) | mode: random/speaking/reading/questions |
| `start_review(slugs?)` | **проверка систем** | список slug или due+new |
| `open_book_cards(tid?)` | **из книги** | focus_book + sync |
| нав-бейджи | review / warehouse / book | due, count, ready/due |

Поиск «СКАНИРОВАТЬ СЛОВО…» в шапке EN → всегда `open_word` → сканер.

## 2. ЗВЁЗДНЫЕ КАРТЫ

```
Strip: СЕКТОР code · NAME · ЗВЁЗДНАЯ КАРТА + прогресс known/total
Параметры сканирования: S-* · поиск · Перемешать · Сброс · НАЙДЕНО
  СТАТУС · ДЛИНА · СЛОЖНОСТЬ
  СОРТИРОВКА · ЧАСТЬ РЕЧИ
Сетка плиток 6×4 (COLS×ROWS), равные ячейки
Низ: ◀ стр ▶ · бортсовет · УЧИТЬ КАРТОЧКАМИ · МИССИЯ ПО НАБОРУ
```

| Элемент | → куда |
| --- | --- |
| Клик по слову | сканер (`open_word`, back=sets) |
| ⟳ переворот | локально (определение ↔ перевод) |
| ✓ знаю | progress.known |
| ⊞ в отсек | меню списков (отсеки) |
| УЧИТЬ КАРТОЧКАМИ | `start_review(due+fresh)` |
| МИССИЯ ПО НАБОРУ | `start_session(..., source="filtered", ids=…)` |

## 3. СКАНЕР

```
Strip + ← НАЗАД · ◀ ПРЕД · СЛЕД ▶
ОКНО СКАНЕРА (слово крупно, POS, лёгк., ГОЛОС/МЕДЛЕННО) — full width
┌ АНАЛИЗ ПРОИЗНОШЕНИЯ ~50% ┬ ДАННЫЕ ОБЪЕКТА ~50% ┐
│ IPA/слоги/гайд/заметки    │ def · пример · мой пер. │
│                           │ ✕не знаю · ⊞отсек · повтор│
└───────────────────────────┴───────────────────────────┘
[ СЛУЧАЙНАЯ · ГОВОРЕНИЕ · ЧТЕНИЕ · ВОПРОСЫ ]  → миссия single=slug
КАНАЛ СВЯЗИ (full): предложение + ◀▶ голос перевод подсказка | 🎙 ПЕРЕДАЧА + совпадение%
```

| Элемент | → куда |
| --- | --- |
| ← НАЗАД | `show(back \|\| "sets")` |
| ПРЕД/СЛЕД | сосед в `sets.items` / текущем наборе |
| ⊞ В ОТСЕК | отсеки (добавить слово) |
| В ПРОВЕРКУ / ПОВТОР | карточка SM-2 (остаёмся / бейдж review++) |
| 4 режима миссии | `start_session(mode, single=slug)` |
| Канал: mic | локально MatchReadout |
