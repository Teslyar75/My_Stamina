## Сделано (не повторять)

| Тема | Что есть в коде / API |
| --- | --- |
| 10 подвкладок + поиск → сканер | `EnglishPanel` |
| Ленивый seed в фоне | `_seed_vocab` + hint в UI |
| Repair ranks (`rank==0` → UPDATE) | `api_english._seed_vocab` |
| Счётчики наборов = каталог | `/sets`: 1000 / 3000 / 10000 / 20000 |
| S-DEV | `/set/dev-interview` ≈ 561 |
| S-1000 не пустой | `/set/top-1000` ≈ 967, страница 24 |
| Сетка карт **6×4** | `PAGE_SIZE=24`, CSS `repeat(6)×repeat(4)` |
| Фильтры статус/длина/сложность/sort/POS | `StarMapsPage` |
| Difficulty RU (`ЛЁГКОЕ`…) | StarMaps + Scanner |
| Сканер: окно + IPA/данные + **режимы** + **канал** + mic | `ScannerPage` (мик заморожен) |
| **Единый вход в сканер** | `openScanner` / `rememberScan` / WOD fallback |
| **Панель данных объекта** (вечер) | широкий `my_tr`; desktop-подписи кнопок |
| **Из книги — низ списка** (вечер) | `.en-from-book` + `.en-book-list` scroll |
| Журнал | 2 вкладки **ПРОГРЕСС** / **ЗНАКИ · ОШИБКИ**, без скролла |
| Миссии / проверка / склад / из книги / отсеки / настройки | страницы есть (плотность — ещё P1) |
| Vocab в web-репо | `backend/app/data/vocab*.json` |

### Сканер: откуда берётся слово в работу

| Вход | Слово в зоне |
| --- | --- |
| Вкладка **Сканер** | последнее слово сеанса (`st_en_last_scan` + `scanSeed`) |
| Звёздные карты / отсеки / миссии / журнал → слово | выбранное слово |
| Обзор → **Слово дня → Сканировать** | слово дня |
| Сеанса ещё не было | fallback: слово дня → первое слово набора |
