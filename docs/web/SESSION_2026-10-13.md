## Docker / диск

1. Docker Desktop падал с **Disk full** на **C:** (`AppData\Local\Docker\log\vm\init.log`), хотя WSL-данные на **D:** (`CustomWslDistroDir` → `D:\DockerDesktopWSL\…`).
2. Пока демон был мёртв, правки библиотеки оставались только на диске; volume `frontend_dist` держал старую сборку (~17:32 UTC).
3. После освобождения места на C и `docker compose up -d --build` свежий бандл попал в контейнер — вместе с уже битым CSS (белые сектора EN и «сломанные окна»).
4. После очистки `index.css` — повторный `--build frontend`; в проде `index-C0h4XhKb.css` без corruption.

Команда подъёма:

```powershell
cd web_star_typing
docker compose up -d --build
```

Сайт: http://localhost (Caddy). После деплоя CSS — **Ctrl+F5**.
