### Бортжурнал

- Heatmap: заливка glass, шкала green→amber→red; % не на каждой клавише.
- Слабые клавиши: мини-клавиши + % + счёт ошибок, до 12 ключей / 2 колонки.
- Компактная динамика — heatmap не обрезается.

### Сканер английского

- Единый вход → `ScannerPage`.
- Панель «Данные объекта»: шире `my_tr`; подписи ○ НЕ ЗНАЮ / ⊞ В ОТСЕК / В ПРОВЕРКУ.
- Mic / ASR **не трогали**.

### Настройки

- Библиотека / 2 языка убраны из общих настроек → только зона **Скорочтение**.
- Системы / Скины / Экипаж остаются в SettingsHub.
