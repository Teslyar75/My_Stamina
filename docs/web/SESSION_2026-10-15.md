## Цель сессии

1. Довести настройки мостика (прицел / шрифты / скролл при XL–XXL).
2. Кнопка **ЭКРАН** и крошки пути на всех главных зонах.
3. **⌨ ПЕЧАТАТЬ** из библиотеки → текст на мостик + UPLINK (слово → перевод).
4. Настройка мигания целевой буквы.

### Библиотека → слепая печать (паритет desktop)

| Область | Файлы | Суть |
| --- | --- | --- |
| ⌨ ПЕЧАТАТЬ | `LibraryPanel.tsx` | `GET /api/texts/{id}/prepared` (+ content), `st_pending_drill`, `st_cargo_board`, переход на мостик |
| Мостик | `BridgeScreen.tsx` | Приём cargo с `text_id`; автосейв позиции; UPLINK: слово → перевод + перевод предложения через `trCache` / `/api/reader/word-tr-batch` |
| API полки | `backend/app/api_library.py` | Фикс `_item(db, …)` — `/api/library` снова 200 |

Как на десктопе (`start_typing_from_library`): версия для печати на мостик; в UPLINK — набираемое слово и перевод.

### Мигание целевой буквы

| Режим | Поведение |
| --- | --- |
| Выкл | `animation: none` |
| Вкл | `blink 1s` (как было) |
| Быстрое | `blink 0.35s` |

Настройка: **Мостик → Настройки → «Мигание целевой буквы»**.  
Ключ: `cabinStore.cursorBlink` → `html[data-cursor-blink]`.
