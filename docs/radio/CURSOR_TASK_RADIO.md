# Задача для Cursor: отсек «РАДИОРУБКА» (онлайн-радио) в Star Typing

Проект: `D:\My_New_Stamina`. Образцы лежат рядом: `ref_shortwave_library.png`, `ref_shortwave_search.png`, `ref_shortwave_player.png`. Это GNOME Shortwave (https://apps.gnome.org/en/Shortwave/). Берём из него логику и раскладку, но **внешний вид делаем полностью в стиле Star Typing**: тёмная панель звездолёта, неоновые голубые рамки со скошенными углами, моноширинные заглавные подписи, полупрозрачные панели поверх «Живого космоса», те же цвета, шрифты и кнопки, что в остальных отсеках. Существующие компоненты переиспользуй, новые стили не придумывай.

## Шаг 0: проверь готовность сам
- Изучи, как сделаны вкладки, общий стиль, i18n, данные пилота, настройки и звук (Windows/Linux).
- Выбери проигрыватель потоков (MP3/AAC/HLS), который работает и на Windows, и на Linux без лишних установок. Например, `python-vlc` (нужен VLC) или `mpv` через subprocess. Если для этого нужна внешняя программа, добавь её в `install.bat` / `install.sh` и в проверку «УСТАНОВИТЬ ВСЁ». Перед добавлением тяжёлой зависимости опиши варианты Сергею.
- Проверь, что приложение запускается.

## Источник станций
- Открытая база https://www.radio-browser.info (API бесплатный, без ключа). Сервер брать из списка `all.api.radio-browser.info`.
- Поиск по названию, стране, языку, жанру (tag); сортировка по популярности (votes/clickcount).
- Кэшировать список станций локально, чтобы отсек открывался без ожидания.
- Нет интернета — показать понятное сообщение в стиле панели, без падения.

## Экраны
### 1. «ЭФИР» — выбор волн (по образцу library + search)
- Слева фильтры: страна, язык, жанр, поиск. Справа сетка или список «частот»: логотип станции (или заглушка-иконка антенны), название, страна, жанр, битрейт.
- Отдельная полка «МОИ ВОЛНЫ» (избранное) для каждого пилота. Звёздочка добавляет или убирает станцию.
- Можно оформить как «шкалу частот»: горизонтальная шкала с бегунком, по которой листаются избранные станции. Это необязательно, но здорово смотрится.

### 2. «ПРИЁМНИК» — станция играет (по образцу player)
- Большая карточка: логотип, название станции, текущий трек (ICY-метаданные, если поток их отдаёт), индикатор «В ЭФИРЕ» с пульсирующей точкой и простым эквалайзером/уровнем, громкость, кнопки Пуск/Стоп, Следующая/Предыдущая из «Моих волн».
- История треков за сеанс (без скачивания).

### 3. Фоновый режим — мини-приёмник
- Когда пилот уходит в другой отсек (набор, английский, скорочтение, читалка), радио продолжает играть.
- В шапке или в углу приложения появляется компактная полоса «📻 Название станции — трек ▮▮ 🔊» в стиле панели. Клик по ней открывает «ПРИЁМНИК», рядом кнопки пауза и громкость.
- Во время проверки произношения (микрофон) радио автоматически приглушается или ставится на паузу, потом возвращается. Во время озвучки (ГОЛОС) приглушается.
- Опция «приглушать радио во время набора» (по умолчанию выкл).

## Управление
- Клавиши: стрелки и Tab для навигации, Enter запускает станцию, пробел ставит паузу, `+`/`-` меняют громкость, Esc выходит. Подсказки на всех кнопках. Подписи через i18n (ru/uk/en/de).
- Сохранять для пилота последнюю станцию, громкость и избранное (по желанию автозапуск последней станции).

## Готово, когда

- Мини-приёмник виден и управляется из любого отсека, при микрофоне и TTS радио приглушается.
