# Скин «Старая Англия» (`old_england`) — концепция

> Статус: **дизайн, кода нет.** Первый скин эпика S8 «глубокие скины» (см. [`SKINS_DEEP.md`](./SKINS_DEEP.md)).
> Скин = целый мир: свои формы, словарь, роли, звуки, фон, радио, слайдшоу. Логика тренировки общая.

## 1. Мир и роли

Лондон между поздней викторианской эпохой и 1950-ми: туман над Темзой, красные будки K6, автобусы Routemaster, Биг-Бен, чёрные кэбы, паб на углу, чай в пять.
Метафора: **ученик газетного/телеграфного бюро на Флит-стрит**. Печатать = отправлять депеши и набирать заметки в номер.

| Было (Звездолёт) | Старая Англия |
| --- | --- |
| Пилот | **Клерк** (ученик) |
| Командир / наставник | **Редактор** («мистер Редактор», голос подсказок) |
| Экипаж | **Редакция** |

## 4. Шрифты (все OFL, Google Fonts)

- **Заголовки:** *Playfair Display SC* (газетные шапки) или *Abril Fatface* для логотипа.
- **Вывески/таблички:** *Gill Sans* недоступна свободно → **Josefin Sans** / **Cabin** (гуманистический гротеск в духе Johnston/Gill). Для эмали улиц — **Josefin Sans SemiBold, капс**.
- **UI:** *Libre Baskerville* / *Lora*.
- **Набор текста:** **Courier Prime** (пишмашинка) или *Special Elite* (только акценты, читаемость хуже).
- Кириллица: Playfair Display, Lora, Courier Prime, Cabin — есть; у Josefin Sans/Abril — нет → фолбэк на Playfair Display SC / Cabin.
Шрифты класть локально (`fonts/old_england/*.woff2` + `.ttf` для Tk), не CDN.

## 7. Фон (background engine `london_fog`)

Слой картинки `bg1.jpg` (силуэт Вестминстера в тумане, затемнён 60 %, blur 8px) + анимация:
- дрейфующий туман (2–3 слоя шума, параллакс);
- редкие огоньки фонарей и проезжающий силуэт двухэтажного автобуса (раз в 40–90 с);
- на правильное слово — лёгкое «расчищение» тумана; на конец смены — далёкий бой часов.
Десктоп: `backgrounds/london_fog.py` (Tk canvas); веб: canvas в `SkinBackdrop`.

## 8. Экран входа (предпросмотр)

При наведении на иконку 🎩/☎️ «Старая Англия»: фон → туман и Биг-Бен, панели → окна будки, заголовок «ВХОД В РЕДАКЦИЮ», кнопка «В ПУТЬ!» → эмалевая табличка, карточки пилотов → пропуска-билетики с подписью и рангом («Репортёр»). Звук клика пишмашинки, на выбор — «ding-ding». Переключение мгновенное, hard-reset прошлого скина.

## 9. Idle-слайдшоу (через N минут без клавиатуры)

Источники с лицензией, позволяющей показ: **Wikimedia Commons** (PD/CC0/CC BY — с подписью автора), **Unsplash API** и **Pexels API** (бесплатный ключ, атрибуция фотографа).
Поисковые запросы (`slideshow.queries` в теме):
`red telephone box london`, `routemaster bus`, `big ben fog`, `london black cab vintage`, `westminster bridge night`, `london pub interior`, `thames fog`, `victorian london street`, `1950s london`, `afternoon tea`.
Wikimedia категории: `Category:K6 telephone kiosks`, `Category:AEC Routemaster`, `Category:Elizabeth Tower`, `Category:London in fog`, `Category:Hackney carriages in London`.
Подпись в углу: автор · лицензия · источник. Кэш 30–50 картинок локально. Любая клавиша закрывает слайдшоу и **не засчитывается** в набор.

## 10. Радио под скин

radio-browser.info (`/json/stations/search?tag=...&countrycode=GB&order=clickcount`):
- теги: `bbc`, `british`, `jazz`, `swing`, `big band`, `oldies`, `1950s`, `classical`, `talk`, `easy listening`, `brit pop` (отдельно);
- закреплённые (проверить `url_resolved` при старте): BBC Radio 3, BBC Radio 4, BBC Radio 2, Jazz FM (UK), Scala Radio, Boom Radio (50–60-е), BBC World Service.
Со слайдшоу: автозапуск станции с fade-in до 30 % громкости; поведение после выхода — настройка.

## 11. Минимальные изменения движка (общие для всех будущих скинов)

Сейчас движок умеет: цвета (`COLOR_MAP` → `--st-*`), 2 шрифта, `data-skin`, фон-движок, звуки, `ranks`, hard-reset. JSON уже содержит `frame`/`button`, но **веб их не применяет**; `ranks` есть, словаря нет; не-спейс скины в вебе пока используют звуки Звездолёта.

Добавить в схему темы (обратно совместимо, всё опционально):
```json
"shape": { "panel": "booth", "button": "enamel", "button2": "ticket", "badge": "roundel",
           "radius": "18px 18px 4px 4px", "border": 4, "divider": "double" },
"fonts": { "ui": [...], "title": [...], "typing": [...], "sign": [...], "files": ["fonts/old_england/..."] },
"voice": "skins/old_england/voice",          // voice.ru.json / voice.en.json ...
"roles": { "student": "Клерк", "mentor": "Редактор", "guest": "Прохожий" },
"slideshow": { "queries": [...], "wikimedia": [...], "idle_min": 3 },
"radio": { "tags": [...], "country": "GB", "pinned": [...] }
```
1. **Shape kit:** `applyTheme` ставит `data-shape-panel/button/badge` + переменные `--st-radius`, `--st-border`, `--st-font-title/sign`; CSS-набор форм в `skins/shapes.css` по атрибутам (формы переиспользуются: `ticket` пригодится «Гангстерам», `enamel` — «Козырькам»). Десктоп: `theme.py` отдаёт `shape(...)`, общий `ThemedButton/ThemedPanel` рисует по ключу.
2. **Voice pack:** единая функция `t(key)` = словарь скина поверх базового; ключи — список строк оболочки (вкладки, кнопки, хаб, help, пустые состояния, тосты, роли). Отсутствующий ключ → базовая строка.
3. **Шрифты-файлы:** загрузка `@font-face` из темы (веб), регистрация TTF в Tk (десктоп, через `pyglet`/`tkextrafont` или фолбэк).
4. **Звуки:** убрать фолбэк на спейс-звуки, если у скина есть свой полный набор.
5. **Idle + slideshow + radio**: один модуль `idle/` (таймер бездействия → оверлей слайдшоу → тег-радио), данные из темы.
6. Тест: смена скина сбрасывает форму, словарь, шрифты (hard-reset); Звездолёт не меняется.

Следующие скины («Чёрная Америка», «Гангстеры Америки», «Острые козырьки») — только новый JSON + voice + ассеты, без кода.

## 14. Решения (15.10.2026)

- **Роль:** клерк редакции на Флит-стрит (наставник — Редактор).
- **Облик:** тёмный туманный Лондон; карточки (картотека, миссии, пилоты на входе) — светлые «газетные».
- **Слайдшоу (E2):** по умолчанию только Wikimedia Commons, без ключей. В «Конторке» (настройки) — необязательные поля для **своих** бесплатных ключей Unsplash (https://unsplash.com/developers) и Pexels (https://www.pexels.com/api/) со ссылками, где их получить; ключи хранятся **на сервере** у пилота, никогда не попадают в git и во фронтенд. Плюс заглушка-интерфейс провайдера (`provider: wikimedia | unsplash | pexels | custom`) для платных сервисов позже.
- **Шрифты (фактически):** Playfair Display SC (заголовки), Old Standard TT (UI), PT Mono (набор) — все OFL, с кириллицей включая украинскую и немецкие умляуты. Josefin/Abril/Courier Prime отклонены (нет кириллицы).
- **Ранги (8, по базовой лестнице):** Посыльный → Младший клерк → Клерк → Корректор → Репортёр → Обозреватель → Редактор → Главный редактор Флит-стрит.
- **Сделано:** E1 + OE1 в вебе — PR https://github.com/Teslyar75/Wed_Star_Typing_Version/pull/7 (не влит).
- **Дальше:** E2 (простой → слайдшоу → радио по тегам), OE2 (фон-туман `london_fog`, названия миссий в духе мира, доводка звуков), D1 (десктоп).
