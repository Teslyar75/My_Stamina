# Глубокая переработка скинов (на будущее)

> **Статус:** отложено. Сейчас эталон — «Звездолёт» (палитра + living_space + hard-reset).  
> Остальные скины пока дают в основном цвета / звуки / фон-движок — этого мало.  
> Канон палитр и S0–S7: [`SKINS.md`](./SKINS.md). Этот файл — **следующий слой**, когда вернёмся к скинам.

## Зачем

Смена скина должна менять не «оттенок кабины», а **мир**, в котором тренируется человек:

| Слой | Сейчас | Цель |
| --- | --- | --- |
| Цвета / шрифты | частично | оставить и довести контраст |
| Формы UI (кнопки, панели, рамки, бейджи) | почти не различаются | **своя геометрия** у каждого скина |
| Нарратив / роли | везде «пилот / экипаж / мостик» | **своя метафора** и словарик |
| Детали оформления | общие HUD-паттерны | иконки, разделители, курсоры, микровзаимодействия под идею |
| Ранги / онбординг / help | частично разные `ranks` | согласованы с ролями и копирайтом |

**Правило:** другой скин → другие идеи → другое оформление деталей. Недостаточно перекрасить акценты.

## Принцип «голос мира»

Каждый скин — мини-вселенная с парой ролей (наставник ↔ ученик) и своим языком интерфейса.

Пример (зафиксировано продуктово):

- **Звездолёт** — командир / экипаж / кадет на мостике. «Миссия», «стыковка», «отсеки».
- **Сад дзен** — **наставник и монах-послушник** (не «капитан» и не «экипаж»). Тишина, дыхание, практика; кнопки и подписи в том же духе.

То же правило для остальных: батискаф ≠ космос с синей палитрой; скрипторий ≠ «панель с пергаментом».

## Слои реализации (когда делать)

1. **Chrome shape kit** — в JSON темы уже есть зачатки `frame` / `button`; довести до реальных CSS/Tk стилей:
   - радиус, скосы, клёпки, «иллюминатор», сургучная печать, неоновый скос, минимальная плашка дзен;
   - отдельные токены: `--st-btn-radius`, `--st-btn-clip`, `--st-panel-frame`, и т.п.
2. **Voice pack (i18n)** — не только `name` скина, а набор ключей оболочки: вкладки, онбординг, help, ContinueHub, ранги, пустые состояния. Подгрузка словаря `skins/<id>/voice.{ru,en,...}.json` поверх базового.
3. **Роли в UI** — аватар/досье/приветствие: «Пилот» vs «Послушник» vs «Раннер» и т.д.; без ломки API пилота (только отображение).
4. **Детали** — иконки вкладок, разделители, форма бейджа API, стиль прогресс-баров, курсор набора, микровспышки ошибок/успеха.
5. **Фон + звук** — уже намечены в SKINS.md (sonar / gears / candles / rain / zen); довести до паритета с идеей, не как «картинка под палитру».
6. **Эталон и hard-reset** — Звездолёт остаётся референсом чистого boot; смена скина по-прежнему полный сброс артефактов, затем применение *полного* пакета (форма + голос + FX).

Не смешивать: логика тренировки (SM-2, сегменты, миссии) общая; **меняется только оболочка и язык мира**.

## Черновик миров (по скинам)

Ниже — ориентиры для дизайна/копирайта. Уточнять при старте эпика; не блокирует текущий код.

### `spaceship` — Звездолёт (эталон)
- **Мир:** рубка звездолёта, флот, полёт.
- **Роли:** командир ↔ кадет / экипаж.
- **Chrome:** неон, bevel-кнопки, срезанные углы, HUD-линии.
- **Слова:** мостик, отсек, миссия, стыковка, экипаж, досье.
- **Статус:** эталон; глубокая переработка не приоритет.

### `bathyscaphe` — Батискаф
- **Мир:** глубоководная рубка, давление, сонар.
- **Роли:** командир лодки ↔ юнга / акустик.
- **Chrome:** круглые «иллюминаторы», тумблеры, клёпки, толстая обшивка.
- **Слова:** погружение, эхо, шлюз, глубина, вахта.

### `steampunk` — Стимпанк-мастерская
- **Мир:** латунь, пар, часовой механизм.
- **Роли:** мастер ↔ подмастерье.
- **Chrome:** пластины, заклёпки, рычаги, циферблаты вместо «бейджей».
- **Слова:** станок, калибр, давление, изобретение, цех.

### `scriptorium` — Скрипторий
- **Мир:** монастырская / средневековая библиотека, перо, свеча.
- **Роли:** книжник / хранитель ↔ переписчик (или послушник скриптория).
- **Chrome:** свитки, рваный край «страницы», сургучные печати-кнопки.
- **Слова:** свиток, глава, перо, хранилище, труд.

### `neon_city` — Неон-Сити
- **Мир:** ночной мегаполис, сеть, дождь.
- **Роли:** фиксер / легенда сети ↔ раннер.
- **Chrome:** скосы, глитч при ошибке, сканлайны, «голограммные» панели.
- **Слова:** аплинк, сектор, протокол, глитч, сетка.

### `zen_garden` — Сад дзен
- **Мир:** сад камней, тишина, практика.
- **Роли:** **наставник ↔ монах-послушник** (явно не «пилот» и не «экипаж»).
- **Chrome:** мало рамок, мягкий радиус или «каменная» плашка, много воздуха, спокойные разделители.
- **Слова:** практика, дыхание, путь, урок, покой / сосредоточение (вместо миссия / стыковка).
- **Детали:** онбординг и help без космической метафоры; ContinueHub — «продолжить практику», не «продолжить стыковку».

## Порядок работ (когда вернёмся)

Предлагаемый эпик **S8 — Deep skins** (после стабилизации ядра):

1. Спека voice-ключей (общий список строк оболочки, которые обязаны переключаться).
2. Shape kit в теме + применение в web CSS (и зеркало в desktop theme, если ещё жив).
3. Пилот: один скин end-to-end как образец (**zen_garden** — самый контрастный к звездолёту по голосу).
4. Остальные скины по тому же чеклисту.
5. Регрессия: Звездолёт визуально/текстово не деградирует; hard-reset без чужих форм/строк.

### Чеклист готовности скина

- [ ] Свои формы кнопок/панелей (не только цвет)
- [ ] Voice pack: вкладки, help, онбординг, пустые состояния, ContinueHub
- [ ] Роли/ранги согласованы с миром
- [ ] Фон + звуки не «чужие» (не spaceship-fallback без пометки)
- [ ] Контраст текста ≥ 4.5:1 на панелях
- [ ] Смена скина сбрасывает предыдущий chrome + voice

## Вне скоупа сейчас

- Не ломать API пилотов / миссий / библиотеки ради метафоры.
- Не плодить отдельные React-деревья на каждый скин — токены + словари + CSS data-skin.
- Image-сцены и тяжёлый art — по желанию после shape+voice.
