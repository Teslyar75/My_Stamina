# Промпт для Ориона: альтернативный вид для остальных скинов

Ты — бортовой агент. Задача: довести вид «Пульт-кабина» (`stamina/alt_ui.py`) для пяти
скинов, у которых сейчас профиль `generic`: Батискаф, Неон-Сити, Старая Англия, Скрипторий
и Дзен-сад (проверь `stamina/themes/*.json`). Образцы — профили `starship` и `steampunk`.

## Правила (не нарушать)
- Ветка `agent/<ты>/alt-ui-<скин>`; без `git push`, `reset --hard`, `--force`, `clean -fd`.
- Снимок перед правкой: `powershell -ExecutionPolicy Bypass -File tools\snapshot.ps1 -Note "..."`.
- Классический вид не трогать. Новые строки — только через `tr_()` + 4 файла i18n
  (indent=1, sort_keys, ensure_ascii=False, LF, в ru ключ = фраза).
- Цвета — токены `theme.*`, шрифт `theme.font`, размеры `px()`. Без `update_idletasks()`
  в обработчиках геометрии; перерисовка только при смене размера/отсека.
- Ни одной функции не прятать без замены: сверяйся с `_orion/guests/grok-bot/ALT_UI_INVENTORY.md`.

## Выпадающие списки — одно правило для всех отсеков

- Только `alt_ui.RowCompactor` + `alt_ui.DropList`; никаких своих меню и столбцов кнопок-вкладок.
- Список раздела «ТЕКУЩИЙ ▾» — первым слева в шапке отсека, под заголовком; «⋯ ЕЩЁ» — справа.
- Открывается под кнопкой на том же мониторе, поверх окон; колесо/↑↓, Enter, Esc, щелчок мимо;
  ✓ у текущего пункта, счётчики в подписях сохраняются.
- Проверка: `tests/test_dropdown_audit.py` должен быть зелёным в новом скине.

## Шаг 0. Библия мира
До кода напиши `docs/skins/WORLD_BIBLE_<skin>.md` по образцу
`WORLD_BIBLE_spaceship.md` и `WORLD_BIBLE_steampunk.md`: концепция мира одной-двумя фразами (кто здесь
живёт и чем являются окна), свет, материалы, орнамент, звук и таблица
«раздел приложения → помещение → изображение → настроение» для всех 8 зон. Библия — ориентир
настроения для всех следующих шагов. Перед реализацией согласуй её с пилотом.

## Шаг 1. Нарратив скина
Сформулируй одной фразой, **чем являются окна** в мире скина (как у образцов:
Звездолёт — фрагменты корабля: иллюминаторы, обзорные окна, бортовые консоли;
Стимпанк — экраны и смотровые стёкла мастера-изобретателя: чертёжные доски, стёкла
приборов, латунные экраны на машинах и верстаках). Этот нарратив должен последовательно
пройти через рамки, отсеки, обои, кнопки дока и табличку отсека. Пример идей:
Батискаф — смотровые иллюминаторы и сонар-экраны; Неон-Сити — неоновые вывески и
голо-витрины; Старая Англия — окна в переплёте и газетные полосы; Скрипторий — пергаменты
и витражи; Дзен-сад — бумажные сёдзи и рамки каллиграфии.

## Шаг 2. Профиль
1. В `PROFILES` добавь профиль: значки зон (все 8 из `nav.ZONE_ORDER`), `subtitle`, `rail`,
   `drawer`, `gauge`. В JSON скина: `"alt_ui": {"profile": "<id>", "frame": "<стиль>"}`.
2. `AltNavButton._draw`: ветка для профиля (свой «орган управления»: рычаг, клавиша, печать…).
3. `OrnamentBand` и `GaugeCanvas` — свой орнамент и свой прибор.

## Шаг 3. Система рамок
Рамки — общий механизм `SkinFrame` + `wrap()`: 4 холста-кромки, стиль выбирается
`frame_style()` по `FRAME_OF_PROFILE` или ключу `alt_ui.frame`. Добавь стиль
`_edge_<стиль>(side, cv, w, h)` — рисует одну кромку; углы, крепёж, заголовок-ярлык.
Каждое видимое окно и панель в alt-режиме обёрнуто этой рамкой (док, главное окно).

## Шаг 4. Отсеки, обои, переход
1. `COMPARTMENTS[<профиль>]` — 8 названий комнат/отсеков в духе нарратива + токен акцента.
2. Обои: `stamina/assets/alt_wallpapers/<профиль>/<zone>.jpg`, 1600×900. Основной вариант —
   НАСТОЯЩИЕ изображения из библии мира: Wikimedia Commons (PD, CC0, CC BY, CC BY-SA), Unsplash или Pexels.
   Одно изображение на зону, исходник шириной ≥1600 px. Нельзя: скриншоты игр и фильмов, логотипы, кадры
   без лицензии, NC/ND. Каждый файл
   запиши в `stamina/assets/alt_wallpapers/ATTRIBUTION.md` (название, ссылка, автор, лицензия).
   Сборка: `python tools/gen_alt_wallpapers.py --photos <папка>`; обработку под скин
   добавь в `from_photo`. Процедурный фолбэк — функции в `SCENES`. Середина кадра должна быть
   спокойной, потому что там окно; текст читается за счёт `alt_wallpaper_dim`.
3. Процедурный фолбэк панорамы: `CompartmentBanner._<профиль>_<zone>(w, h, acc, rnd)`.
4. Переход — «шлюз» (`_airlock`): адаптируй створки под скин (сёдзи разъезжаются,
   занавес, затвор иллюминатора). ≤ 8 кадров, отключается `alt_transition`.
