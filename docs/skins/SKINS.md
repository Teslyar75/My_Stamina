# Star Typing — система скинов (все версии программы)

Скины общие для **десктопного Tkinter-пульта** и **браузерной версии** (`web_star_typing`).

| Артеfact | Путь |
| --- | --- |
| Спека и промпты | этот файл (`docs/skins/SKINS.md`) |
| JSON тем (канон для web + sync в desktop) | веб-репо `packages/themes/<id>.json` |
| Картинки | `docs/skins/images/<id>/` (и копия в веб-репо) |
| Десктоп (после S1) | `stamina/themes/<id>.json` |
| Веб | [Wed_Star_Typing_Version](https://github.com/Teslyar75/Wed_Star_Typing_Version) — CSS через `applyTheme.ts` |

План веба: [docs/web/WEB_PLAN.md](../web/WEB_PLAN.md) · репозиторий: [Wed_Star_Typing_Version](https://github.com/Teslyar75/Wed_Star_Typing_Version).

## 1. Движок тем (десктоп)
Цвета (`AMBER`, `GREEN` и др.) загружаются из JSON; модульные имена обновляются при смене скина.
**Цель:** токены темы + предпросмотр без перезапуска.

- `stamina/themes/<id>.json`:
```json
{
  "id": "spaceship", "name": {"ru": "Звездолёт", "uk": "Зореліт", "en": "Starship", "de": "Raumschiff"},
  "colors": {"bg": "#05070f", "panel": "#0b1424", "panel_border": "#1fd1ff", "text": "#cfe8ff",
             "accent": "#ffb300", "ok": "#39ff88", "error": "#ff3b5c", "muted": "#5a7090"},
  "fonts": {"ui": ["Consolas", 11], "title": ["Orbitron", 14, "bold"], "typing": ["Consolas", 18]},
  "frame": {"style": "neon", "radius": 6, "border": 2, "corner_cuts": true},
  "button": {"shape": "bevel", "pad": [10, 4]},
  "background": {"engine": "living_space", "params": {}},
  "sounds": {"key": "sounds/space/key.wav", "error": "...", "ok": "..."},
  "ranks": ["Кадет", "Пилот", "Штурман", "Капитан", "Адмирал"]
}
```
- `stamina/theme.py`: `load_theme(id)`, `current()`, `on_change(cb)`; все модули берут цвета через `theme.c("accent")`.
- Фоны — плагины: `stamina/backgrounds/<engine>.py` с единым интерфейсом `start(canvas) / stop() / resize()`.
- Выбор темы — в настройках, хранится **у каждого пилота** (`pilots.py`), применяется без перезапуска.

## Выбор скина в стартовом окне («ВХОД В КАБИНУ»)

Скин выбирается прямо в стартовом окне, где пилот выбирает профиль и вводит код доступа.

- Под списком пилотов (или над полем пароля) идёт ряд **иконок-скинов**: 🚀 Звездолёт, 🌊 Батискаф, ⚙️ Стимпанк, 📜 Скрипторий, 🌃 Неон-Сити, 🪨 Сад дзен. Каждая иконка — квадрат 48–64 px в стиле своего скина, с подписью и подсказкой при наведении.
- При наведении или выборе стрелками **всё стартовое окно сразу перекрашивается** в этот скин (живой предпросмотр: цвета, рамки, фон, звук щелчка).
- Выбранная иконка подсвечена рамкой. Управление: стрелки ←/→ по иконкам, Tab переходит к полю пароля, Enter входит.
- При выборе пилота окно сразу принимает **его сохранённый скин**. Если пилот выбрал другую иконку и вошёл, новый скин сохраняется в его профиль.
- Новый пилот выбирает скин при регистрации, по умолчанию Звездолёт.
- Сменить скин можно и позже в Настройках, выбор синхронизирован со стартовым окном.
- Иконки рисуются программно или лежат в `themes/<id>/icon.png` и указываются в `themes/*.json` (`"icon"`, `"title"` через i18n).

### Промпт S0 для Cursor (выполнять после S1, системы тем)
«В окне «ВХОД В КАБИНУ» добавь ряд иконок-скинов из `themes/*.json` по разделу «Выбор скина в стартовом окне» в `docs/skins/SKINS.md`. Сделай живой предпросмотр всего окна при наведении или выборе, сохрани скин в профиль пилота при входе, при выборе пилота применяй его скин, добавь управление стрелками, Tab и Enter, подписи через i18n (ru/uk/en/de). Готово, когда переключение иконок мгновенно меняет вид окна, а после входа приложение открывается в выбранном скине.»

## Картинки для скинов

Готовые картинки лежат в `docs/skins/images/<id>/` (id: `spaceship`, `bathyscaphe`, `steampunk`, `scriptorium`, `neon_city`, `zen_garden`). Авторы и лицензии — в `docs/skins/images/ATTRIBUTION.md` (все с Wikimedia Commons: CC0 / PD / CC BY / CC BY-SA). При переносе в `stamina/themes/<id>/` сохрани атрибуцию и покажи её в «О программе».

- `bg*.jpg` — фон окна (до 1920 px). Масштабируй cover, затемняй 50–70 % и размывай (Gaussian 6–12 px), чтобы текст читался; анимированный фон скина рисуется поверх.
- `tex*.jpg` — фактура панелей: накладывай полупрозрачно (10–25 %) или тайлом с затемнением.
- `icon*.jpg` — для выбора скина в окне «ВХОД В КАБИНУ»: квадратный кроп по центру → 64×64 (и 128×128 для HiDPI), сохранить как `themes/<id>/icon.png`, рамка в акцентном цвете скина.
- Если картинка слабо подходит к концепции — замени на свою и обнови ATTRIBUTION.md.
