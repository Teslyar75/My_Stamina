## 2. Архитектура

```
stamina/
  speedread_hook.py          # как english_hook.py: KEY="speedread", TITLE="СКОРОЧТЕНИЕ", load_class(), create(), лог
  speedread/
    __init__.py              # экспорт SpeedReadScreen
    screen.py                # SpeedReadScreen(tk.Frame): подвкладки ОБЗОР/ГИПЕРДРАЙВ/ТРЕНАЖЁРЫ/БИБЛИОТЕКА/ЖУРНАЛ/НАСТРОЙКИ, on_key(e), close()
    rsvp.py                  # логика без GUI: токенизация, ORP, кадры N слов, тайминги, разгон (тестируется отдельно)
    reader.py                # экран гипердрайва: иллюминатор на Canvas, режим фокуса, пауза с контекстом
    texts.py                 # экран библиотеки поверх stamina/library.py (общей для печати и чтения): вставка, .txt, позже .fb2/.epub, English
    quiz.py                  # дебрифинг: авто-вопросы + встроенные
    store.py                 # speedread.json: чтение/запись атомарно (tmp + replace), миграция версий
    xp.py                    # формулы XP, начисление через app.store
    exercises/
      __init__.py            # реестр: код → класс, название, описание
      base.py                # ExerciseScreen: таймер, табло, итог со ★ (DebriefModal-стиль)
      schulte.py gorbov.py tachisto.py pacer.py pyramid.py find_words.py gaps.py eye.py
    data/builtin_texts/*.json  # короткие тексты общественного достояния с вопросами
tests/test_rsvp.py           # unittest: ORP, кадры, тайминги, разгон
docs/speedread/              # SPEC.md, этот файл, mockups/
```

- Подключение: в `cockpit.py` по образцу английской вкладки (добавить `(speedread_hook.KEY, speedread_hook.TITLE)` перед «НАСТРОЙКИ», создать экран через `speedread_hook.create(...)`, ветка в `_on_key`, `close()` в `_on_close`). Ошибка загрузки → вкладки нет, Star Typing работает, запись в `%APPDATA%\Stamina\speedread_error.log`.
- Данные: `%APPDATA%\Stamina\speedread.json`:
  ```json
  {"version":1,
   "settings":{"wpm_start":300,"wpm_target":600,"ramp":"smooth","ramp_step":10,"ramp_every_s":30,
               "chunk":1,"chunk_max_chars":24,"font_pt":64,"orp":true,"punct_pauses":true,"focus_mode":true,"quiz":"always","quiz_words":1000},
   "texts":{"<id>":{"title":"…","lang":"ru","words":9806,"pos":1248,"sha1":"…","path":"…","best_wpm":452}},
   "sessions":[{"ts":0,"text":"<id>","words":1248,"secs":171,"avg_wpm":402,"max_wpm":452,"comp":0.82,"eff_wpm":330,"xp":21}],
   "exercises":{"E-SHL":{"5x5":{"best_s":31.8,"stars":3,"runs":[…]}}},
   "streak":{"last_day":"2026-10-09","days":6}}
  ```
  Тексты из вставки/файлов копировать в `%APPDATA%\Stamina\speedread\texts\`.
- XP: `app.store.stats["xp"] += xp; app.store.save_stats(); app.update_rank()` — **не** через `add_run` (иначе попадёт в статистику печати). Лучше добавить в `storage.Store` маленький метод `add_xp(n)`.
- Таймеры: только `after()`; в режиме чтения шаг планировать от `time.perf_counter()` (компенсация дрейфа), не накапливать задержку. Рисование слова — один `canvas.itemconfig` для трёх текстовых элементов (левая часть, ORP, правая часть), без пересоздания.
- DPI/масштаб — через `theme.px()`, как во всём Star Typing.

- [ ] `stamina/library.py` (общий модуль Star Typing, не внутри `speedread/`): `library.json`, `texts\<id>\{meta.json, original.txt, prepared.txt}`, атомарная запись, поиск дубликатов по SHA-256.
- [ ] `prepared = process_text(original, **cargo_opts)` — только существующие функции `stamina/text_processing.py`, без копий логики; поле `prepared.opts` + `processor`.
- [ ] Пересоздание подготовленной версии при смене `cargo_opts` с переносом позиции печати через оригинал; для `missing` — запрет с подсказкой.
- [ ] `stamina/textmap.py`: якоря слово-в-слово (токены оригинала `\S+` → `process(token)` → склейка == `prepared`), `prep_to_orig()`, `orig_to_prep()`, запасной путь `difflib` по блокам, кэш `map.bin`. Переиспользовать идею `translator.Segments._from_original`.
- [ ] Синхронизация позиций чтения/печати (`sync: ask|auto|off`), плашка «В ПЕЧАТИ ВЫ ДАЛЬШЕ: N% · ПРОДОЛЖИТЬ?».
- [ ] «СВОЙ ТЕКСТ»: «Сохранить на борт» пишет в библиотеку; `cargo.txt`/`cargo_original.txt` остаются зеркалом активного текста; `session.json` — формат без изменений.
- [ ] Миграция: `cargo_original.txt` → `full`; иначе поиск оригинала (`*1984*`, `*orwell*`, затем все `.txt` ≤ 20 МБ в известных папках) с проверкой `process(candidate)` == / префикс / фрагмент; для «1984» — фрагмент `For_stamina\1984_11.txt` (символы 0–35 524), `recovered`; разовое предложение «Продолжить «1984» целиком?»; иначе `missing` + «ПРИВЯЗАТЬ ОРИГИНАЛ…».
- [ ] Тесты `tests/test_library.py` (на временной папке, тексты-образцы своими словами, без книг под авторским правом): обе версии сохраняются; пересоздание при смене опций; `prep_to_orig(orig_to_prep(w)) == w` для всех слов; позиция переносится при смене опций; миграция full/recovered(префикс)/missing; `session.json` после миграции побайтно тот же.
- **Готово, когда:** «1984» в библиотеке с оригиналом (`recovered`), «СВОЙ ТЕКСТ → ПРОДОЛЖИТЬ С МЕСТА» открывает его на позиции 472, гипердрайв открывает тот же текст с заглавными и пунктуацией на слове 89 («depicted simply an enormous face…») и обратно; смена опций подготовки не теряет прогресс.
