# Общая библиотека текстов Star Typing (печать + скорочтение)

> Статус: **проект**. Решение пользователя (2026-10-09): каждый загруженный текст хранится **в двух версиях**:
> 1. **Оригинал** — без изменений (заглавные, пунктуация, переводы строк, абзацы). Им пользуются «СКОРОЧТЕНИЕ» (гипердрайв, указка, тесты) и тренажёры.
> 2. **Подготовленная версия** — результат существующих функций «Подготовка текста» Star Typing (`stamina/text_processing.py`: убрать заглавные, знаки препинания, лишние пробелы). Ей пользуется печать («СВОЙ ТЕКСТ»).
>
> Связано: [SPEC.md](SPEC.md) §4, [CURSOR_TASK_SPEEDREAD.md](CURSOR_TASK_SPEEDREAD.md) шаг 5а, `docs/pilots/SPEC_PILOTS.md` (библиотека лежит в папке пилота).

## 2. Модель данных
Библиотека — **у каждого пилота своя** (`DATA_DIR` активного пилота, см. профили пилотов):
```
<DATA_DIR>\library\
  library.json                   # индекс + активные тексты
  texts\<id>\
    meta.json                    # описание текста (ниже)
    original.txt                 # UTF-8, как загружено (нормализуются только \r\n → \n и BOM)
    prepared.txt                 # UTF-8, = process(original, opts) — или единственная версия, если оригинала нет
    map.bin                      # необязательно: кэш соответствия позиций (§4), пересоздаётся
```
`library.json`:
```json
{"version":1,"active_typing":"t-20261009-1984","active_reading":"t-20261009-1984",
 "texts":[{"id":"t-20261009-1984","title":"1984","author":"George Orwell","lang":"en","updated":"…"}]}
```
`meta.json`:
```json
{"id":"t-20261009-1984", "title":"1984", "author":"George Orwell", "lang":"en",
 "source":{"kind":"file|paste|builtin|english|migrated", "path":"D:\\Books\\1984.txt", "filename":"1984.txt",
           "encoding":"utf-8-sig|cp1251", "sha256":"<хэш исходных байт файла>", "imported":"2026-10-09T18:55:00+03:00"},
 "created":"…", "updated":"…",
 "original":{"status":"full|recovered|partial|missing", "chars":0, "words":0, "sha256":"…", "note":"…"},
 "prepared":{"opts":{"lower":true,"punct":true,"spaces":true}, "processor":"text_processing v1",
             "chars":34482, "sha256":"…", "generated":"…"},
 "positions":{"typing":{"char":472,"updated":"…"}, "reading":{"word":0,"updated":"…"}},
 "sync":"ask|auto|off", "protected":false, "tags":[]}
```
- `id` = `t-` + дата + 4 hex (не зависит от названия). Название и автор — из имени файла / первой строки / метаданных `.fb2`/`.epub`, редактируются.
- `original.status`: `full` — есть настоящий оригинал; `recovered` — найден позже и проверен (`process(original) == prepared` целиком); `partial` — оригинал найден для части текста; `missing` — оригинала нет, есть только подготовленная версия.
- Хэши — для проверки целостности и для того, чтобы при повторной загрузке того же файла не создавать дубликат («Этот текст уже в библиотеке: 1984»).
- Запись атомарная (tmp + replace). Тексты в репозиторий не попадают.

## 3. Подготовленная версия: создание и пересоздание
- При загрузке (файл/вставка/«Применить к тексту в поле») сохраняется **оригинал как есть** и `prepared = process(original, opts)` с текущими `cargo_opts`.
- **Подготовленная версия всегда выводится из оригинала** (если он есть) и не редактируется руками. Ручная правка в поле «СВОЙ ТЕКСТ» = новый оригинал (новая ревизия того же текста, `updated`).
- **Смена опций** (`cargo_opts`) или новой версии `text_processing` (поле `processor`):
  1. если по тексту нет прогресса печати — молча пересоздать `prepared.txt`;
  2. если есть — окно «Подготовка изменилась: пересоздать текст для печати? Позиция будет перенесена на то же слово (≈ 13%)». Позиция переносится через оригинал (§4): `char(prepared_old) → слово оригинала → char(prepared_new)` (на начало слова). Статистика заходов не меняется; `session.json` переписывается новым `text` и `index`;
  3. для `missing` пересоздать нельзя (нет источника) — кнопка неактивна с подсказкой «Нет оригинала — привяжите файл (§5)». Опции, которые только **убирают** (lower/punct/spaces), можно применить к самой подготовленной версии — это разрешено, обратное — нет.
- Хранится одна подготовленная версия на текст (для текущих опций); старые не нужны — их всегда можно пересчитать.

## 4. Соответствие позиций (оригинал ↔ подготовленная)
Цель: одна книга — один прогресс; можно читать в гипердрайве и печатать с того же места.
- **Единица соответствия — слово.** Оригинал режется на токены по пробельным символам (как `str.split()`), у каждого — позиция `(start, end)` в `original.txt`. Для каждого токена `w' = process(w, opts)` (для `spaces=False` — с `normalize_typography`); пустые `w'` (тире, «…», отдельные знаки) пропускаются. Склейка непустых `w'` через пробел обязана дать `prepared` (проверка, как в `translator.Segments._from_original`).
- Получаем массив якорей `anchors[k] = (orig_token_index, orig_char_start, prep_char_start)` — по одному на слово подготовленной версии. Функции:
  - `prep_to_orig(char)` → бинарный поиск по `prep_char_start` → номер слова оригинала (+ смещение внутри слова);
  - `orig_to_prep(word_index)` → ближайший якорь не раньше этого слова → `prep_char_start`;
  - гипердрайв работает в словах оригинала (`positions.reading.word`), печать — в символах подготовленной (`positions.typing.char` = `session.json → index`).
- Если быстрая проверка не прошла (редкие символы, другая версия функций) — запасной путь: выравнивание потоков «только буквы и цифры в нижнем регистре» через `difflib.SequenceMatcher` (без внешних библиотек) по блокам ~5 000 символов; якоря — по совпавшим словам; точность ±1 слово. Если и это не удалось — синхронизация для текста выключается с сообщением.
- Кэш якорей — `map.bin` (массив `array('I')`), пересчитывается при изменении хэшей. Для «1984» целиком (~100 000 слов) построение < 0,5 с.
- **Синхронизация прогресса** (`meta.sync`, по умолчанию `ask`):
  - при открытии текста в гипердрайве, если позиция печати дальше чтения (или наоборот) — плашка «В ПЕЧАТИ ВЫ ДАЛЬШЕ: 13% · ПРОДОЛЖИТЬ С ЭТОГО МЕСТА?» [ДА] [НЕТ, С МОЕГО]; то же в «СВОЙ ТЕКСТ» → «▶ ПРОДОЛЖИТЬ С МЕСТА ЧТЕНИЯ»;
  - `auto` — всегда брать более дальнюю позицию; `off` — независимые позиции.
  - Синхронизируется **только позиция**, а не статистика: прочитанное в гипердрайве не засчитывается как напечатанное. При переносе в печать `session.json` получает новый `index`, `typed`/`errors`/`elapsed` сохраняются (это статистика пилота, а не текста).
- Для `missing` гипердрайв работает по подготовленной версии (§5), соответствие тривиальное (1:1 по словам).

## 5. Миграция существующих текстов
Выполняется один раз (после миграции пилотов, в папке каждого пилота), только после резервной копии; `session.json` **не меняется** (кроме ссылки на текст, см. ниже — и то лишь в новом поле, формат сохраняется).
1. Если есть `cargo_original.txt` и `process(original, cargo_opts) == cargo.txt` → текст со статусом `full`.
2. Если есть только `cargo.txt` или только `session.json → text` → `prepared` = этот текст; оригинал ищется:
   - **поиск источника** (сначала автоматически, затем по кнопке «Найти исходный файл…»): `.txt`/`.fb2`/`.epub` ≤ 20 МБ в `D:\My_New_Stamina`, «Документы», «Загрузки», «Рабочий стол», OneDrive, а также в резервных копиях (`D:\My_New_Stamina_backup_*`, `_appdata_Stamina`); кандидат читается (utf-8-sig/cp1251), обрабатывается теми же опциями и проверяется:
     - `process(candidate) == prepared` → `recovered` (оригинал = файл целиком);
     - `prepared` — **префикс/фрагмент** `process(candidate)` (пилот загружал часть книги — это случай «1984»: 34 482 знака — начало книги) → по якорям (§4) вырезается соответствующий кусок оригинала → `recovered` (+ в `meta.note` «оригинал — фрагмент файла X, слова A–B»); полный файл можно предложить загрузить как отдельный текст;
     - частичное совпадение (> 95% слов) → `partial`, показать пилоту для подтверждения;
   - не найдено → `missing`, плашка в библиотеке «⚠ БЕЗ ОРИГИНАЛА» и кнопка «ПРИВЯЗАТЬ ОРИГИНАЛ…» (выбрать файл вручную — та же проверка).
3. **«1984»** распознаётся по началу `part one chapter 1 it was a bright cold day in april` → `title "1984"`, `author "George Orwell"`, `lang "en"`. Кандидаты ищутся в первую очередь по именам `*1984*`, `*orwell*`.
   **Проверено на ноутбуке 2026-10-09 (только чтение, копии на box):**
   - `C:\Users\mi\OneDrive\Рабочий стол\For_stamina\1984_Chapter_1.txt` (34 482 байта) — это **уже подготовленный** текст, побайтно равный `session.json → text`; оригиналом не является.
   - `…\For_stamina\1984_11.txt` (597 264 байта, UTF-8 с BOM, CRLF) — **полный оригинал книги** («PART ONE / Chapter 1 / It was a bright cold day in April, and the clocks were striking thirteen.…»). `adapt_for_typing(1984_11.txt)` начинается ровно с `session.json → text` (префикс, 6 233 слова из 103 365). Пословное сопоставление (§4) сходится без запасного пути.
   - Значит оригинал фрагмента восстанавливается: первые **35 524 символа** `1984_11.txt` (после `\r\n → \n`), до «…He got up and moved heavily towards the door.». Позиция печати 472 → слово 89 оригинала («depicted simply an enormous face, more than a metre wide…»).
   - `1984_1.txt`…`1984_10.txt` (≈ 0,5 КБ) — короткие подготовленные отрывки другой редакции («george orwell nineteen eighty four part i i…»), не используются.
   **Решение миграции для «1984»:** текст в библиотеке = фрагмент, `original.status = "recovered"`, `meta.note = "оригинал — символы 0–35524 файла 1984_11.txt"`, `source.path` = этот файл, `source.sha256` = его хэш; `prepared.txt` = `session.json → text` (без изменений), позиция 472 сохраняется. Затем пилоту **один раз** предлагается: «Найдена полная книга (103 365 слов). Продолжить «1984» целиком? Позиция сохранится» — при согласии оригинал = весь файл, `prepared` = `process(весь файл)`, `session.json → text` заменяется на полный подготовленный текст, `index` остаётся 472 (префикс совпадает, проверить перед заменой). Без согласия — всё как было.
   Если файла на компьютере не окажется (другой пилот/компьютер) — статус `missing`, позиция сохраняется, «ПРИВЯЗАТЬ ОРИГИНАЛ…» потом.
4. Создаётся `library.json` с `active_typing` = этот текст; `positions.typing.char` = `session.json → index`; `positions.reading.word` = соответствующее слово (если оригинал есть) или 0.
5. Проверка: `prepared.txt` побайтно равен `session.json → text`; «СВОЙ ТЕКСТ → ПРОДОЛЖИТЬ С МЕСТА» открывает «1984» на той же позиции.
- `cargo.txt`/`cargo_original.txt` дальше пишутся как **зеркало активного текста** для совместимости (переводчик и старый код читают их); источник истины — библиотека.

## 6. Интерфейс
- **БИБЛИОТЕКА** (подвкладка «СКОРОЧТЕНИЕ», та же таблица доступна из «СВОЙ ТЕКСТ» кнопкой «📚 БИБЛИОТЕКА»): строки `HudPanel` — название, автор, язык, слов, «печать 13% · чтение 9%», статус оригинала (`✓ ОРИГИНАЛ` зелёным / `⚠ БЕЗ ОРИГИНАЛА` янтарным / `≈ ЧАСТИЧНО`), кнопки «ПЕЧАТАТЬ», «ЧИТАТЬ», «✎», «ПРИВЯЗАТЬ ОРИГИНАЛ…», «✕».
- «СВОЙ ТЕКСТ» работает как раньше (открыть/вставить/опции/применить/сохранить на борт/старт/продолжить), но «Сохранить на борт» добавляет/обновляет текст в библиотеке; поле редактора показывает оригинал (если есть), предпросмотр — подготовленную версию.
- Удаление текста — с подтверждением, в `backups\deleted-texts\`.
