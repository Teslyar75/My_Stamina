## 1. Что это за проект

**Star Typing** (до версии 3.1 — **Stamina**) — мой тренажёр слепой печати на Python (tkinter). Пользователь загружает
свой текст (книгу/статью), программа адаптирует его (без знаков препинания, строчные,
один пробел) и даёт набирать. Сейчас я набираю «1984» Оруэлла на английском.

## 2. Цель

Сделать интерфейс как **пульт космического корабля / HUD**, улучшить функционал.

### Стиль
- Фон «глубокий космос» `#03060C`, панели `#081221`, рамки `#15314D` / `#1F4F7A`.
- Неон: циан `#00E5FF` (основной), янтарь `#FFB000` (акцент/цель/текущая клавиша),
  красный `#FF3B5C` (ошибки), зелёный `#3DFF8A` (успех), текст `#D6F4FF`, приглушённый `#6F90AB`.
- Шрифты: заголовки и цифры — `Bahnschrift` (запасной Segoe UI), строка набора — `Cascadia Mono`
  (запасной Consolas).
- Панели со срезанными углами (chamfer) и яркими уголками-акцентами; «свечение» —
  несколько контуров смешанных цветов (в tkinter нет прозрачности).
- Приборы: спидометр (зн/мин, стрелка, дуга, отметка цели), кольцо точности,
  сегментная шкала «ритм», цифровые табло (время, ошибки, серия, осталось).
- «Иллюминатор»: строка набора с фиксированным центром (как в оригинале), звёзды
  летят быстрее при быстрой печати (≈70 линий, `canvas.coords`, ~30 fps, можно выключить),
  тонкие scanlines.
- Масштаб: ноутбук 1920×1080 при 125 % → включить DPI-awareness и умножать размеры на коэффициент.

### Функционал
- Живые приборы скорости/точности/ритма; время считается с первой клавиши, простои > 4 с не считаются.
- Пауза Esc (без диалога «закрыть программу»), автопауза при потере фокуса.
- Экранная клавиатура EN+RU подписи, зоны пальцев, подсказка «каким пальцем», тепловая карта ошибок.
- Миссии (10 EN + 10 RU, по рядам клавиатуры), звёзды 1–3, открытие следующей, звания по XP.
- «Ремонт систем» — адаптивное упражнение из слов со слабыми клавишами.
- «Бортжурнал»: сводка, график последних 30 заходов (скорость + точность), тепловая карта.
- **Главная функция — свой текст** (сохранить полностью!): открыть файл (UTF-8/cp1251) или вставить
  из буфера; переключатели «Убрать заглавные буквы» / «Убрать знаки препинания» / «Один пробел между
  словами» (каждый отдельно, по умолчанию все включены = прежнее поведение); «Применить к тексту в
  поле»; живой предпросмотр; «Сохранить на борт», «Старт», «Продолжить с места»; «Защита от правки»;
  «Экспорт .txt»; «Очистить». Прогресс автосохраняется (не чаще раза в 3 с).
- Настройки: звук, громкость (4 уровня), переводчик, звёзды, клавиатура, зоны, размер шрифта, папка данных.

### Звук (обязательно)
- Верная клавиша → щелчок печатной машинки (3 варианта по очереди).
- Ошибка → отчётливый низкий «бззт».
- Конец миссии → колокольчик каретки.
- WAV синтезируются самой программой (`stamina/sounds.py`, без чужих файлов), лежат в
  `stamina/sounds/*_v1..v4.wav`, проигрываются `winsound.PlaySound(..., SND_FILENAME|SND_ASYNC)`.
- Включено по умолчанию, переключатель в настройках и F9.

### Переводчик «UPLINK / ПЕРЕВОДЧИК» (обязательно)
- Показывает перевод текущего предложения своего текста: EN→RU (для русского текста RU→EN).
- Запросы в фоновом потоке (`threading` + `queue`), интерфейс не ждёт сеть.
- Сначала Google `translate.googleapis.com/translate_a/single?client=gtx` (без ключа),
  запасной — MyMemory `api.mymemory.translated.net/get?q=...&langpair=en|ru`
  (у MyMemory маленький бесплатный лимит, предупреждение о лимите = ошибка).
- Кэш в JSON на D:, повторные предложения работают без сети; состояние «НЕТ СВЯЗИ», повтор раз в 20 с.
- Границы предложений берутся из оригинального текста (адаптированный без пунктуации);
  если оригинала нет — куски по 14 слов. Следующее предложение подгружается заранее.
- Переключатель в настройках. В миссиях панель скрыта (там случайные слова).

### Ограничения
- HP Ryzen 3 5300U, 8 ГБ RAM: никаких тяжёлых зависимостей, анимации дешёвые и отключаемые.
- Диск C: почти полный — всё новое класть на D:.
- Ярлык и `main.py` должны работать; данные пользователя не терять.
- Весь текст интерфейса и README — на русском.

### Известные ограничения и идеи
- Для «1984» нет оригинала с пунктуацией (старая версия его не сохраняла), поэтому переводчик режет
  текст на куски по 14 слов. Если снова открыть исходный `.txt` в «Свой текст», появится кнопка
  «Продолжить с 2%», и переводчик будет переводить целые предложения.
- Звук идёт через `winsound.PlaySound`: новый звук обрывает предыдущий (при быстрой печати это нормально).
- Перевод использует неофициальный бесплатный адрес Google; если его закроют, сработает
  MyMemory (около 5000 знаков в день без ключа).
- В узком окне (меньше ~1300 px) надпись звания в правом верхнем углу может обрезаться.
- Идеи: начало своего текста с любого места, режим «с регистром и знаками», экспорт статистики в CSV.
