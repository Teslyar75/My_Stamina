## Последние изменения

### 2026-10-18 — Привязка агента, эволюция, режим мастера, чтение книг, диалог выбора

**Привязка агента к OpenCode:**
- Корабль генерирует одноразовый код заселения (make_boarding_code)
- Панель в карточке агента: код, токен OpenCode, статус связи
- Проверка токена через opencode run (простой запрос)
- Для Командира: проверка GitHub API (write-доступ к Teslyar75/My_Stamina)
- Функции: save_binding, read_binding, binding_status, check_opencode_token, check_github_access

**Эволюция характера Ориона:**
- 6 уровней развития (от количества репилок диалога: 0, 10, 30, 60, 100, 200)
- Уровень 1: Знакомство → Уровень 6: Незаменимый
- Правила эволюции автоматически добавляются в блок ЭВОЛЮЦИЯ ХАРАКТЕРА
- Функции: evolution_level, evolution_status, evolution_manner

**Режим мастера (активный ок):**
- Триггеры: нужен мастер, позови мастера, что это, как это работает
- Отслеживание курсора мыши каждые 500 мс
- Анализ элемента под курсором и текущего раздела
- Подсказки через агента каждые 10 секунд
- Выход: скажи стоп
- Функции: detect_master_call, mouse_position_text

**Чтение книг вслух:**
- Доступ к библиотеке (library_books, book_text_for_reading)
- Доступ к английскому модулю (english_books, english_book_sentences, english_words)
- Кнопка ЧИТАТЬ КНИГУ в чате Ориона

**Отправка задач внешнему агенту:**
- Создание задачи через GitHub Issues или локально в orion_external_tasks.md
- Функция: create_external_task

**Диалог выбора агента после входа пилота:**
- Кнопка Заселить агента на экране входа
- После выбора пилота появляется диалог выбора агента
- Выбор сохраняется, изменить можно позже через Орион → АГЕНТЫ
- Файл: stamina/pilot_screens.py: AgentChoiceDialog

**Исправление бага:**
- Кнопка ОТПРАВИТЬ не активировалась после распознавания речи
- Исправлено: _insert_text теперь вызывает send_btn.set_enabled(True)

**Доступ агента к материалам корабля:**
- Наблюдатель: библиотека, английский, скорочтение, журнал, задания, настройки, код
- Командир: всё + правка файлов, команды, внешние задачи

## Ключевые решения

- Права выдаются на входе — на борту не меняют
- Командир — только по коду владельца + токен OpenCode + GitHub write-доступ
- Манеры — документ корабля, пилот правит сам; права — в tools: профиля
- Ключей на борту нет — всё снаружи (D16)
- Эволюция иллюзорна — уровень от количества реплиок, не настоящий ИИ
- Выбор агента сохраняется — после входа пилота, можно изменить позже
