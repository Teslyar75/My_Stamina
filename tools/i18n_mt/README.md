# Как получены переводы интерфейса (uk / en / de)

1. `mt.py <en|uk|de>` — офлайн машинный перевод всех ключей `stamina/i18n/ru.json` моделями
   Helsinki-NLP opus-mt (ru→en, ru→uk, en→de как «мост» для немецкого). Нужны `torch`, `transformers`,
   `sentencepiece` (отдельный venv, в программу не входят). Подстановки `{0}` защищаются, КАПС переводится как
   обычный текст и снова поднимается.
2. `finalize.py` — сборка `stamina/i18n/{lang}.json`: машинный перевод → ручные переводы ключевых экранов
   (`hand_<lang>.txt`, построчно в порядке `key_screens.json`: приветствие, меню, мостик, настройки, окно PDF)
   → словарь званий/вкладок → глоссарий терминов (печать = typing/Tippen, клавиша = Taste, зн/мин = cpm/Z/min …).
3. `python tools/i18n_check.py` — проверка.

Пути в скриптах указывают на рабочие папки box (`/workspace/...`) — поправьте под себя.
Ручную правку отдельных фраз можно делать прямо в `stamina/i18n/<lang>.json`.
