# Голосовой ввод (речь -> текст)

Вспомогательная утилита для диалога с ассистентом: говорите в микрофон, распознанный текст
попадает в **буфер обмена**, вы вставляете его в чат — `Ctrl+V`. Работает **без интернета**
(Vosk, русская модель лежит локально).

Это не часть программы Star Typing: сама программа использует Vosk для проверки
произношения в разделе «Английский» (там английская модель).

## Первый запуск

1. Поставьте библиотеки (если их ещё нет): `pip install vosk sounddevice`
2. Скачайте русскую модель (~45 МБ) — один раз:

   ```
   python tools/voice_input/get_model.py
   ```

   Модель распакуется в `models/vosk-model-small-ru-0.22/`.
3. Windows: двойной щелчок по **`voice.bat`** (он сам найдёт `.venv`).
   Linux/macOS: `python tools/voice_input/voice_input.py`

Проверка «бортовых систем» без микрофона: `voice.bat --self-test`
Проверка микрофона (говорите 6 секунд, видно шкалу): `voice.bat --test-mic`

## Режимы

| Команда | Что делает |
|---|---|
| `voice_input.py` | **По фразе.** Enter -> говорите -> пауза -> текст в буфере. Enter во время записи — прервать. |
| `voice_input.py --once` | **Одна фраза без Enter** — удобно повесить на ярлык или горячую клавишу. |
| `voice_input.py --listen` | **Непрерывно.** Фразы распознаются сами, весь текст копится в буфере. Enter — начать новую порцию. |
| `voice_input.py --type` | Дополнительно **набрать** текст в активное окно (только Windows), пауза перед набором — `--delay`. |
| `voice_input.py --devices` | Список устройств ввода; номер передаётся в `--device N`. |
| `voice_input.py --test-mic` | Живая шкала громкости 6 с: слышит ли микрофон вообще. |
| `voice_input.py --self-test` | Проверка: библиотеки, модель, буфер обмена, набор текста. Без микрофона. |

Полезные настройки:

| Ключ | Смысл | По умолчанию |
|---|---|---|
| `--silence 2.5` | сколько тишины считать концом фразы, с | 2.5 |
| `--soft 0.7` | после какой тишины показать «…пауза», с | 0.7 |
| `--hold` | не рвать фразу по тишине: только клавиша или лимит | выкл |
| `--max-sec 120` | максимальная длина фразы, с | 120 |
| `--idle 12` | сколько ждать речи, прежде чем сдаться, с | 12 |
| `--gate 0.003` | порог тишины, 0…1 — ниже него блок считается паузой (уточняется по фону автоматически) | 0.003 |
| `--no-copy` | не трогать буфер обмена | — |

Заминка посреди речи фразу **не** закрывает: пауза, которую заметил Vosk, копится в общий
текст («привет… как дела» — одна фраза). Пока идёт тишина, в консоли видно «… пауза 1,2 с —
говорите, не закрываю», а причина закрытия фразы печатается после распознавания
(«(фраза закрыта: тишина 2.5 с)»). Порог тишины подстраивается под фон: первые ~1,5 с
утилита слушает комнату, и тихий голос больше не считается паузой.

## Рабочий приём

**Вариант «печатаю руками только Enter»** — держите утилиту запущенной и говорите:

```
voice.bat --listen --type --delay 0
```

Курсор стоит в поле ввода чата, вы говорите, текст сам набирается в него. Enter — отправить
сообщение (уже вручную, чтобы случайно не отправить лишнее).

**Вариант «надёжный»** — `voice.bat` обычный режим: после каждой фразы в буфере лежит
ровно то, что вы сказали.

## Если распознаёт неточно

`vosk-model-small-ru-0.22` (44 МБ) быстрая, но путает похожие слова. Если важна точность —
скачайте большую модель (1.8 ГБ), она подхватится сама:

```
python tools/voice_input/get_model.py vosk-model-ru-0.42
```

Обе могут лежать рядом в `models/`. Если русских моделей несколько, утилита берёт первую
по алфавиту (это `vosk-model-ru-0.42`); выбрать явно — `--model models/имя-папки`.

## Мелочи, о которых стоит знать

- Первая буква фразы делается заглавной, лишние пробелы убираются. Если диктуете путь к файлу
  или код — проверяйте текст перед отправкой.
- Каждая фраза дописывается в `voice_log.txt` (папка рядом, в `.gitignore`): история диктовки.
- `--type` работает в Windows и печатает символы Unicode (кириллица тоже), но **не** нажимает
  Enter и заменяет перевод строки пробелом.
- Пауза. Заминка посреди речи фразу не рвёт (тишина 2,5 с по умолчанию), а если хочется
  диктовать до своей команды — `--hold`. Подбирать `--silence` и `--gate` вручную нужно редко.
- Модель `vosk-model-small-ru-0.22` понимает обычную речь, но не имена, латиницу и термины:
  «файл a-s-a-r точка py» распознаётся как текст, а не как `asr.py`.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| «Нет модели Vosk» | `python tools/voice_input/get_model.py` |
| «Не хватает библиотеки» | `pip install vosk sounddevice` |
| Шкала в `--test-mic` пустая | Проверьте устройство (`--devices`, `--device N`), разрешение микрофона (Параметры → Конфиденциальность → Микрофон), кнопку mute |
| Фраза обрывается слишком рано | Проверьте, что запущена свежая версия (тишина 2,5 с по умолчанию); увеличьте `--silence 4` или диктуйте с `--hold` |
| Фраза «не заканчивается» | `--silence 1.5 --gate 0.02` (жёстче порог тишины) |
| В буфере старое | Текст копируется после каждой фразы; посмотрите строку «В буфере: да» |
| `--type` печатает не туда | Фокус должен быть в нужном окне; увеличьте `--delay`, для непрерывного режима — `--delay 0` |

**Как подобрать `--gate` по своему микрофону:** запустите `--test-mic`, запомните число при
**молчании** (шум комнаты) — порог ставьте в 3–4 раза выше него. На проверенном ноутбуке:
тишина 0.0000–0.0007, тихая речь 0.004–0.022, поэтому подходит `--gate 0.003`.
