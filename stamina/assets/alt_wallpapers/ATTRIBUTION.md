# Обои отсеков ALT UI: источники и лицензии

Файлы `<profile>/<zone>.jpg` собраны командой `python tools/gen_alt_wallpapers.py --photos <папка_с_исходниками>`:
фото приводятся к 1600×900 (cover), для Звездолёта космос вставлен в иллюминатор корпуса (процедурные плиты, трафареты, консоли),
для обоих скинов добавлены тёплая тонировка и виньетка. Это производные работы; лицензии CC BY / CC BY-SA требуют указать автора
(сделано ниже) и распространять производную под той же лицензией (для BY-SA). Если файла нет — работает процедурная сцена
(`python tools/gen_alt_wallpapers.py` без аргументов или отрисовка Canvas в `stamina/alt_ui.py`).

Скриншоты из игр (в том числе Syberia) не используются. Syberia — только ориентир настроения.
