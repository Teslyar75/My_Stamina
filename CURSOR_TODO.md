## 0. Правила (обязательно)

- **Не коммитить пользовательские данные**: `%APPDATA%\Stamina\**`, `~/.local/share/StarTyping/**`, файлы пилотов `.stpilot`,
  PIN/коды доступа, `session.json`, `cargo*.txt`, кэш переводов `cache/`, тексты книг и PDF пользователя.
  В тестах — только свои маленькие образцы (`tests/data/`).
- **Перед любой миграцией данных — резервная копия** (как в `pilot_migrate.py`: `backups/…`). Ничего не удалять безвозвратно.
- **Дизайн — только токены** из `stamina/theme.py` (цвета `CYAN/AMBER/GREEN/RED/PANEL/BG…`, `theme.font()`, `px()`),
  виджеты из `stamina/hud.py` (`HudButton`, `HudPanel` …). Без «сырых» цветов и шрифтов.
- Все новые надписи интерфейса — через `t("русская фраза")` (`from stamina.i18n import t`), затем
  `python tools/i18n_check.py --fix-ru` и переводы в `stamina/i18n/{uk,en,de}.json`.
- Работает на **Windows и Linux** (пути — `pilots.default_root()`, звук/озвучка — `sounds.py`, `english/tts.py`).
- Реальные данные пользователя на ноутбуке не трогать: проверки — во временной папке с временным `APPDATA`.
- Слияние: PR → обычный merge в `master` → `git pull` в `D:\My_New_Stamina`.

```
python -m unittest discover -s tests          # все тесты (Windows / Linux)

DISPLAY=:7 python3 -m unittest discover -s tests   # Linux без экрана (Xvfb)
```
Тесты всегда идут на русском интерфейсе (`stamina/i18n` при `unittest` выбирает `ru`).
